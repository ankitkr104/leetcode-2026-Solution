# Problem Statement

You are given two strings `s` and `target`, each of length `n`, consisting of lowercase English letters.

Return the **lexicographically smallest string** that is both:

1. A **palindromic permutation** of `s`.
2. **Strictly greater** than `target`.

If no such string exists, return an empty string `""`.

A string `a` is lexicographically strictly greater than a string `b` of the same length if, at the first position where they differ, `a` has a character that appears later in the alphabet than the corresponding character in `b`.

---

## Example 1

**Input:**

    s = "baba"
    target = "abba"

**Output:**

    "baab"

**Explanation:**

The palindromic permutations of `s` in lexicographical order are:

    "abba"
    "baab"

`"abba"` is equal to the target, so it is not strictly greater.

`"baab"` is the smallest palindromic permutation that is strictly greater than `"abba"`.

Therefore, the answer is `"baab"`.

---

## Example 2

**Input:**

    s = "baba"
    target = "bbaa"

**Output:**

    ""

**Explanation:**

The palindromic permutations are:

    "abba"
    "baab"

Both are lexicographically smaller than `"bbaa"`.

Therefore, no valid answer exists.

---

## Example 3

**Input:**

    s = "abc"
    target = "abb"

**Output:**

    ""

**Explanation:**

The frequencies of the characters are:

    a -> 1
    b -> 1
    c -> 1

A palindrome can have at most one character with an odd frequency.

Here, there are three characters with odd frequencies, so no palindromic permutation of `s` is possible.

Therefore, the answer is `""`.

---

## Example 4

**Input:**

    s = "aac"
    target = "abb"

**Output:**

    "aca"

**Explanation:**

The only palindromic permutation of `"aac"` is `"aca"`.

Since:

    "aca" > "abb"

the answer is `"aca"`.

---

## Constraints

- `1 <= n == s.length == target.length <= 300`
- `s` and `target` consist only of lowercase English letters.

---

## Solution Python

    class Solution:
        def lexPalindromicPermutation(self, s: str, target: str) -> str:
            n = len(s)

            # Count frequencies
            cnt = [0] * 26

            for ch in s:
                cnt[ord(ch) - ord('a')] += 1

            # A palindrome can have at most one
            # character with an odd frequency.
            odd_char = ""

            for i in range(26):
                if cnt[i] % 2 == 1:
                    if odd_char != "":
                        return ""

                    odd_char = chr(ord('a') + i)

            # Number of characters in the left half
            half = n // 2

            # Frequency of characters available
            # for the left half.
            half_cnt = [x // 2 for x in cnt]

            def build(left):
                # Construct the complete palindrome
                return left + odd_char + left[::-1]

            # -------------------------------------------------
            # Step 1:
            # Construct the smallest possible palindrome.
            # -------------------------------------------------

            smallest_left = []

            for i in range(26):
                smallest_left.extend(
                    [chr(ord('a') + i)] * half_cnt[i]
                )

            smallest_left = ''.join(smallest_left)

            smallest_palindrome = build(smallest_left)

            if smallest_palindrome > target:
                return smallest_palindrome

            # -------------------------------------------------
            # Step 2:
            # Match the target's left half.
            # -------------------------------------------------

            remaining = half_cnt[:]
            prefix = []

            for i in range(half):
                t = ord(target[i]) - ord('a')

                if remaining[t] > 0:
                    remaining[t] -= 1
                    prefix.append(target[i])
                else:
                    break

            # -------------------------------------------------
            # Step 3:
            # The complete left half matched target's left half.
            #
            # The resulting palindrome itself may still be
            # greater than target because of the middle/right half.
            # -------------------------------------------------

            if len(prefix) == half:
                left = ''.join(prefix)
                candidate = build(left)

                if candidate > target:
                    return candidate

            # -------------------------------------------------
            # Step 4:
            # Backtrack from right to left.
            # -------------------------------------------------

            for i in range(len(prefix) - 1, -1, -1):

                # Restore the current character
                current = ord(prefix[i]) - ord('a')
                remaining[current] += 1

                target_char = ord(target[i]) - ord('a')

                # Find the smallest available character
                # greater than target[i].
                for j in range(target_char + 1, 26):

                    if remaining[j] > 0:

                        remaining[j] -= 1

                        # Keep the prefix before i
                        left = prefix[:i]

                        # Make this position greater
                        left.append(chr(ord('a') + j))

                        # Fill the remaining positions
                        # with the smallest characters.
                        for x in range(26):
                            left.extend(
                                [chr(ord('a') + x)] * remaining[x]
                            )

                        return build(''.join(left))

            return ""
