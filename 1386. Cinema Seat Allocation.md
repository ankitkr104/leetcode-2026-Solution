## Problem Statement

A cinema has `n` rows of seats, numbered from `1` to `n`. Each row has 10 seats, numbered from `1` to `10`.

You are given a 2D integer array `reservedSeats`, where `reservedSeats[i] = [rowi, seati]` means that seat `seati` in row `rowi` is already reserved.

A four-person group must be assigned to four seats in the **same row**.

The group can be seated in one of the following seat blocks:

- Seats `2, 3, 4, 5`
- Seats `4, 5, 6, 7`
- Seats `6, 7, 8, 9`

A block can be used only if **none of its seats are reserved**.

Each seat can be assigned to **at most one group**.

Return the maximum number of four-person groups that can be assigned.

## Examples

### Example 1

**Input:**
`n = 3, reservedSeats = [[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]]`

**Output:**
`4`

**Explanation:**

There are 3 rows.

- Row 1 has reservations at seats `2, 3, 8`, so only one group can be placed.
- Row 2 has a reservation at seat `6`, so only one group can be placed.
- Row 3 has reservations at seats `1, 10`, so two groups can be placed.

Therefore:

`1 + 1 + 2 = 4`

### Example 2

**Input:**
`n = 2, reservedSeats = [[2,1],[1,8],[2,6]]`

**Output:**
`2`

### Example 3

**Input:**
`n = 4, reservedSeats = [[4,3],[1,4],[4,6],[1,7]]`

**Output:**
`4`

## Constraints

- `1 <= n <= 10^9`
- `1 <= reservedSeats.length <= min(10 * n, 10^4)`
- `reservedSeats[i] == [rowi, seati]`
- `1 <= rowi <= n`
- `1 <= seati <= 10`
- All `reservedSeats[i]` are distinct.


## Python Solution

    class Solution:
    def maxNumberOfFamilies(self, n, reservedSeats):
        rows = {}

        # Store only seats 2 to 9.
        # Seats 1 and 10 do not affect any group.
        for row, seat in reservedSeats:
            if 2 <= seat <= 9:
                if row not in rows:
                    rows[row] = 0

                rows[row] |= 1 << (seat - 2)

        # Every row can initially fit 2 groups.
        ans = 2 * n

        # Seats 2, 3, 4, 5
        left = 0b00001111

        # Seats 4, 5, 6, 7
        middle = 0b00111100

        # Seats 6, 7, 8, 9
        right = 0b11110000

        # Process only rows containing relevant reservations.
        for mask in rows.values():
            groups = 0

            # Can use seats 2-5
            if (mask & left) == 0:
                groups += 1

            # Can use seats 6-9
            if (mask & right) == 0:
                groups += 1

            # If neither side works, try seats 4-7.
            if groups == 0 and (mask & middle) == 0:
                groups = 1

            # We initially counted this row as 2 groups.
            ans -= 2 - groups

        return ans
