# Problem Statement

You are given an integer array `nums` consisting of **unique integers**.

Originally, `nums` contained **every integer within a continuous range**, but some integers may have been removed.

It is guaranteed that:

- The **smallest** element of the original range is still present.
- The **largest** element of the original range is still present.

Return a **sorted list** of all missing integers in the original range.

If no integers are missing, return an empty list.

---

## Example 1

```text
Input

nums = [1,4,2,5]
```

Output

```text
[3]
```

### Explanation

Smallest number

```text
1
```

Largest number

```text
5
```

Complete range

```text
[1,2,3,4,5]
```

Missing number

```text
3
```

---

## Example 2

```text
Input

nums = [7,8,6,9]
```

Output

```text
[]
```

### Explanation

Complete range

```text
[6,7,8,9]
```

Every number exists.

---

## Example 3

```text
Input

nums = [5,1]
```

Output

```text
[2,3,4]
```

### Explanation

Complete range

```text
[1,2,3,4,5]
```

Missing numbers

```text
2

3

4
```

---

## Constraints

```text
2 <= nums.length <= 100

1 <= nums[i] <= 100

All elements are unique.
```

---

# Python3 Solution

```python
from typing import List

class Solution:
    def findMissing(self, nums: List[int]) -> List[int]:
        seen = set(nums)

        left = min(nums)
        right = max(nums)

        ans = []

        for x in range(left, right + 1):
            if x not in seen:
                ans.append(x)

        return ans
```
