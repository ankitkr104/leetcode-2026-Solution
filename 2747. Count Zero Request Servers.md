# Problem Statement

You are given:

- An integer `n` representing the total number of servers.
- A 2D integer array `logs`, where `logs[i] = [server_id, time]` indicates that the server received a request at the given time.
- An integer `x`.
- An array `queries`.

For each query `queries[i]`, consider the inclusive time interval:

    [queries[i] - x, queries[i]]

Return an array `arr` where `arr[i]` represents the number of servers that did not receive any requests during that interval.

## Examples

### Example 1

**Input:**
    n = 3
    logs = [[1,3],[2,6],[1,5]]
    x = 5
    queries = [10,11]

**Output:**
    [1,2]

**Explanation:**

For query `10`, the interval is `[5,10]`.

- Server 1 received a request at time 5.
- Server 2 received a request at time 6.
- Server 3 received no requests.

Answer = `1`.

For query `11`, the interval is `[6,11]`.

- Server 2 received a request at time 6.
- Servers 1 and 3 received no requests.

Answer = `2`.

### Example 2

**Input:**
    n = 3
    logs = [[2,4],[2,1],[1,2],[3,1]]
    x = 2
    queries = [3,4]

**Output:**
    [0,1]

**Explanation:**

For query `3`, the interval is `[1,3]`. All three servers received requests.

For query `4`, the interval is `[2,4]`. Only servers 1 and 2 received requests, so the answer is `1`.

## Constraints

- `1 <= n <= 10^5`
- `1 <= logs.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `logs[i].length == 2`
- `1 <= logs[i][0] <= n`
- `1 <= logs[i][1] <= 10^6`
- `1 <= x <= 10^5`
- `x < queries[i] <= 10^6`
