# Problem Statement

You are given a 2D integer array `grid` of size `m x n`.

You start at the top-left cell `(0, 0)` and want to reach the bottom-right cell `(m - 1, n - 1)`.

At each step, you may move either:
- Right: `(i, j) -> (i, j + 1)`
- Down: `(i, j) -> (i + 1, j)`

The cost of a path is the bitwise XOR of all values along the path, including the starting and ending cells.

Return the **minimum possible XOR value** among all valid paths.

## Examples

### Example 1

**Input:**
    grid = [[1,2],[3,4]]

**Output:**
    6

**Explanation:**

There are two valid paths:

- Right, then down: `1 ^ 2 ^ 4 = 7`
- Down, then right: `1 ^ 3 ^ 4 = 6`

The minimum XOR value is `6`.

### Example 2

**Input:**
    grid = [[6,7],[5,8]]

**Output:**
    9

**Explanation:**

- Right, then down: `6 ^ 7 ^ 8 = 9`
- Down, then right: `6 ^ 5 ^ 8 = 11`

The minimum XOR value is `9`.

### Example 3

**Input:**
    grid = [[2,7,5]]

**Output:**
    0

**Explanation:**

There is only one path:

    2 ^ 7 ^ 5 = 0

Therefore, the answer is `0`.

## Constraints

- `1 <= m == grid.length <= 1000`
- `1 <= n == grid[i].length <= 1000`
- `m * n <= 1000`
- `0 <= grid[i][j] <= 1023`

## C++ Solution

    class Solution {
    public:
        int minXorPath(vector<vector<int>>& grid) {
            int m = grid.size();
            int n = grid[0].size();

            const int MAX_XOR = 1024;

            vector<vector<array<bool, MAX_XOR>>> dp(
                m, vector<array<bool, MAX_XOR>>(n)
            );

            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    dp[i][j].fill(false);
                }
            }

            dp[0][0][grid[0][0]] = true;

            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (i == 0 && j == 0) {
                        continue;
                    }

                    int value = grid[i][j];

                    if (i > 0) {
                        for (int x = 0; x < MAX_XOR; x++) {
                            if (dp[i - 1][j][x]) {
                                dp[i][j][x ^ value] = true;
                            }
                        }
                    }

                    if (j > 0) {
                        for (int x = 0; x < MAX_XOR; x++) {
                            if (dp[i][j - 1][x]) {
                                dp[i][j][x ^ value] = true;
                            }
                        }
                    }
                }
            }

            for (int x = 0; x < MAX_XOR; x++) {
                if (dp[m - 1][n - 1][x]) {
                    return x;
                }
            }

            return -1;
        }
    };
