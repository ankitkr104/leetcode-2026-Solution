# Problem Statement
You are given an integer array `arr`.

Return the number of contiguous subarrays whose sum is odd.

Since the answer can be very large, return it modulo `10^9 + 7`.

## Examples

**Example 1:**
- Input: `arr = [1,3,5]`
- Output: `4`
- Explanation: The subarrays with odd sums are `[1]`, `[1,3,5]`, `[3]`, and `[5]`.

**Example 2:**
- Input: `arr = [2,4,6]`
- Output: `0`
- Explanation: Every subarray has an even sum.

**Example 3:**
- Input: `arr = [1,2,3,4,5,6,7]`
- Output: `16`

## Constraints
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 100`

## C++ Solution

    class Solution {
    public:
        int numOfSubarrays(vector<int>& arr) {
            const int MOD = 1e9 + 7;

            long long even = 1;
            long long odd = 0;
            long long prefix = 0;
            long long ans = 0;

            for (int num : arr) {
                prefix += num;

                if (prefix % 2 == 1) {
                    ans = (ans + even) % MOD;
                    odd++;
                } else {
                    ans = (ans + odd) % MOD;
                    even++;
                }
            }

            return ans;
        }
    };
