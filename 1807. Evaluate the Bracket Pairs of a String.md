# Problem Statement

You are given a string `s` containing bracket pairs. Each bracket pair contains a non-empty key.

For example:

    "(name)is(age)yearsold"

contains the keys:

    "name"
    "age"

You are also given a 2D array `knowledge`, where:

    knowledge[i] = [key, value]

means that the key has the given value.

For every bracket pair:

- If its key exists in `knowledge`, replace the entire bracket pair with its corresponding value.
- If its key does not exist, replace the entire bracket pair with `"?"`.

Return the resulting string after evaluating all bracket pairs.

There are no nested brackets.

---

## Examples

### Example 1

    Input:
    s = "(name)is(age)yearsold"
    knowledge = [["name","bob"],["age","two"]]

    Output:
    "bobistwoyearsold"

Explanation:

    (name) -> bob
    (age)  -> two

Therefore:

    "bob" + "is" + "two" + "yearsold"

gives:

    "bobistwoyearsold"

---

### Example 2

    Input:
    s = "hi(name)"
    knowledge = [["a","b"]]

    Output:
    "hi?"

Explanation:

`"name"` does not exist in `knowledge`, so:

    (name) -> ?

---

### Example 3

    Input:
    s = "(a)(a)(a)aaa"
    knowledge = [["a","yes"]]

    Output:
    "yesyesyesaaa"

Explanation:

Every occurrence of `(a)` is replaced with `"yes"`.

The `a` characters outside brackets are unchanged.

---

## Constraints

- `1 <= s.length <= 10^5`
- `0 <= knowledge.length <= 10^5`
- `knowledge[i].length == 2`
- `1 <= keyi.length, valuei.length <= 10`
- `s` consists of lowercase English letters and `(`, `)`.
- Every `(` has a corresponding `)`.
- Every bracket key is non-empty.
- There are no nested brackets.
- Each key in `knowledge` is unique.
