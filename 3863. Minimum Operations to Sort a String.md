# Problem Statement

You are given a string `s` consisting of lowercase English letters.

In one operation, you can select any substring of `s` that is **not the entire string** and sort it in non-descending alphabetical order.

Return the minimum number of operations required to make `s` sorted in non-descending order. If it is impossible, return `-1`.

## Examples

### Example 1

**Input:**
    s = "dog"

**Output:**
    1

**Explanation:**

Sort the substring `"og"` to obtain `"go"`.

    "dog" -> "dgo"

The string is now sorted, so the answer is `1`.

### Example 2

**Input:**
    s = "card"

**Output:**
    2

**Explanation:**

First, sort `"car"`:

    "card" -> "acrd"

Then, sort `"rd"`:

    "acrd" -> "acdr"

The string is now sorted, so the answer is `2`.

### Example 3

**Input:**
    s = "gf"

**Output:**
    -1

**Explanation:**

The only non-empty proper substrings are `"g"` and `"f"`. Sorting either one does not change the string, so it is impossible to sort `"gf"`.

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
