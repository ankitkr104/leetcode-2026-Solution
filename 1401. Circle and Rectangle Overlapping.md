# Problem Statement

You are given:

- A circle represented by `(radius, xCenter, yCenter)`.
- An axis-aligned rectangle represented by `(x1, y1, x2, y2)`.

Here:

- `(x1, y1)` is the bottom-left corner of the rectangle.
- `(x2, y2)` is the top-right corner of the rectangle.

Return `true` if the circle and rectangle have **any common point**. Otherwise, return `false`.

---

## Examples

### Example 1

    Input:
    radius = 1
    xCenter = 0
    yCenter = 0
    x1 = 1
    y1 = -1
    x2 = 3
    y2 = 1

    Output:
    true

Explanation:

The circle and rectangle share the point `(1, 0)`.

---

### Example 2

    Input:
    radius = 1
    xCenter = 1
    yCenter = 1
    x1 = 1
    y1 = -3
    x2 = 2
    y2 = -1

    Output:
    false

Explanation:

The rectangle is too far from the circle, so they do not overlap.

---

### Example 3

    Input:
    radius = 1
    xCenter = 0
    yCenter = 0
    x1 = -1
    y1 = 0
    x2 = 0
    y2 = 1

    Output:
    true

Explanation:

The circle and rectangle share boundary points, so they overlap.

---

## Constraints

- `1 <= radius <= 2000`
- `-10^4 <= xCenter, yCenter <= 10^4`
- `-10^4 <= x1 < x2 <= 10^4`
- `-10^4 <= y1 < y2 <= 10^4`
