# Problem Statement

An axis-aligned rectangle is represented as:

    [x1, y1, x2, y2]

where:

- `(x1, y1)` is the **bottom-left** corner.
- `(x2, y2)` is the **top-right** corner.

The rectangle's edges are parallel to the X-axis and Y-axis.

Given two rectangles `rec1` and `rec2`, return `true` if they overlap with a **positive area**.

Two rectangles that only touch at:

- A corner
- An edge

do **not** overlap.

---

## Examples

### Example 1

Input:

    rec1 = [0,0,2,2]
    rec2 = [1,1,3,3]

Output:

    true

Explanation:

The rectangles share an area from:

    x = 1 to 2
    y = 1 to 2

The intersection has positive area.

---

### Example 2

Input:

    rec1 = [0,0,1,1]
    rec2 = [1,0,2,1]

Output:

    false

Explanation:

The rectangles only touch along the vertical edge:

    x = 1

They do not share any positive-area region.

---

### Example 3

Input:

    rec1 = [0,0,1,1]
    rec2 = [2,2,3,3]

Output:

    false

Explanation:

The rectangles are completely separated.

---

## Constraints

- `rec1.length == 4`
- `rec2.length == 4`
- `-10^9 <= rec1[i], rec2[i] <= 10^9`
- Both rectangles have non-zero area.

---

## C++ Solution

    class Solution {
    public:
        bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
            int left = max(rec1[0], rec2[0]);
            int right = min(rec1[2], rec2[2]);

            int bottom = max(rec1[1], rec2[1]);
            int top = min(rec1[3], rec2[3]);

            return left < right && bottom < top;
        }
    };
