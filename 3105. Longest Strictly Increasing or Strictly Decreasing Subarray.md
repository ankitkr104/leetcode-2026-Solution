# Problem Statement
You are given an integer array `nums`.

Return the length of the longest contiguous subarray that is either:
- Strictly increasing: Every element is greater than the previous element.
- Strictly decreasing: Every element is smaller than the previous element.

Equal adjacent elements break both increasing and decreasing sequences.

## Examples

**Example 1:**
- Input: `nums = [1,4,3,3,2]`
- Output: `2`
- Explanation: The longest strictly increasing subarray is `[1,4]`, and the longest strictly decreasing subarray is `[4,3]` or `[3,2]`.

**Example 2:**
- Input: `nums = [3,3,3,3]`
- Output: `1`
- Explanation: Equal adjacent elements cannot form a strictly increasing or decreasing subarray.

**Example 3:**
- Input: `nums = [3,2,1]`
- Output: `3`
- Explanation: The entire array is strictly decreasing.

## Constraints
- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 50`
