## Problem Statement

Given an array `nums` that represents a permutation of integers from `1` to `n`, construct a binary search tree (BST) by inserting the elements of `nums` in order into an initially empty BST.

Find the number of different ways to reorder `nums` so that the resulting BST is identical to the BST constructed from the original array.

Return the number of valid reorderings, excluding the original ordering, modulo `10^9 + 7`.

## Examples

### Example 1

**Input:**
    nums = [2,1,3]

**Output:**
    1

**Explanation:**

The reorderings `[2,1,3]` and `[2,3,1]` produce the same BST. Excluding the original ordering, only one valid reordering remains.

### Example 2

**Input:**
    nums = [3,4,5,1,2]

**Output:**
    5

**Explanation:**

There are five reorderings, excluding the original ordering, that produce the same BST:

    [3,1,2,4,5]
    [3,1,4,2,5]
    [3,1,4,5,2]
    [3,4,1,2,5]
    [3,4,1,5,2]

### Example 3

**Input:**
    nums = [1,2,3]

**Output:**
    0

**Explanation:**

Only the original ordering produces the same BST. Therefore, there are no other valid reorderings.

## Constraints

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= nums.length`
- All integers in `nums` are distinct.


## C++ Solution

    class Solution {
    private:
        static constexpr long long MOD = 1000000007LL;
        vector<vector<long long>> combinations;

        long long countWays(vector<int>& nums) {
            int n = nums.size();

            if (n <= 2) {
                return 1;
            }

            vector<int> left;
            vector<int> right;

            int root = nums[0];

            for (int i = 1; i < n; i++) {
                if (nums[i] < root) {
                    left.push_back(nums[i]);
                } else {
                    right.push_back(nums[i]);
                }
            }

            long long leftWays = countWays(left);
            long long rightWays = countWays(right);

            long long interleavings =
                combinations[n - 1][left.size()];

            return interleavings * leftWays % MOD
                   * rightWays % MOD;
        }

    public:
        int numOfWays(vector<int>& nums) {
            int n = nums.size();

            combinations.assign(
                n + 1, vector<long long>(n + 1, 0)
            );

            for (int i = 0; i <= n; i++) {
                combinations[i][0] = 1;
                combinations[i][i] = 1;

                for (int j = 1; j < i; j++) {
                    combinations[i][j] =
                        (combinations[i - 1][j - 1]
                         + combinations[i - 1][j]) % MOD;
                }
            }

            return (countWays(nums) - 1 + MOD) % MOD;
        }
    };
