# Problem Statement
You are given an integer array `nums` and two integers `l` and `r`.

Find the minimum sum of a contiguous subarray whose length is between `l` and `r` (inclusive) and whose sum is strictly positive.

Return `-1` if no such subarray exists.

## Examples

**Example 1:**
- Input: `nums = [3, -2, 1, 4], l = 2, r = 3`
- Output: `1`
- Explanation: The subarray `[3, -2]` has sum `1`, which is the smallest positive sum among all valid subarrays.

**Example 2:**
- Input: `nums = [-2, 2, -3, 1], l = 2, r = 3`
- Output: `-1`
- Explanation: No subarray of an allowed length has a positive sum.

**Example 3:**
- Input: `nums = [1, 2, 3, 4], l = 2, r = 4`
- Output: `3`
- Explanation: The subarray `[1, 2]` has the minimum positive sum of `3`.

## Constraints
- `1 <= nums.length <= 100`
- `1 <= l <= r <= nums.length`
- `-1000 <= nums[i] <= 1000`

## C++ Solution

    class Solution {
    public:
        int minimumSumSubarray(vector<int>& nums, int l, int r) {
            int n = nums.size();

            vector<int> prefix(n + 1, 0);

            // Build prefix sum array
            for (int i = 0; i < n; i++) {
                prefix[i + 1] = prefix[i] + nums[i];
            }

            int ans = INT_MAX;

            // Check all valid subarrays
            for (int i = 0; i < n; i++) {
                for (int len = l; len <= r && i + len <= n; len++) {
                    int sum = prefix[i + len] - prefix[i];

                    if (sum > 0) {
                        ans = min(ans, sum);
                    }
                }
            }

            return ans == INT_MAX ? -1 : ans;
        }
    };
