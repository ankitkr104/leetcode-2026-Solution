## Problem Statement

You are given a positive integer `n`.

Return the **maximum product** of any two digits in `n`.

**Note:** You may use the same digit twice only if it appears more than once in the number.

---

## Example 1

```text
Input

n = 31
```

Output

```text
3
```

### Explanation

Digits

```text
[3,1]
```

Possible products

```text
3 × 1 = 3
```

Maximum product

```text
3
```

## Example 3

```text
Input

n = 124
```

Output

```text
8
```

### Explanation

Digits

```text
[1,2,4]
```

Possible products

```text
1 × 2 = 2

1 × 4 = 4

2 × 4 = 8
```

Maximum product

```text
8
```

---

## Constraints

```text
10 <= n <= 10^9
```

---

# Python Solution

```python
class Solution:
    def maxProduct(self, n):
        largest = 0
        secondLargest = 0

        while n > 0:
            digit = n % 10

            if digit >= largest:
                secondLargest = largest
                largest = digit
            elif digit > secondLargest:
                secondLargest = digit

            n //= 10

        return largest * secondLargest
```
