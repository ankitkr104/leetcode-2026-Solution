## Problem Statement

You are given a 0-indexed integer array `nums` and a positive integer `k`.

You can perform the following operation any number of times:

- Choose two distinct indices `i` and `j`.
- Simultaneously update:
  - `nums[i] = nums[i] & nums[j]`
  - `nums[j] = nums[i] | nums[j]`

Here, `&` represents bitwise AND and `|` represents bitwise OR, using the original values before the operation.

You must choose `k` elements from the final array and calculate the sum of their squares.

Return the maximum possible sum modulo `10^9 + 7`.

## Examples

### Example 1

**Input:**
    nums = [2,6,5,8], k = 2

**Output:**
    261

**Explanation:**

After applying operations, the array can become `[0,6,0,15]`.

Choose `15` and `6`:

    15² + 6² = 225 + 36 = 261

### Example 2

**Input:**
    nums = [4,5,4,7], k = 3

**Output:**
    90

**Explanation:**

Choose `7`, `5`, and `4`:

    7² + 5² + 4² = 49 + 25 + 16 = 90

## Constraints

- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## C++ Solution

    class Solution {
    public:
        int maxSum(vector<int>& nums, int k) {
            const long long MOD = 1000000007LL;
            vector<int> bitCount(31, 0);

            // Count occurrences of each set bit.
            for (int num : nums) {
                for (int bit = 0; bit <= 30; bit++) {
                    if (num & (1 << bit)) {
                        bitCount[bit]++;
                    }
                }
            }

            long long answer = 0;

            // Construct k numbers with as many set bits as possible.
            for (int i = 0; i < k; i++) {
                long long value = 0;

                for (int bit = 0; bit <= 30; bit++) {
                    if (bitCount[bit] > 0) {
                        value |= (1LL << bit);
                        bitCount[bit]--;
                    }
                }

                answer = (answer + value * value) % MOD;
            }

            return static_cast<int>(answer);
        }
    };
