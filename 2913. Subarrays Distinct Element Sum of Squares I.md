# Problem Statement

You are given a 0-indexed integer array `nums`.

The distinct count of a subarray is the number of unique elements in that subarray.

Return the sum of the squares of the distinct counts of all non-empty contiguous subarrays of `nums`.

## Examples

### Example 1

**Input:**
    nums = [1,2,1]

**Output:**
    15

**Explanation:**

The possible subarrays and their distinct counts are:

| Subarray | Distinct Count | Square |
|---|---:|---:|
| [1] | 1 | 1 |
| [2] | 1 | 1 |
| [1] | 1 | 1 |
| [1,2] | 2 | 4 |
| [2,1] | 2 | 4 |
| [1,2,1] | 2 | 4 |

Total sum:

    1 + 1 + 1 + 4 + 4 + 4 = 15

### Example 2

**Input:**
    nums = [1,1]

**Output:**
    3

**Explanation:**

The possible subarrays are `[1]`, `[1]`, and `[1,1]`. Each contains one distinct value.

    1² + 1² + 1² = 3

## Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## C++ Solution

    class Solution {
    public:
        int sumCounts(vector<int>& nums) {
            int n = nums.size();
            int answer = 0;

            for (int i = 0; i < n; i++) {
                unordered_set<int> distinct;

                for (int j = i; j < n; j++) {
                    distinct.insert(nums[j]);

                    int count = distinct.size();
                    answer += count * count;
                }
            }

            return answer;
        }
    };
