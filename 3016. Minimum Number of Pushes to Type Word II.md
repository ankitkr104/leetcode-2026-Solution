# Problem Statement

You are given a string `word` consisting of lowercase English letters.

A telephone keypad has **8 available keys** (`2` to `9`) that can be remapped to any collection of lowercase English letters.

For a key:

- The **first** letter assigned to it requires **1 push**.
- The **second** letter requires **2 pushes**.
- The **third** letter requires **3 pushes**, and so on.

Each letter must be assigned to **exactly one** key.

Return the **minimum total number of pushes** required to type `word` after choosing the optimal remapping.

Unlike Problem 3014, **letters may appear multiple times**, so assigning frequently used letters to positions requiring fewer pushes minimizes the total cost.

---

## Example 1

```text
Input

word = "abcde"
```

Output

```text
5
```

### Explanation

Each letter appears once.

Assign every letter to the first position of a different key.

```text
a → 1 push

b → 1 push

c → 1 push

d → 1 push

e → 1 push
```

Total

```text
5
```

---

## Example 2

```text
Input

word = "xyzxyzxyzxyz"
```

Output

```text
12
```

### Explanation

Frequency

```text
x → 4

y → 4

z → 4
```

Assign all three letters to the first position of different keys.

Cost

```text
4 × 1

+

4 × 1

+

4 × 1

=

12
```

---

## Example 3

```text
Input

word = "aabbccddeeffgghhiiiiii"
```

Output

```text
24
```

### Explanation

The most frequent letter `'i'` is assigned to a first-position key.

Less frequent letters occupy later positions when necessary, minimizing the total number of pushes.

---

## Constraints

```text
1 <= word.length <= 100000

word consists of lowercase English letters.
```

---

# Python Solution

```python
from collections import Counter

class Solution:
    def minimumPushes(self, word: str) -> int:
        freq = sorted(Counter(word).values(), reverse=True)

        ans = 0

        for i, f in enumerate(freq):
            ans += (i // 8 + 1) * f

        return ans
```
