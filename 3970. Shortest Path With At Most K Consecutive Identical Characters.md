# Problem Statement

You are given a directed weighted graph with `n` nodes numbered from `0` to `n - 1`.

Each edge is represented as:

    edges[i] = [u, v, w]

This represents a directed edge from node `u` to node `v` with weight `w`.

You are also given:
- A string `labels` of length `n`, where `labels[i]` is the character assigned to node `i`.
- An integer `k`.

Find the minimum total edge weight of a path from node `0` to node `n - 1` such that the concatenation of node labels along the path contains **at most `k` consecutive identical characters**.

Return the minimum cost, or `-1` if no valid path exists.

## Examples

### Example 1

**Input:**
    n = 3
    edges = [[0,1,1],[1,2,1],[0,2,3]]
    labels = "aab"
    k = 1

**Output:**
    3

**Explanation:**

The path `0 -> 1 -> 2` produces `"aab"`, which contains two consecutive `a` characters and is invalid.

The direct path `0 -> 2` produces `"ab"`, which is valid and costs `3`.

### Example 2

**Input:**
    n = 3
    edges = [[0,1,1],[1,2,1],[0,2,3]]
    labels = "aab"
    k = 2

**Output:**
    2

**Explanation:**

The path `0 -> 1 -> 2` produces `"aab"`. It contains at most two consecutive identical characters and costs `2`.

### Example 3

**Input:**
    n = 3
    edges = [[0,1,1],[1,2,1]]
    labels = "aaa"
    k = 2

**Output:**
    -1

**Explanation:**

The only possible path produces `"aaa"`, which has three consecutive identical characters. Therefore, no valid path exists.

## Constraints

- `1 <= n <= 5 * 10^4`
- `0 <= edges.length <= 5 * 10^4`
- `0 <= ui, vi < n`
- `ui != vi`
- `1 <= wi <= 10^4`
- `labels` consists of lowercase English letters.
- `1 <= k <= 50`

## C++ Solution

    class Solution {
    public:
        int shortestPath(int n, vector<vector<int>>& edges,
                         string labels, int k) {
    
            vector<vector<pair<int, int>>> adj(n);
    
            for (auto& e : edges) {
                adj[e[0]].push_back({e[1], e[2]});
            }
    
            const long long INF = LLONG_MAX;
    
            vector<vector<long long>> dist(
                n, vector<long long>(k + 1, INF)
            );
    
            // {cost, node, consecutiveCount}
            using State = tuple<long long, int, int>;
    
            priority_queue<
                State,
                vector<State>,
                greater<State>
            > pq;
    
            dist[0][1] = 0;
            pq.push({0, 0, 1});
    
            while (!pq.empty()) {
                auto [cost, u, count] = pq.top();
                pq.pop();
    
                if (cost != dist[u][count]) {
                    continue;
                }
    
                if (u == n - 1) {
                    return (int)cost;
                }
    
                for (auto& [v, weight] : adj[u]) {
                    int newCount = (labels[u] == labels[v])
                                       ? count + 1
                                       : 1;
    
                    if (newCount > k) {
                        continue;
                    }
    
                    long long newCost = cost + weight;
    
                    if (newCost < dist[v][newCount]) {
                        dist[v][newCount] = newCost;
                        pq.push({newCost, v, newCount});
                    }
                }
            }
    
            return -1;
        }
    };
