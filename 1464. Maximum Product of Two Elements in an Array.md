## Problem Statement

Given an integer array `nums`, choose two **different indices** `i` and `j`.

Return the maximum value of

```text
(nums[i] - 1) × (nums[j] - 1)
```

---

## Example 1

```text
Input

nums = [3,4,5,2]
```

Output

```text
12
```

### Explanation

Choose

```text
nums[1] = 4

nums[2] = 5
```

Then

```text
(4 - 1) × (5 - 1)

= 3 × 4

= 12
```

---

## Example 2

```text
Input

nums = [1,5,4,5]
```

Output

```text
16
```

### Explanation

Choose the two `5`s.

```text
(5 - 1) × (5 - 1)

= 4 × 4

= 16
```

---

## Example 3

```text
Input

nums = [3,7]
```

Output

```text
12
```

### Explanation

```text
(7 - 1) × (3 - 1)

= 6 × 2

= 12
```

---

## Constraints

```text
2 <= nums.length <= 500

1 <= nums[i] <= 1000
```
