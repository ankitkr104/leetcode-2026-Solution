# Problem Statement

You are given two strings:

- `word1`
- `word2`

A string `x` is called **almost equal** to another string `y` if you can change **at most one character** in `x` to make it identical to `y`.

A sequence of indices `seq` is called **valid** if:

- The indices are strictly increasing.
- Taking the characters of `word1` at those indices forms a string that is almost equal to `word2`.

Return the **lexicographically smallest** valid sequence of indices.

If no such sequence exists, return an empty array.

> The answer should be the lexicographically smallest **index array**, not the smallest resulting string.

---

## Example 1

```text
Input

word1 = "vbcca"

word2 = "abc"
```

Output

```text
[0,1,2]
```

### Explanation

Selected characters

```text
v b c
```

Changing

```text
v → a
```

produces

```text
abc
```

Only one modification is required.

---

## Example 2

```text
Input

word1 = "bacdc"

word2 = "abc"
```

Output

```text
[1,2,4]
```

### Explanation

Selected characters

```text
a c c
```

Changing

```text
c → b
```

gives

```text
abc
```

---

## Example 3

```text
Input

word1 = "aaaaaa"

word2 = "aaabc"
```

Output

```text
[]
```

### Explanation

More than one mismatch is unavoidable.

---

## Example 4

```text
Input

word1 = "abc"

word2 = "ab"
```

Output

```text
[0,1]
```

---

## Constraints

```text
1 <= |word2| < |word1| <= 3 × 10^5

Both strings contain only lowercase English letters.
```
