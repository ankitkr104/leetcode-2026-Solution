# Problem Statement

You are given two 0-indexed integer arrays:

- `servers` of length `n`, where `servers[i]` represents the weight of the `i-th` server.
- `tasks` of length `m`, where `tasks[j]` represents the processing time of the `j-th` task.

Tasks are assigned to servers using a queue.

The rules are:

1. Task `j` enters the queue at second `j`.
2. If free servers and waiting tasks are available, assign the front task to the free server with:
   - The smallest weight.
   - The smallest index if weights are equal.
3. If no server is free, wait until one becomes available.
4. If multiple servers become free simultaneously, assign waiting tasks in order using the same server priority.
5. A server assigned task `j` at time `t` becomes free at time `t + tasks[j]`.

Return an array `ans` where `ans[j]` is the index of the server assigned to task `j`.

## Examples

### Example 1

**Input:**
    servers = [3,3,2]
    tasks = [1,2,3,2,1,2]

**Output:**
    [2,2,0,2,1,2]

**Explanation:**

- At second 0, task 0 is assigned to server 2.
- At second 1, task 1 is assigned to server 2.
- At second 2, task 2 is assigned to server 0.
- At second 3, task 3 is assigned to server 2.
- At second 4, task 4 is assigned to server 1.
- At second 5, task 5 is assigned to server 2.

### Example 2

**Input:**
    servers = [5,1,4,3,2]
    tasks = [2,1,2,4,5,2,1]

**Output:**
    [1,4,1,4,1,3,2]

## Constraints

- `servers.length == n`
- `tasks.length == m`
- `1 <= n, m <= 2 * 10^5`
- `1 <= servers[i], tasks[j] <= 2 * 10^5`

## C++ Solution

    class Solution {
    public:
        vector<int> assignTasks(vector<int>& servers,
                                vector<int>& tasks) {

            int n = servers.size();
            int m = tasks.size();

            // Available servers: {weight, index}
            priority_queue<
                pair<int, int>,
                vector<pair<int, int>>,
                greater<pair<int, int>>
            > available;

            // Busy servers: {freeTime, weight, index}
            priority_queue<
                tuple<long long, int, int>,
                vector<tuple<long long, int, int>>,
                greater<tuple<long long, int, int>>
            > busy;

            // Initially, all servers are available.
            for (int i = 0; i < n; i++) {
                available.push({servers[i], i});
            }

            vector<int> ans(m);

            long long time = 0;

            for (int i = 0; i < m; i++) {
                time = max(time, (long long)i);

                // Release all servers that have finished.
                while (!busy.empty() &&
                       get<0>(busy.top()) <= time) {

                    auto [freeTime, weight, index] = busy.top();
                    busy.pop();

                    available.push({weight, index});
                }

                // If no server is available, wait.
                if (available.empty()) {
                    time = get<0>(busy.top());

                    // Release all servers finishing at this time.
                    while (!busy.empty() &&
                           get<0>(busy.top()) <= time) {

                        auto [freeTime, weight, index] = busy.top();
                        busy.pop();

                        available.push({weight, index});
                    }
                }

                // Select the server with minimum weight,
                // breaking ties by minimum index.
                auto [weight, index] = available.top();
                available.pop();

                ans[i] = index;

                // Assign the task to this server.
                long long freeTime = time + tasks[i];

                busy.push({freeTime, weight, index});
            }

            return ans;
        }
    };
