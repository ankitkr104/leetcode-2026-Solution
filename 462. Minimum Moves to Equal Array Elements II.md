# Problem Statement

Given an integer array `nums` of size `n`, return the minimum number of moves required to make all array elements equal.

In one move, you can increment or decrement any single element of the array by `1`.

Return the minimum number of moves needed to make all elements equal.

## Examples

### Example 1

**Input:**
    nums = [1, 2, 3]

**Output:**
    2

**Explanation:**

Only two moves are needed:

    [1, 2, 3]
    [2, 2, 3]
    [2, 2, 2]

### Example 2

**Input:**
    nums = [1, 10, 2, 9]

**Output:**
    16

**Explanation:**

Choose `9` as the target:

    |1 - 9| + |10 - 9| + |2 - 9| + |9 - 9|
    = 8 + 1 + 7 + 0
    = 16

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- The answer fits in a 32-bit integer.


## C++ Solution

    class Solution {
    public:
        int minMoves2(vector<int>& nums) {
            sort(nums.begin(), nums.end());

            int n = nums.size();
            int median = nums[n / 2];

            long long moves = 0;

            for (int num : nums) {
                moves += abs((long long)num - median);
            }

            return (int)moves;
        }
    };
