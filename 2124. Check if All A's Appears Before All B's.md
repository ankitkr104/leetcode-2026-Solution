# Problem Statement

Given a string `s` consisting only of characters `'a'` and `'b'`, return `true` if every `'a'` appears before every `'b'` in the string. Otherwise, return `false`.

## Examples

**Example 1:**

    Input: s = "aaabbb"
    Output: true

    Explanation:
    All 'a' characters appear before all 'b' characters.

**Example 2:**

    Input: s = "abab"
    Output: false

    Explanation:
    An 'a' appears after a 'b', violating the condition.

**Example 3:**

    Input: s = "bbb"
    Output: true

    Explanation:
    There are no 'a' characters, so the condition is satisfied.

## Constraints

- `1 <= s.length <= 100`
- `s[i]` is either `'a'` or `'b'`.

## C++ Solution

    class Solution {
    public:
        bool checkString(string s) {
            return s.find("ba") == string::npos;
        }
    };
