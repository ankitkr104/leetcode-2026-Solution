# Problem Statement

A valid parentheses string can be:

- Empty: `""`
- `(A)`, where `A` is a valid parentheses string.
- `A + B`, where both `A` and `B` are valid parentheses strings.

A valid parentheses string `s` is called **primitive** if it is non-empty and cannot be split into two non-empty valid parentheses strings.

Given a valid parentheses string `s`, its primitive decomposition is:

    s = P1 + P2 + ... + Pk

For every primitive string `Pi`, remove its **outermost pair of parentheses**.

Return the resulting string.

---

## Examples

### Example 1

Input:

    s = "(()())(())"

Output:

    "()()()"

Explanation:

The primitive decomposition is:

    "(()())" + "(())"

Remove the outermost parentheses from each:

    "(()())" -> "()()"
    "(())"   -> "()"

Therefore:

    "()()" + "()" = "()()()"

---

### Example 2

Input:

    s = "(()())(())(()(()))"

Output:

    "()()()()(())"

Explanation:

Primitive decomposition:

    "(()())" + "(())" + "(()(()))"

After removing the outermost parentheses:

    "()()" + "()" + "()(())"

Therefore:

    "()()()()(())"

---

### Example 3

Input:

    s = "()()"

Output:

    ""

Explanation:

The primitive decomposition is:

    "()" + "()"

Removing the outermost parentheses from each primitive gives:

    "" + ""

Therefore, the result is an empty string.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s[i]` is either `(` or `)`.
- `s` is a valid parentheses string.

---

## C++ Solution

    class Solution {
    public:
        string removeOuterParentheses(string s) {
            string answer;
            int balance = 0;

            for (char c : s) {

                if (c == '(') {
                    // Keep '(' only if it is not
                    // the outermost '(' of a primitive.
                    if (balance > 0) {
                        answer += c;
                    }

                    balance++;
                }
                else {
                    balance--;

                    // Keep ')' only if it is not
                    // the outermost ')' of a primitive.
                    if (balance > 0) {
                        answer += c;
                    }
                }
            }

            return answer;
        }
    };
