# Problem Statement

Alice and Bob are playing a game with a row of stone piles.

- `piles[i]` represents the number of stones in the `i-th` pile.
- Alice starts first.
- Initially,

```text
M = 1
```

On each turn, a player can take the first

```text
X
```

remaining piles, where

```text
1 ≤ X ≤ 2M
```

After taking `X` piles,

```text
M = max(M, X)
```

The game continues until all piles are taken.

Both players play optimally.

Return the **maximum number of stones Alice can collect**.

---

## Example 1

```text
Input

piles = [2,7,9,4,4]
```

Output

```text
10
```

### Explanation

One optimal play is:

```text
Alice takes 1 pile

↓

Bob takes 2 piles

↓

Alice takes the remaining 2 piles
```

Alice collects

```text
2 + 4 + 4 = 10
```

which is optimal.

---

## Example 2

```text
Input

piles = [1,2,3,4,5,100]
```

Output

```text
104
```

---

## Constraints

```text
1 <= piles.length <= 100

1 <= piles[i] <= 10^4
```

---

# Python3 Solution

```python
from functools import lru_cache
from typing import List

class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        n = len(piles)

        suffix = [0] * (n + 1)

        for i in range(n - 1, -1, -1):
            suffix[i] = suffix[i + 1] + piles[i]

        @lru_cache(None)
        def dp(i: int, M: int) -> int:
            if i >= n:
                return 0

            if 2 * M >= n - i:
                return suffix[i]

            best = 0

            for X in range(1, 2 * M + 1):
                best = max(
                    best,
                    suffix[i] - dp(i + X, max(M, X))
                )

            return best

        return dp(0, 1)
```
