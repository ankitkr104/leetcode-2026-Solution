# Problem Statement
You are given five integers: `cost1`, `cost2`, `costBoth`, `need1`, and `need2`.

There are three types of items:

- **Type 1:** Costs `cost1` and contributes 1 unit toward requirement 1.
- **Type 2:** Costs `cost2` and contributes 1 unit toward requirement 2.
- **Type 3:** Costs `costBoth` and contributes 1 unit toward both requirements.

You must collect enough items to satisfy both requirements.

Return the minimum possible total cost.

## Examples

**Example 1:**
- Input: `cost1 = 3, cost2 = 2, costBoth = 1, need1 = 3, need2 = 2`
- Output: `3`
- Explanation: Buy three type 3 items. They contribute 3 units to both requirements.

**Example 2:**
- Input: `cost1 = 5, cost2 = 4, costBoth = 15, need1 = 2, need2 = 3`
- Output: `22`
- Explanation: Buy two type 1 items and three type 2 items. Total cost = `2 * 5 + 3 * 4 = 22`.

**Example 3:**
- Input: `cost1 = 5, cost2 = 4, costBoth = 15, need1 = 0, need2 = 0`
- Output: `0`
- Explanation: No items are required.

## Constraints
- `1 <= cost1, cost2, costBoth <= 10^6`
- `0 <= need1, need2 <= 10^9`
