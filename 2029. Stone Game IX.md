## Problem Statement

Alice and Bob play a game with a row of `n` stones.

You are given an integer array `stones`, where `stones[i]` represents the value of the `ith` stone.

Alice and Bob take turns, with **Alice starting first**.

On each turn, the current player may remove **any one stone** from `stones`.

The player who removes a stone **loses immediately** if the sum of the values of **all removed stones** becomes divisible by `3`.

Bob wins automatically if there are no remaining stones, even if it is Alice's turn.

Both players play optimally.

Return `true` if Alice wins, otherwise return `false`.

---

## Example 1

**Input:**

`stones = [2,1]`

**Output:**

`true`

**Explanation:**

Alice can remove either stone.

Suppose Alice removes `2`.

The removed sum is `2`.

Bob removes the remaining `1`.

The removed sum becomes:

`2 + 1 = 3`

Since `3` is divisible by `3`, Bob loses.

Therefore, Alice wins.

---

## Example 2

**Input:**

`stones = [2]`

**Output:**

`false`

**Explanation:**

Alice must remove the only stone.

The removed sum is `2`, which is not divisible by `3`.

There are no stones remaining, so Bob wins automatically.

Therefore, Alice loses.

---

## Example 3

**Input:**

`stones = [5,1,2,4,3]`

**Output:**

`false`

**Explanation:**

Bob can always force a win.

One possible sequence is:

- Alice removes `1`. Sum = `1`.
- Bob removes `3`. Sum = `4`.
- Alice removes `4`. Sum = `8`.
- Bob removes `2`. Sum = `10`.
- Alice removes `5`. Sum = `15`.

Since `15` is divisible by `3`, Alice loses.

Therefore, the answer is `false`.

---

## Constraints

- `1 <= stones.length <= 10^5`
- `1 <= stones[i] <= 10^4`
