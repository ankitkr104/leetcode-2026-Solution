# Problem Statement
You are climbing a staircase with `n + 1` steps, numbered from `0` to `n`.

You are given a 1-indexed integer array `costs` of length `n`, where `costs[i]` represents the cost of landing on step `i`.

From step `i`, you can jump to:
- Step `i + 1`
- Step `i + 2`
- Step `i + 3`

The cost of jumping from step `i` to step `j` is:

`costs[j] + (j - i)^2`

You start at step `0` with an initial cost of `0`.

Return the minimum total cost required to reach step `n`.

## Examples

**Example 1:**
- Input: `n = 4, costs = [1,2,3,4]`
- Output: `13`
- Explanation: One optimal path is `0 → 1 → 2 → 4`.
  - `0 → 1`: `1 + 1² = 2`
  - `1 → 2`: `2 + 1² = 3`
  - `2 → 4`: `4 + 2² = 8`
  - Total = `2 + 3 + 8 = 13`

**Example 2:**
- Input: `n = 4, costs = [5,1,6,2]`
- Output: `11`
- Explanation: One optimal path is `0 → 2 → 4`.
  - `0 → 2`: `1 + 2² = 5`
  - `2 → 4`: `2 + 2² = 6`
  - Total = `11`

**Example 3:**
- Input: `n = 3, costs = [9,8,3]`
- Output: `12`
- Explanation: Jump directly from `0 → 3`, costing `3 + 3² = 12`.

## Constraints
- `1 <= n == costs.length <= 10^5`
- `1 <= costs[i] <= 10^4`

## C++ Solution

    class Solution {
    public:
        int climbStairs(int n, vector<int>& costs) {
            vector<int> dp(n + 1, INT_MAX);

            dp[0] = 0;

            for (int i = 1; i <= n; i++) {
                for (int jump = 1; jump <= 3; jump++) {
                    if (i - jump >= 0) {
                        int jumpCost = jump * jump;

                        dp[i] = min(
                            dp[i],
                            dp[i - jump] + costs[i - 1] + jumpCost
                        );
                    }
                }
            }

            return dp[n];
        }
    };
