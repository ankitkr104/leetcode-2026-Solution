# Problem Statement

You are given a 0-indexed array `nums` consisting of positive integers.

Initially, you can increase the value of any element by at most `1`.

After modification, select one or more elements such that the selected elements are consecutive when sorted in increasing order.

Return the maximum number of elements you can select.

## Examples

**Example 1:**

    Input: nums = [2,1,5,1,1]
    Output: 3

    Explanation:
    Increase nums[0] and nums[3] by 1.
    The array becomes [3,1,5,2,1].

    Select [1,2,3], which are consecutive.
    Maximum selected elements = 3.

**Example 2:**

    Input: nums = [1,4,7,10]
    Output: 1

    Explanation:
    No two elements can be made consecutive using
    at most one increment per element.

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
