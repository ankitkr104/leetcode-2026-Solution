# Problem Statement

Given an integer array `nums`, return the **maximum product** that can be obtained by multiplying any three numbers.

---

## Example 1

```text
Input

nums = [1,2,3]
```

Output

```text
6
```

### Explanation

The only possible product is

```text
1 × 2 × 3 = 6
```

---

## Example 2

```text
Input

nums = [1,2,3,4]
```

Output

```text
24
```

### Explanation

Choose the three largest numbers

```text
2 × 3 × 4 = 24
```

---

## Example 3

```text
Input

nums = [-1,-2,-3]
```

Output

```text
-6
```

### Explanation

The only possible product is

```text
(-1) × (-2) × (-3) = -6
```

---

## Constraints

```text
3 <= nums.length <= 10^4

-1000 <= nums[i] <= 1000
```

---

# Python Solution

```python
class Solution:
    def maximumProduct(self, nums):
        max1 = max2 = max3 = float("-inf")
        min1 = min2 = float("inf")

        for x in nums:

            if x >= max1:
                max3 = max2
                max2 = max1
                max1 = x
            elif x >= max2:
                max3 = max2
                max2 = x
            elif x > max3:
                max3 = x

            if x <= min1:
                min2 = min1
                min1 = x
            elif x < min2:
                min2 = x

        return max(
            max1 * max2 * max3,
            max1 * min1 * min2
        )
```
