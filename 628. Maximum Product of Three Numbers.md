# Problem Statement

Given an integer array `nums`, return the **maximum product** that can be obtained by multiplying any three numbers.

---

## Example 1

```text
Input

nums = [1,2,3]
```

Output

```text
6
```

### Explanation

The only possible product is

```text
1 × 2 × 3 = 6
```

---

## Example 2

```text
Input

nums = [1,2,3,4]
```

Output

```text
24
```

### Explanation

Choose the three largest numbers

```text
2 × 3 × 4 = 24
```

---

## Example 3

```text
Input

nums = [-1,-2,-3]
```

Output

```text
-6
```

### Explanation

The only possible product is

```text
(-1) × (-2) × (-3) = -6
```

---

## Constraints

```text
3 <= nums.length <= 10^4

-1000 <= nums[i] <= 1000
```
