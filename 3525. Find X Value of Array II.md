# Problem Statement

You are given:

- An array of positive integers `nums`.
- A positive integer `k`.
- A list of queries.

Each query is:

    [index, value, start, x]

For every query:

1. Update `nums[index] = value`.
2. This update **persists** for all future queries.
3. Remove the prefix `nums[0 ... start - 1]`.
4. Then we may remove any suffix, including an empty suffix.
5. Count the number of ways such that the product of the remaining non-empty array has remainder `x` modulo `k`.

Return the answer for every query.

---

## Important Observation

After removing the prefix up to `start - 1`, the remaining array is:

    nums[start ... n-1]

We can then remove a suffix.

Therefore, every possible remaining array is exactly a **non-empty prefix** of:

    nums[start ... n-1]

For example:

    nums = [1,2,3,4,5]
    start = 2

The remaining array is:

    [3,4,5]

Possible non-empty arrays after removing a suffix are:

    [3]
    [3,4]
    [3,4,5]

So the query asks:

> Among all non-empty prefixes of `nums[start ... n-1]`, how many have product remainder `x` modulo `k`?

The difficulty is that every query can also modify one element.

Since:

    n <= 10^5
    queries <= 2 * 10^4
    k <= 5

we need a data structure that supports:

- Point update.
- Query all prefix-product remainders in a range.

A **segment tree** is ideal for this.

---

## Segment Tree Idea

For every segment, store two things:

### 1. `prod`

The product of all elements in the segment modulo `k`.

### 2. `pref[r]`

The number of non-empty prefixes of this segment whose product has remainder `r`.

For example, suppose a segment contains:

    [2, 3, 4]

and:

    k = 5

Its non-empty prefixes are:

    [2]       -> 2
    [2,3]     -> 6 % 5 = 1
    [2,3,4]   -> 24 % 5 = 4

Therefore:

    pref[1] = 1
    pref[2] = 1
    pref[4] = 1

and:

    prod = 4

---

## Merging Two Segments

Suppose we have two adjacent segments:

    A | B

Assume:

    A.prod
    A.pref[]
    B.prod
    B.pref[]

The total product is:

    (A.prod * B.prod) % k

Now consider the prefixes of `A + B`.

There are two types.

### Type 1: Prefix Ends Inside A

These prefixes are exactly the prefixes already stored in `A`.

So:

    result.pref[r] += A.pref[r]

### Type 2: Prefix Contains All of A and Some Prefix of B

If a prefix of `B` has product remainder `r`, then after adding all of `A`, its new remainder becomes:

    (A.prod * r) % k

Therefore:

    result.pref[(A.prod * r) % k] += B.pref[r]

This allows us to merge two segment-tree nodes in `O(k)` time.

---

## Example of Merge

Suppose:

    A = [2]
    B = [3,4]

with:

    k = 5

For `A`:

    prod = 2
    pref[2] = 1

For `B`:

    prefixes:
    [3]     -> 3
    [3,4]   -> 12 % 5 = 2

So:

    B.prod = 2
    B.pref[3] = 1
    B.pref[2] = 1

Now merge them.

Prefixes from `A`:

    [2] -> 2

Prefixes using all of `A` plus a prefix of `B`:

    2 * 3 % 5 = 1
    2 * 2 % 5 = 4

Therefore the combined segment `[2,3,4]` has:

    [2]       -> 2
    [2,3]     -> 1
    [2,3,4]   -> 4

Exactly as required.

---

## Range Query

For a query:

    [index, value, start, x]

we first update:

    nums[index] = value

Then query the segment tree for:

    [start, n - 1]

The resulting node contains:

    pref[x]

which is exactly the number of valid ways for this query.

---

## C++ Solution

    class Solution {
    public:
        struct Node {
            int prod;
            array<long long, 5> pref;

            Node() {
                prod = 1;
                pref.fill(0);
            }
        };

        int K;

        Node mergeNode(const Node& a, const Node& b) {
            Node res;

            res.prod = (a.prod * b.prod) % K;

            // Prefixes completely inside the left segment.
            for (int r = 0; r < K; r++) {
                res.pref[r] += a.pref[r];
            }

            // Prefixes containing the entire left segment
            // and then a prefix of the right segment.
            for (int r = 0; r < K; r++) {
                if (b.pref[r] == 0) {
                    continue;
                }

                int nr = (a.prod * r) % K;
                res.pref[nr] += b.pref[r];
            }

            return res;
        }

        vector<int> resultArray(
            vector<int>& nums,
            int k,
            vector<vector<int>>& queries
        ) {
            K = k;

            int n = nums.size();

            // Iterative segment tree.
            int size = 1;
            while (size < n) {
                size <<= 1;
            }

            vector<Node> tree(2 * size);

            // Build leaves.
            for (int i = 0; i < n; i++) {
                int value = nums[i] % K;

                tree[size + i].prod = value;
                tree[size + i].pref[value] = 1;
            }

            // Build tree.
            for (int i = size - 1; i >= 1; i--) {
                tree[i] = mergeNode(tree[i << 1],
                                     tree[i << 1 | 1]);
            }

            auto update = [&](int pos, int value) {
                int p = size + pos;

                value %= K;

                tree[p] = Node();
                tree[p].prod = value;
                tree[p].pref[value] = 1;

                p >>= 1;

                while (p >= 1) {
                    tree[p] = mergeNode(tree[p << 1],
                                         tree[p << 1 | 1]);
                    p >>= 1;
                }
            };

            auto query = [&](int l, int r) {
                // Query [l, r].
                l += size;
                r += size + 1;

                Node leftResult;
                Node rightResult;

                while (l < r) {
                    if (l & 1) {
                        leftResult = mergeNode(leftResult, tree[l]);
                        l++;
                    }

                    if (r & 1) {
                        --r;
                        rightResult = mergeNode(tree[r], rightResult);
                    }

                    l >>= 1;
                    r >>= 1;
                }

                return mergeNode(leftResult, rightResult);
            };

            vector<int> result;
            result.reserve(queries.size());

            for (const auto& q : queries) {
                int index = q[0];
                int value = q[1];
                int start = q[2];
                int x = q[3];

                // Update persists for future queries.
                update(index, value);

                // Possible remaining arrays are all non-empty
                // prefixes of nums[start ... n-1].
                Node res = query(start, n - 1);

                result.push_back((int)res.pref[x]);
            }

            return result;
        }
    };
