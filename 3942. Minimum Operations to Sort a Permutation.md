# Problem Statement

You are given an integer array `nums` of length `n`, where `nums` is a permutation of the integers from `0` to `n - 1`.

You may perform only the following operations:

1. **Reverse the entire array:** Reverse the order of all elements.
2. **Rotate Left by One:** Move the first element to the end of the array and shift all remaining elements one position to the left.

Return the minimum number of operations required to sort the array in increasing order.

If it is impossible to sort the array using only these operations, return `-1`.

## Examples

### Example 1

**Input:**
    nums = [0,2,1]

**Output:**
    2

**Explanation:**

Rotate left by one:

    [0,2,1] -> [2,1,0]

Reverse the array:

    [2,1,0] -> [0,1,2]

The array is sorted in two operations.

### Example 2

**Input:**
    nums = [1,0,2]

**Output:**
    2

**Explanation:**

Reverse the array:

    [1,0,2] -> [2,0,1]

Rotate left by one:

    [2,0,1] -> [0,1,2]

The array is sorted in two operations.

### Example 3

**Input:**
    nums = [2,0,1,3]

**Output:**
    -1

**Explanation:**

Neither reversing the entire array nor rotating it left by one, in any sequence, can produce `[0,1,2,3]`.

## Constraints

- `1 <= n == nums.length <= 10^5`
- `0 <= nums[i] <= n - 1`
- `nums` is a permutation of the integers from `0` to `n - 1`.

## C++ Solution

    class Solution {
    private:
        int rotationsToSort(const vector<int>& nums) {
            int n = nums.size();
            int zeroPos = -1;

            for (int i = 0; i < n; i++) {
                if (nums[i] == 0) {
                    zeroPos = i;
                    break;
                }
            }

            // After rotating left by zeroPos, the first element is 0.
            for (int i = 0; i < n; i++) {
                if (nums[(zeroPos + i) % n] != i) {
                    return -1;
                }
            }

            return zeroPos;
        }

    public:
        int minOperations(vector<int>& nums) {
            int n = nums.size();

            int answer = rotationsToSort(nums);

            vector<int> reversedNums = nums;
            reverse(reversedNums.begin(), reversedNums.end());

            int reversedRotations = rotationsToSort(reversedNums);

            if (reversedRotations != -1) {
                int candidate = 1 + reversedRotations;

                if (answer == -1 || candidate < answer) {
                    answer = candidate;
                }
            }

            return answer;
        }
    };
