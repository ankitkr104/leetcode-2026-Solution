## Problem Statement

You are given a **0-indexed** array of **distinct** integers `nums`.

There is an element in `nums` that has the **lowest** value and an element that has the **highest** value. We call them the **minimum** and **maximum** respectively.

Your goal is to remove **both** the minimum and maximum elements from the array.

A **deletion** is defined as either:

- Removing an element from the **front** of the array.
- Removing an element from the **back** of the array.

Return the **minimum number of deletions** required to remove both the minimum and maximum elements from the array.

---

## Example 1

**Input:**

```text
nums = [2,10,7,5,4,1,8,6]
```

**Output:**

```text
5
```

**Explanation:**

The minimum element is `1` at index `5`.

The maximum element is `10` at index `1`.

We can remove both elements by:

- Removing `2` elements from the front.
- Removing `3` elements from the back.

Total deletions:

```text
2 + 3 = 5
```

Therefore, the answer is `5`.

---

## Example 2

**Input:**

```text
nums = [0,-4,19,1,8,-2,-3,5]
```

**Output:**

```text
3
```

**Explanation:**

The minimum element is `-4` at index `1`.

The maximum element is `19` at index `2`.

Both elements can be removed by deleting the first `3` elements from the front.

Therefore, the minimum number of deletions is:

```text
3
```

---

## Example 3

**Input:**

```text
nums = [101]
```

**Output:**

```text
1
```

**Explanation:**

There is only one element.

It is both the minimum and maximum element, so we only need one deletion to remove it.

---

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`
- The integers in `nums` are **distinct**.
