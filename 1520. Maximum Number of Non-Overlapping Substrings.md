# Problem Statement

Given a string `s` of lowercase English letters, find the maximum number of **non-empty, non-overlapping substrings** satisfying these conditions:

1. The substrings do not overlap.
2. If a substring contains a character `c`, it must contain **all occurrences** of `c` in the entire string.

If multiple solutions contain the same maximum number of substrings, return the solution with the **minimum total length**.

It is guaranteed that the minimum-total-length solution is unique.

---

## Examples

### Example 1

    Input: s = "adefaddaccc"
    Output: ["e","f","ccc"]

Explanation:

Some valid substrings are:

    "adefaddaccc"
    "adefadda"
    "ef"
    "e"
    "f"
    "ccc"

Choosing `"e"`, `"f"`, and `"ccc"` gives 3 non-overlapping substrings, which is the maximum possible.

---

### Example 2

    Input: s = "abbaccd"
    Output: ["d","bb","cc"]

Explanation:

Both:

    ["d", "abba", "cc"]

and

    ["d", "bb", "cc"]

contain 3 substrings.

However, `["d","bb","cc"]` has the smaller total length, so it is the required answer.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` contains only lowercase English letters.

---

## C++ Solution

    class Solution {
    public:
        vector<string> maxNumOfSubstrings(string s) {
            int n = s.size();

            vector<int> first(26, n);
            vector<int> last(26, -1);

            // Find first and last occurrence of every character.
            for (int i = 0; i < n; i++) {
                int c = s[i] - 'a';
                first[c] = min(first[c], i);
                last[c] = i;
            }

            vector<pair<int, int>> intervals;

            // Build the smallest valid interval for each character.
            for (int c = 0; c < 26; c++) {
                if (last[c] == -1) {
                    continue;
                }

                int left = first[c];
                int right = last[c];
                bool valid = true;

                for (int i = left; i <= right; i++) {
                    int x = s[i] - 'a';

                    // This character occurs before our interval.
                    if (first[x] < left) {
                        valid = false;
                        break;
                    }

                    // Include all occurrences of this character.
                    right = max(right, last[x]);
                }

                if (valid) {
                    intervals.push_back({left, right});
                }
            }

            // Earliest finishing intervals first.
            sort(intervals.begin(), intervals.end(),
                 [](const pair<int, int>& a, const pair<int, int>& b) {
                     return a.second < b.second;
                 });

            vector<string> result;
            int previousEnd = -1;

            for (auto &[left, right] : intervals) {
                if (left > previousEnd) {
                    result.push_back(s.substr(left, right - left + 1));
                    previousEnd = right;
                }
            }

            return result;
        }
    };
