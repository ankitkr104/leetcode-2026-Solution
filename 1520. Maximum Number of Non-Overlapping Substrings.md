# Problem Statement

Given a string `s` of lowercase English letters, find the maximum number of **non-empty, non-overlapping substrings** satisfying these conditions:

1. The substrings do not overlap.
2. If a substring contains a character `c`, it must contain **all occurrences** of `c` in the entire string.

If multiple solutions contain the same maximum number of substrings, return the solution with the **minimum total length**.

It is guaranteed that the minimum-total-length solution is unique.

---

## Examples

### Example 1

    Input: s = "adefaddaccc"
    Output: ["e","f","ccc"]

Explanation:

Some valid substrings are:

    "adefaddaccc"
    "adefadda"
    "ef"
    "e"
    "f"
    "ccc"

Choosing `"e"`, `"f"`, and `"ccc"` gives 3 non-overlapping substrings, which is the maximum possible.

---

### Example 2

    Input: s = "abbaccd"
    Output: ["d","bb","cc"]

Explanation:

Both:

    ["d", "abba", "cc"]

and

    ["d", "bb", "cc"]

contain 3 substrings.

However, `["d","bb","cc"]` has the smaller total length, so it is the required answer.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` contains only lowercase English letters.
