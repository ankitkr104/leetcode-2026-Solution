# Problem Statement

You are given an integer array `nums`.

Two players play a game optimally.

- Player 1 starts first.
- On each turn, a player chooses either the **leftmost** or **rightmost** number from the array.
- The chosen number is added to that player's score.
- The chosen number is then removed from the array.
- The game ends when all numbers have been picked.

Return

```text
true
```

if Player 1 can win or tie (a tie is considered a win for Player 1); otherwise return

```text
false
```

---

## Example 1

```text
Input

nums = [1,5,2]
```

Output

```text
false
```

### Explanation

Player 1 can choose

```text
1

or

2
```

Regardless of the choice, Player 2 will pick

```text
5
```

Final scores

```text
Player 1 = 3

Player 2 = 5
```

Player 1 loses.

---

## Example 2

```text
Input

nums = [1,5,233,7]
```

Output

```text
true
```

### Explanation

Player 1 starts with

```text
1
```

Whatever Player 2 chooses next,

Player 1 can take

```text
233
```

Player 1 finishes with a higher score.

---

## Constraints

```text
1 <= nums.length <= 20

0 <= nums[i] <= 10^7
```
