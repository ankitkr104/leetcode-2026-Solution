# Problem Statement

Given a **valid parentheses string** `s`, return its **maximum nesting depth**.

The nesting depth is the maximum number of parentheses that are open at the same time.

For example:

    "(())"

has a maximum nesting depth of:

    2

because the second `(` is inside the first `(`.

---

## Examples

### Example 1

    Input:
    s = "(1+(2*3)+((8)/4))+1"

    Output:
    3

Explanation:

The digit `8` is inside three nested pairs of parentheses:

    ((8))

Therefore, the maximum nesting depth is:

    3

---

### Example 2

    Input:
    s = "(1)+((2))+(((3)))"

    Output:
    3

Explanation:

The digit `3` is inside three nested pairs of parentheses.

---

### Example 3

    Input:
    s = "()(())((()()))"

    Output:
    3

Explanation:

The deepest nested section is:

    ((()()))

At its deepest point, three parentheses are open simultaneously.

---

## Constraints

- `1 <= s.length <= 100`
- `s` consists of digits `0-9` and characters:
  - `+`
  - `-`
  - `*`
  - `/`
  - `(`
  - `)`
- `s` is guaranteed to be a valid parentheses string.

---


## C++ Solution

    class Solution {
    public:
        int maxDepth(string s) {
            int currentDepth = 0;
            int maxDepth = 0;

            for (char ch : s) {
                if (ch == '(') {
                    currentDepth++;
                    maxDepth = max(maxDepth, currentDepth);
                }
                else if (ch == ')') {
                    currentDepth--;
                }
            }

            return maxDepth;
        }
    };
