## Problem Statement

You are given an `m x n` grid `classroom` where a student volunteer is tasked with cleaning up litter scattered around the room.

Each cell in the grid is one of the following:

- `S`: Starting position of the student.
- `L`: Litter that must be collected. Once collected, the cell becomes empty.
- `R`: Reset area that restores the student's energy to full capacity, regardless of their current energy level. It can be used multiple times.
- `X`: Obstacle that the student cannot pass through.
- `.`: Empty space.

You are also given an integer `energy`, representing the student's maximum energy capacity.

The student starts at `S` with the full amount of energy.

Each move to an adjacent cell (up, down, left, or right) costs 1 unit of energy.

If the energy reaches `0`, the student can only continue if they are currently on a reset area `R`, which resets the energy back to its maximum capacity.

Return the **minimum number of moves** required to collect all litter items, or `-1` if it is impossible.

## Example 1

Input:
classroom = ["S.", "XL"]
energy = 2

Output:
2

Explanation:

- The student starts at `(0, 0)` with 2 units of energy.
- Cell `(1, 0)` is an obstacle, so the student cannot move directly downward.
- Move 1: `(0, 0) -> (0, 1)`, energy becomes 1.
- Move 2: `(0, 1) -> (1, 1)`, collecting the litter.

All litter is collected in 2 moves.

## Example 2

Input:
classroom = ["LS", "RL"]
energy = 4

Output:
3

Explanation:

- The student starts at `(0, 1)` with 4 units of energy.
- Move 1: `(0, 1) -> (0, 0)`, collecting the first litter.
- Move 2: `(0, 0) -> (1, 0)`, reaching `R` and resetting energy to 4.
- Move 3: `(1, 0) -> (1, 1)`, collecting the second litter.

All litter is collected in 3 moves.

## Example 3

Input:
classroom = ["L.S", "RXL"]
energy = 3

Output:
-1

Explanation:

No valid path exists that allows the student to collect all litter.

## Constraints

- `1 <= m == classroom.length <= 20`
- `1 <= n == classroom[i].length <= 20`
- `classroom[i][j]` is one of `S`, `L`, `R`, `X`, or `.`
- `1 <= energy <= 50`
- There is exactly one `S` in the grid.
- There are at most 10 `L` cells in the grid.

## Python Solution

    class Solution:
        def minMoves(self, classroom, energy):
            m = len(classroom)
            n = len(classroom[0])
    
            # Find the starting position and assign an index to each litter.
            start_r = start_c = -1
            litter_id = {}
    
            for r in range(m):
                for c in range(n):
                    if classroom[r][c] == 'S':
                        start_r, start_c = r, c
                    elif classroom[r][c] == 'L':
                        litter_id[(r, c)] = len(litter_id)
    
            total_litter = len(litter_id)
    
            # No litter needs to be collected.
            if total_litter == 0:
                return 0
    
            target_mask = (1 << total_litter) - 1
    
            # BFS state:
            # (row, column, remaining_energy, collected_mask, moves)
            queue = deque()
            queue.append((start_r, start_c, energy, 0, 0))
    
            visited = set()
            visited.add((start_r, start_c, energy, 0))
    
            directions = [
                (1, 0),
                (-1, 0),
                (0, 1),
                (0, -1)
            ]
    
            while queue:
                r, c, current_energy, mask, moves = queue.popleft()
    
                for dr, dc in directions:
                    nr = r + dr
                    nc = c + dc
    
                    # Check boundaries.
                    if nr < 0 or nr >= m or nc < 0 or nc >= n:
                        continue
    
                    # Cannot move through obstacles.
                    if classroom[nr][nc] == 'X':
                        continue
    
                    # Need at least one unit of energy to make a move.
                    if current_energy == 0:
                        continue
    
                    new_energy = current_energy - 1
                    new_mask = mask
    
                    # Collect litter if this cell contains one.
                    if classroom[nr][nc] == 'L':
                        bit = litter_id[(nr, nc)]
                        new_mask |= (1 << bit)
    
                    # Reset energy when entering an R cell.
                    if classroom[nr][nc] == 'R':
                        new_energy = energy
    
                    new_moves = moves + 1
    
                    # Check whether all litter has been collected.
                    if new_mask == target_mask:
                        return new_moves
    
                    state = (nr, nc, new_energy, new_mask)
    
                    if state in visited:
                        continue
    
                    visited.add(state)
                    queue.append(
                        (nr, nc, new_energy, new_mask, new_moves)
                    )
    
            return -1
