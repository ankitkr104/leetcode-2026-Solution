# Problem Statement

You are given a string `s` containing lowercase English letters and parentheses.

For every matching pair of parentheses:

1. Reverse the substring inside the parentheses.
2. Start with the innermost parentheses.
3. Continue until all parentheses have been processed.
4. Remove all parentheses from the final result.

Return the resulting string.

---

## Examples

### Example 1

    Input:
    s = "(abcd)"

    Output:
    "dcba"

Explanation:

The substring inside the parentheses is:

    "abcd"

Reverse it:

    "dcba"

---

### Example 2

    Input:
    s = "(u(love)i)"

    Output:
    "iloveu"

Explanation:

First reverse the innermost substring:

    (love) -> "evol"

The string becomes conceptually:

    "(uevoli)"

Now reverse the outer substring:

    "uevoli" -> "iloveu"

Therefore:

    Output = "iloveu"

---

### Example 3

    Input:
    s = "(ed(et(oc))el)"

    Output:
    "leetcode"

Explanation:

Process the innermost parentheses first:

    (oc) -> "co"

Then:

    (etco) -> "octe"

Finally, reverse the outer substring to obtain:

    "leetcode"

---

## Constraints

- `1 <= s.length <= 2000`
- `s` contains only lowercase English letters and parentheses.
- All parentheses are balanced.
