# Problem Statement 

You are given an array `nums1` of `n` distinct integers.

You want to construct another array `nums2` of length `n` such that the elements in `nums2` are either **all odd or all even**.

For each index `i`, you must choose exactly one of the following:

- `nums2[i] = nums1[i]`
- `nums2[i] = nums1[i] - nums1[j]`, for an index `j != i`, such that `nums1[i] - nums1[j] >= 1`

Return `true` if it is possible to construct such an array, otherwise return `false`.

## Examples

### Example 1

**Input:** `nums1 = [1,4,7]`

**Output:** `true`

**Explanation:**

- `nums2[0] = nums1[0] = 1`
- `nums2[1] = nums1[1] - nums1[0] = 4 - 1 = 3`
- `nums2[2] = nums1[2] = 7`

Therefore:

`nums2 = [1,3,7]`

All elements are odd, so the answer is `true`.

### Example 2

**Input:** `nums1 = [2,3]`

**Output:** `false`

**Explanation:**

For `2`, there is no smaller element, so it must remain `2`, which is even.

For `3`, we can choose:

- `3`
- `3 - 2 = 1`

Both possible values are odd.

Therefore, `2` cannot be made to have the same parity as `3`.

The answer is `false`.

### Example 3

**Input:** `nums1 = [4,6]`

**Output:** `true`

**Explanation:**

We can keep both elements unchanged:

`nums2 = [4,6]`

Both elements are even.

Therefore, the answer is `true`.

## Approach

The key observation is based on the parity of subtraction.

- Even - Even = Even
- Odd - Odd = Even
- Even - Odd = Odd
- Odd - Even = Odd

Let `min_odd` be the smallest odd number in `nums1`.

### Case 1: There is no odd number

If all numbers are even, we can simply keep every number unchanged.

Therefore, the answer is `true`.

### Case 2: There is at least one odd number

All odd numbers can remain unchanged.

For an even number `x` to become odd, we need to subtract an odd number:

`Even - Odd = Odd`

The smallest available odd number is `min_odd`.

Therefore, an even number can be converted to odd only when:

`x > min_odd`

If an even number is smaller than `min_odd`, there is no smaller odd number that can be subtracted from it.

So the answer is `false`.

Otherwise, every even number can be converted to odd, and all elements can have the same parity.

## Algorithm

1. Find the smallest odd number in `nums1`.
2. If there is no odd number, return `true`.
3. Traverse the array.
4. If an even number is smaller than `min_odd`, return `false`.
5. Otherwise, return `true`.

## Python Solution

    class Solution:
      def uniformArray(self, nums1):
          min_odd = float('inf')
  
          # Find the smallest odd number
          for x in nums1:
              if x % 2 == 1:
                  min_odd = min(min_odd, x)
  
          # No odd numbers -> all are already even
          if min_odd == float('inf'):
              return True
  
          # If any even number is smaller than the
          # smallest odd number, construction is impossible.
          for x in nums1:
              if x % 2 == 0 and x < min_odd:
                  return False
  
          return True
