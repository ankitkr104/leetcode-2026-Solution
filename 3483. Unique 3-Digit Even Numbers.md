# Problem Statement

You are given an array of digits called `digits`.

Your task is to determine the number of **distinct three-digit even numbers** that can be formed using these digits.

### Rules

- Each copy of a digit can be used **only once per number**.
- A three-digit number **cannot have a leading zero**.
- The number must be **even**, so its last digit must be one of:
  
      0, 2, 4, 6, 8

- If a digit appears multiple times in `digits`, each copy can be used separately.

---

## Examples

### Example 1

Input:

    digits = [1,2,3,4]

Output:

    12

Explanation:

The distinct three-digit even numbers are:

    124
    132
    134
    142
    214
    234
    312
    314
    324
    342
    412
    432

There are `12` such numbers.

`222` cannot be formed because there is only one copy of digit `2`.

---

### Example 2

Input:

    digits = [0,2,2]

Output:

    2

Explanation:

The only valid numbers are:

    202
    220

The two copies of `2` allow us to use digit `2` twice.

`022` is not valid because a three-digit number cannot start with `0`.

---

### Example 3

Input:

    digits = [6,6,6]

Output:

    1

Explanation:

The only possible number is:

    666

---

### Example 4

Input:

    digits = [1,3,5]

Output:

    0

Explanation:

There are no even digits, so no three-digit even number can be formed.

---

## Constraints

- `3 <= digits.length <= 10`
- `0 <= digits[i] <= 9`

---

## C++ Solution

    class Solution {
    public:
        int totalNumbers(vector<int>& digits) {
            set<int> numbers;
            int n = digits.size();

            for (int i = 0; i < n; i++) {
                // No leading zero
                if (digits[i] == 0) {
                    continue;
                }

                for (int j = 0; j < n; j++) {
                    // Each copy can be used only once
                    if (j == i) {
                        continue;
                    }

                    for (int k = 0; k < n; k++) {
                        // Each copy can be used only once
                        if (k == i || k == j) {
                            continue;
                        }

                        // Last digit must be even
                        if (digits[k] % 2 != 0) {
                            continue;
                        }

                        int number = digits[i] * 100
                                   + digits[j] * 10
                                   + digits[k];

                        numbers.insert(number);
                    }
                }
            }

            return numbers.size();
        }
    };
