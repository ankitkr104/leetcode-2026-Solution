# Problem Statement

You are given an integer array `nums`.

In one move, you may increase the value of any single element `nums[i]` by `1`.

Return the minimum total number of moves required so that all elements in `nums` become equal.

## Examples

### Example 1

**Input:**
    nums = [2, 1, 3]

**Output:**
    3

**Explanation:**

To make all elements equal:

    [2, 1, 3]
    [3, 1, 3]
    [3, 2, 3]
    [3, 3, 3]

The minimum total number of moves is `3`.

### Example 2

**Input:**
    nums = [4, 4, 5]

**Output:**
    2

**Explanation:**

Increase the first two elements by `1`:

    [4, 4, 5]
    [5, 4, 5]
    [5, 5, 5]

The minimum total number of moves is `2`.

## Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## C++ Solution

    class Solution {
    public:
        int minMoves(vector<int>& nums) {
            int maximum = *max_element(nums.begin(), nums.end());

            int moves = 0;

            for (int num : nums) {
                moves += maximum - num;
            }

            return moves;
        }
    };
