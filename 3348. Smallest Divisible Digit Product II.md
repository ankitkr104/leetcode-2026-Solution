# Problem Statement

You are given:

- A string `num` representing a positive integer.
- An integer `t`.

A number is called **zero-free** if it contains **no digit `0`**.

Return the **smallest zero-free number greater than or equal to `num`** such that the **product of its digits** is divisible by `t`.

If no such number exists, return

```text
"-1"
```

---

## Example 1

```text
Input

num = "1234"

t = 256
```

Output

```text
"1488"
```

### Explanation

Product of digits

```text
1 × 4 × 8 × 8 = 256
```

which is divisible by

```text
256
```

No smaller valid zero-free number exists.

---

## Example 2

```text
Input

num = "12355"

t = 50
```

Output

```text
"12355"
```

### Explanation

Digit product

```text
1 × 2 × 3 × 5 × 5 = 150
```

Since

```text
150 % 50 = 0
```

the original number already satisfies the condition.

---

## Example 3

```text
Input

num = "11111"

t = 26
```

Output

```text
"-1"
```

### Explanation

Since

```text
26 = 2 × 13
```

and no digit contributes a factor of

```text
13
```

no valid zero-free number can exist.

---

## Constraints

```text
2 <= num.length <= 2 × 10^5

1 <= t <= 10^14
```
