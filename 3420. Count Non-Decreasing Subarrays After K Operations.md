# Problem Statement
You are given an integer array `nums` and an integer `k`.

For each subarray, you can increment any element by 1 in one operation. Each subarray is considered independently.

Return the number of subarrays that can be converted into a non-decreasing array using at most `k` operations.

A non-decreasing array satisfies:

`nums[i] >= nums[i - 1]`

## Examples

**Example 1:**
- Input: `nums = [6,3,1,2,4,4], k = 7`
- Output: `17`
- Explanation: There are 21 total subarrays. Only four subarrays starting at index 0 and having length at least 3 require more than 7 operations.

**Example 2:**
- Input: `nums = [6,3,1,3,6], k = 4`
- Output: `12`

## Constraints
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## C++ Solution

    class Solution {
    public:
        long long countNonDecreasingSubarrays(vector<int>& nums, int k) {
            int n = nums.size();

            long long ans = 0;
            long long cost = 0;

            int j = n - 1;

            deque<pair<int, int>> dq;

            for (int i = n - 1; i >= 0; i--) {
                int num = nums[i];
                int count = 1;

                // Merge smaller groups into the current value
                while (!dq.empty() && dq.back().first < num) {
                    auto [nextNum, nextCount] = dq.back();
                    dq.pop_back();

                    count += nextCount;

                    cost += 1LL * (num - nextNum) * nextCount;
                }

                dq.emplace_back(num, count);

                // Shrink the window while cost exceeds k
                while (cost > k) {
                    auto [rightmostNum, rightmostCount] = dq.front();
                    dq.pop_front();

                    cost -= 1LL * (rightmostNum - nums[j]);
                    j--;

                    if (rightmostCount > 1) {
                        dq.emplace_front(rightmostNum, rightmostCount - 1);
                    }
                }

                // Count all valid subarrays ending at j
                ans += j - i + 1;
            }

            return ans;
        }
    };
