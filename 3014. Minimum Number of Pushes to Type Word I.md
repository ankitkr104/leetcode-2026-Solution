# Problem Statement

You are given a string `word` consisting of **distinct lowercase English letters**.

A telephone keypad has **8 available keys** (`2` to `9`) that can be remapped to any collection of lowercase letters.

For a key:

- The **first** letter assigned to it requires **1 push**.
- The **second** letter requires **2 pushes**.
- The **third** letter requires **3 pushes**, and so on.

Each letter must be assigned to **exactly one** key.

Return the **minimum total number of pushes** required to type `word` after choosing the optimal remapping.

---

## Example 1

```text
Input

word = "abcde"
```

Output

```text
5
```

### Explanation

Assign each letter to a different key.

```text
a → 1 push

b → 1 push

c → 1 push

d → 1 push

e → 1 push
```

Total pushes

```text
1 + 1 + 1 + 1 + 1 = 5
```

---

## Example 2

```text
Input

word = "xycdefghij"
```

Output

```text
12
```

### Explanation

There are 10 letters but only 8 keys.

The first 8 letters can each occupy the first position of a key.

The remaining 2 letters must occupy the second position.

```text
8 × 1 + 2 × 2

= 8 + 4

= 12
```

---

## Constraints

```text
1 <= word.length <= 26

word consists of lowercase English letters.

All letters are distinct.
```

---

# Python3 Solution

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        ans = 0

        for i in range(len(word)):
            ans += i // 8 + 1

        return ans
```
