# Problem Statement

You are given an integer array `nums` of length `n`.

An integer `k` is called **sortable** if:

1. `k` divides `n`.
2. You can sort `nums` in non-decreasing order by partitioning it into consecutive subarrays of length `k` and cyclically rotating each subarray independently any number of times to the left or right.

Return the sum of all possible sortable integers `k`.

## Examples

### Example 1

**Input:**
    nums = [3,1,2]

**Output:**
    3

**Explanation:**

The divisors of `n = 3` are `1` and `3`.

- `k = 1`: Each subarray contains one element, so rotation cannot change the array.
- `k = 3`: The entire array `[3,1,2]` can be rotated to `[1,2,3]`.

Only `k = 3` is sortable.

Answer: `3`

### Example 2

**Input:**
    nums = [7,6,5]

**Output:**
    0

**Explanation:**

The divisors of `3` are `1` and `3`.

- `k = 1`: The array cannot be changed.
- `k = 3`: Rotations of `[7,6,5]` cannot produce a non-decreasing array.

No value of `k` is sortable, so the answer is `0`.

### Example 3

**Input:**
    nums = [5,8]

**Output:**
    3

**Explanation:**

The divisors of `n = 2` are `1` and `2`.

The array is already sorted, so both values are sortable.

Answer: `1 + 2 = 3`

## Constraints

- `1 <= n == nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## C++ Solution

    class Solution {
    private:
        bool isRotation(vector<int>& nums, vector<int>& sortedNums,
                        int start, int k) {
            // Build the KMP pattern from the corresponding sorted block.
            vector<int> lps(k, 0);
    
            for (int i = 1, len = 0; i < k;) {
                if (sortedNums[start + i] == sortedNums[start + len]) {
                    lps[i++] = ++len;
                } else if (len > 0) {
                    len = lps[len - 1];
                } else {
                    lps[i++] = 0;
                }
            }
    
            // Search for the sorted block in the original block
            // repeated twice. This covers every cyclic rotation.
            int j = 0;
    
            for (int i = 0; i < 2 * k - 1; i++) {
                int value = nums[start + i % k];
    
                while (j > 0 && value != sortedNums[start + j]) {
                    j = lps[j - 1];
                }
    
                if (value == sortedNums[start + j]) {
                    j++;
                }
    
                if (j == k) {
                    return true;
                }
            }
    
            return false;
        }
    
    public:
        int sortableIntegers(vector<int>& nums) {
            int n = nums.size();
    
            vector<int> sortedNums = nums;
            sort(sortedNums.begin(), sortedNums.end());
    
            int answer = 0;
    
            for (int k = 1; k <= n; k++) {
                if (n % k != 0) {
                    continue;
                }
    
                bool sortable = true;
    
                for (int start = 0; start < n; start += k) {
                    if (!isRotation(nums, sortedNums, start, k)) {
                        sortable = false;
                        break;
                    }
                }
    
                if (sortable) {
                    answer += k;
                }
            }
    
            return answer;
        }
    };
