# Problem Statement

You are given an integer array `nums` of length `n`.

An integer `k` is called **sortable** if:

1. `k` divides `n`.
2. You can sort `nums` in non-decreasing order by partitioning it into consecutive subarrays of length `k` and cyclically rotating each subarray independently any number of times to the left or right.

Return the sum of all possible sortable integers `k`.

## Examples

### Example 1

**Input:**
    nums = [3,1,2]

**Output:**
    3

**Explanation:**

The divisors of `n = 3` are `1` and `3`.

- `k = 1`: Each subarray contains one element, so rotation cannot change the array.
- `k = 3`: The entire array `[3,1,2]` can be rotated to `[1,2,3]`.

Only `k = 3` is sortable.

Answer: `3`

### Example 2

**Input:**
    nums = [7,6,5]

**Output:**
    0

**Explanation:**

The divisors of `3` are `1` and `3`.

- `k = 1`: The array cannot be changed.
- `k = 3`: Rotations of `[7,6,5]` cannot produce a non-decreasing array.

No value of `k` is sortable, so the answer is `0`.

### Example 3

**Input:**
    nums = [5,8]

**Output:**
    3

**Explanation:**

The divisors of `n = 2` are `1` and `2`.

The array is already sorted, so both values are sortable.

Answer: `1 + 2 = 3`

## Constraints

- `1 <= n == nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
