# Problem Statement

Alice and Bob play a game where they take turns removing stones from a pile. Alice goes first.

Rules:

- Alice must remove exactly `10` stones on her first turn.
- On every subsequent turn, a player must remove exactly `1` fewer stone than the previous opponent removed.
- A player who cannot make the required move loses.

Given an integer `n`, return `true` if Alice wins; otherwise, return `false`.

## Examples

**Example 1:**

    Input: n = 12
    Output: true

    Explanation:
    Alice removes 10 stones, leaving 2.
    Bob must remove 9 stones but cannot.
    Alice wins.

**Example 2:**

    Input: n = 1
    Output: false

    Explanation:
    Alice cannot remove 10 stones.
    Alice loses.

## Constraints

- `1 <= n <= 50`
