# Problem Statement

You are given a 2D integer array `items`, where:

- `items[i][0]` represents the factor of item `i`.
- `items[i][1]` represents the price of item `i`.

You are also given an integer `budget`.

There are unlimited copies of every item available.

After purchasing at least one copy of an item `i`, you receive one free copy of every item `j` satisfying:

- `j != i`
- `factor[i]` divides `factor[j]`

If multiple purchased item types give you the same item for free, you receive multiple free copies.

Return the maximum total number of items you can obtain, including purchased and free items, without exceeding the budget.

## Examples

**Example 1:**

    Input: items = [[6,2],[2,6],[3,4]], budget = 9
    Output: 4

    Explanation:
    Buy 2 copies of item 0 and 1 copy of item 2.

    Total spending = 2 * 2 + 4 = 8.

    Buying item 2 gives one free copy of item 0
    because 3 divides 6.

    Total items = 3 purchased + 1 free = 4.

**Example 2:**

    Input: items = [[2,4],[3,2],[4,1],[6,4],[12,4]], budget = 8
    Output: 10

    Explanation:
    Buy:
    - 1 copy of item 0.
    - 1 copy of item 1.
    - 2 copies of item 2.

    Total spending = 4 + 2 + 2 = 8.

    Free items:
    - Item 0 gives items 2, 3, 4.
    - Item 1 gives items 3, 4.
    - Item 2 gives item 4.

    Total = 4 purchased + 6 free = 10.

## Constraints

- `1 <= items.length <= 1000`
- `1 <= items[i][0], items[i][1] <= 1500`
- `1 <= budget <= 1500`

## C++ Solution

    class Solution {
    public:
        int maximumSaleItems(vector<vector<int>>& items, int budget) {
            int n = items.size();
    
            int minPrice = INT_MAX;
    
            for (auto& item : items) {
                minPrice = min(minPrice, item[1]);
            }
    
            // Calculate the reward for each item type.
            vector<int> reward(n, 1);
    
            for (int i = 0; i < n; i++) {
                int factor = items[i][0];
    
                for (int j = 0; j < n; j++) {
                    if (i != j && items[j][0] % factor == 0) {
                        reward[i]++;
                    }
                }
            }
    
            // 0/1 Knapsack DP.
            vector<int> dp(budget + 1, -1);
            dp[0] = 0;
    
            for (int i = 0; i < n; i++) {
                int cost = items[i][1];
    
                for (int c = budget; c >= cost; c--) {
                    if (dp[c - cost] != -1) {
                        dp[c] = max(
                            dp[c],
                            dp[c - cost] + reward[i]
                        );
                    }
                }
            }
    
            // Buy additional copies of the cheapest item.
            int ans = 0;
    
            for (int c = 0; c <= budget; c++) {
                if (dp[c] == -1) continue;
    
                int remaining = budget - c;
                int total = dp[c] + remaining / minPrice;
    
                ans = max(ans, total);
            }
    
            return ans;
        }
    };
