## Problem statement 

You are given an integer array `coins` representing coins of different denominations and an integer `k`.

You have an infinite number of coins of each denomination. However, you are **not allowed to combine coins of different denominations**.

For each denomination `c`, you can make:

    c, 2c, 3c, 4c, ...

The same amount may be produced by multiple denominations, but it should only be counted **once**.

Return the `k`th **smallest distinct amount** that can be made.

---

## Example 1

**Input:**

    coins = [3,6,9]
    k = 3

**Output:**

    9

### Explanation

Coin `3` can produce:

    3, 6, 9, 12, 15, ...

Coin `6` can produce:

    6, 12, 18, 24, ...

Coin `9` can produce:

    9, 18, 27, 36, ...

The distinct amounts in sorted order are:

    3, 6, 9, 12, 15, ...

Therefore, the 3rd smallest amount is:

    9

---

## Example 2

**Input:**

    coins = [5,2]
    k = 7

**Output:**

    12

### Explanation

Multiples of `5`:

    5, 10, 15, 20, ...

Multiples of `2`:

    2, 4, 6, 8, 10, 12, 14, ...

The distinct amounts in sorted order are:

    2, 4, 5, 6, 8, 10, 12, 14, 15, ...

The 7th smallest amount is:

    12

---

## Constraints

- `1 <= coins.length <= 15`
- `1 <= coins[i] <= 25`
- `1 <= k <= 2 * 10^9`
- `coins` contains pairwise distinct integers.

---


# Python Solution

    from math import gcd
    from functools import reduce

    class Solution:
        def findKthSmallest(self, coins, k):
            n = len(coins)

            def count(x):
                total = 0

                # Iterate through every non-empty subset.
                for mask in range(1, 1 << n):
                    lcm = 1
                    bits = 0
                    valid = True

                    for i in range(n):
                        if mask & (1 << i):
                            bits += 1

                            g = gcd(lcm, coins[i])
                            lcm = lcm // g * coins[i]

                            # This subset contributes nothing.
                            if lcm > x:
                                valid = False
                                break

                    if not valid:
                        continue

                    multiples = x // lcm

                    if bits % 2 == 1:
                        total += multiples
                    else:
                        total -= multiples

                return total

            low = 1
            high = min(coins) * k

            while low < high:
                mid = (low + high) // 2

                if count(mid) >= k:
                    high = mid
                else:
                    low = mid + 1

            return low
