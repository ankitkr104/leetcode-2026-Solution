## Problem Statement

Alice and Bob play a game with a pile containing `n` stones.

- Alice plays first.
- On each turn, a player can remove **any non-zero perfect square number** of stones.
- A player who cannot make a move loses.
- Both players play optimally.

Return `true` if Alice can win; otherwise return `false`.

---

## Example 1

```text
Input

n = 1
```

Output

```text
true
```

### Explanation

Alice can remove

```text
1 = 1²
```

stones.

The pile becomes empty, so Bob cannot make a move.

Therefore, Alice wins.

---

## Example 2

```text
Input

n = 2
```

Output

```text
false
```

### Explanation

Alice can only remove `1`.

```text
2 → 1
```

Bob removes the remaining `1`.

```text
1 → 0
```

Alice has no move left, so Bob wins.

---

## Example 3

```text
Input

n = 4
```

Output

```text
true
```

### Explanation

`4` is a perfect square:

```text
4 = 2²
```

Alice can remove all 4 stones immediately.

```text
4 → 0
```

Bob cannot move, so Alice wins.

---

## Constraints

```text
1 <= n <= 10^5
```
