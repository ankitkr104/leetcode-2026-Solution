## Problem Statement

You are given an integer array `nums` of length `n` and an integer `k`.

For each index `i`, define its **instability score** as:

    max(nums[0..i]) - min(nums[i..n - 1])

where:

- `max(nums[0..i])` is the largest value from index `0` to `i`.
- `min(nums[i..n-1])` is the smallest value from index `i` to `n-1`.

An index `i` is called **stable** if its instability score is less than or equal to `k`.

Return the **smallest stable index**.

If no stable index exists, return `-1`.

---

## Examples

### Example 1

Input:

    nums = [5,0,1,4]
    k = 3

Output:

    3

Explanation:

- Index 0: `5 - 0 = 5`
- Index 1: `5 - 0 = 5`
- Index 2: `5 - 1 = 4`
- Index 3: `5 - 4 = 1`

The first score that is `<= 3` occurs at index `3`.

---

### Example 2

Input:

    nums = [3,2,1]
    k = 1

Output:

    -1

Explanation:

- Index 0: `3 - 1 = 2`
- Index 1: `3 - 1 = 2`
- Index 2: `3 - 1 = 2`

No index has an instability score `<= 1`.

---

### Example 3

Input:

    nums = [0]
    k = 0

Output:

    0

Explanation:

At index `0`:

    max([0]) - min([0]) = 0

Since `0 <= k`, index `0` is stable.

---

## Approach

We need two pieces of information for every index:

1. The maximum value from the beginning up to that index.
2. The minimum value from that index to the end.

We can calculate both in `O(n)` time.

### Step 1: Build Suffix Minimum

Create an array `suffix_min` where:

    suffix_min[i] = min(nums[i], nums[i+1], ..., nums[n-1])

Start from the end and keep track of the minimum.

For:

    nums = [5,0,1,4]

we get:

    suffix_min = [0,0,1,4]

---

### Step 2: Scan From Left to Right

Maintain `prefix_max`, which represents:

    max(nums[0..i])

For every index:

    instability = prefix_max - suffix_min[i]

If:

    instability <= k

then `i` is stable.

Because we scan from left to right, the first valid index is automatically the smallest stable index.

---

## Algorithm

1. Let `n = len(nums)`.
2. Create an array `suffix_min` of size `n`.
3. Set `suffix_min[n-1] = nums[n-1]`.
4. Traverse from right to left and calculate every suffix minimum.
5. Initialize `prefix_max = nums[0]`.
6. Traverse from left to right.
7. Update `prefix_max`.
8. Calculate:
   
       prefix_max - suffix_min[i]

9. If the value is `<= k`, return `i`.
10. If no index satisfies the condition, return `-1`.
