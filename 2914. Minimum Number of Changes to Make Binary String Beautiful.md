# Problem Statement

You are given an even-length binary string `s`.

A string is called **beautiful** if it can be partitioned into one or more substrings such that:

- Every substring has an even length.
- Every substring contains only `0`s or only `1`s.

You can change any character from `0` to `1` or vice versa.

Return the minimum number of changes required to make `s` beautiful.

## Examples

**Example 1:**

    Input: s = "1001"
    Output: 2

    Explanation:
    Change s[1] to '1' and s[3] to '0'.
    The resulting string is "1100".
    Partition: "11" | "00".

**Example 2:**

    Input: s = "10"
    Output: 1

    Explanation:
    Change s[1] to '1'.
    The resulting string is "11".

**Example 3:**

    Input: s = "0000"
    Output: 0

    Explanation:
    The string is already beautiful.

## Constraints

- `2 <= s.length <= 10^5`
- `s.length` is even.
- `s[i]` is either `'0'` or `'1'`.
