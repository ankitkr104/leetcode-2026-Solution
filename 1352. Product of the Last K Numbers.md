# Problem Statement

Design an algorithm that accepts a stream of integers and retrieves the product of the last `k` integers in the stream.

Implement the `ProductOfNumbers` class:

- `ProductOfNumbers()` initializes the object.
- `void add(int num)` appends `num` to the stream.
- `int getProduct(int k)` returns the product of the last `k` numbers.

You can assume the product of any contiguous sequence of numbers fits into a 32-bit integer.

## Examples

    Input:
    ["ProductOfNumbers", "add", "add", "add", "add", "add",
     "getProduct", "getProduct", "getProduct", "add", "getProduct"]

    [[], [3], [0], [2], [5], [4], [2], [3], [4], [8], [2]]

    Output:
    [null, null, null, null, null, null, 20, 40, 0, null, 32]

**Explanation:**

    ProductOfNumbers productOfNumbers = new ProductOfNumbers();

    productOfNumbers.add(3);         // [3]
    productOfNumbers.add(0);         // [3,0]
    productOfNumbers.add(2);         // [3,0,2]
    productOfNumbers.add(5);         // [3,0,2,5]
    productOfNumbers.add(4);         // [3,0,2,5,4]

    productOfNumbers.getProduct(2);  // 20
    productOfNumbers.getProduct(3);  // 40
    productOfNumbers.getProduct(4);  // 0

    productOfNumbers.add(8);         // [3,0,2,5,4,8]
    productOfNumbers.getProduct(2);  // 32

## Constraints

- `0 <= num <= 100`
- `1 <= k <= 4 * 10^4`
- At most `4 * 10^4` calls will be made to `add` and `getProduct`.
- The product of the stream at any point in time will fit in a 32-bit integer.
