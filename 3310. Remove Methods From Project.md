# Problem Statement

You are maintaining a project with `n` methods numbered from `0` to `n - 1`.

You are given:

- An integer `k`, representing a known buggy method.
- A list `invocations`, where

```text
[a, b]
```

means method `a` invokes method `b`.

A method is **suspicious** if:

- It is method `k`, or
- It is directly or indirectly invoked by `k`.

You want to remove **all suspicious methods**.

However, removal is only allowed if **no non-suspicious method invokes any suspicious method**.

Return the list of remaining methods after removing the suspicious ones.

If removal is impossible, return all methods.

---

## Example 1

```text
Input

n = 4

k = 1

invocations = [[1,2],[0,1],[3,2]]
```

Output

```text
[0,1,2,3]
```

### Explanation

Suspicious methods are

```text
1

2
```

But method

```text
0
```

calls

```text
1
```

and method

```text
3
```

calls

```text
2
```

Since non-suspicious methods invoke suspicious ones, removal is impossible.

---

## Example 2

```text
Input

n = 5

k = 0

invocations = [[1,2],[0,2],[0,1],[3,4]]
```

Output

```text
[3,4]
```

### Explanation

Suspicious methods are

```text
0

1

2
```

No outside method invokes them.

They can all be removed.

---

## Example 3

```text
Input

n = 3

k = 2

invocations = [[1,2],[0,1],[2,0]]
```

Output

```text
[]
```

### Explanation

All methods become suspicious.

Removing all methods is allowed.

---

## Constraints

```text
1 <= n <= 100000

0 <= k < n

0 <= invocations.length <= 200000
```

---
# Python3 Solution

```python
from typing import List
from collections import deque

class Solution:
    def remainingMethods(self, n: int, k: int, invocations: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]

        for u, v in invocations:
            graph[u].append(v)

        suspicious = [False] * n

        q = deque([k])
        suspicious[k] = True

        while q:
            node = q.popleft()

            for nxt in graph[node]:
                if not suspicious[nxt]:
                    suspicious[nxt] = True
                    q.append(nxt)

        for u, v in invocations:
            if not suspicious[u] and suspicious[v]:
                return list(range(n))

        return [i for i in range(n) if not suspicious[i]]
```
