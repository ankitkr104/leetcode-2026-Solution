# Problem Statement

You are given a rooted tree with `n` nodes numbered from `0` to `n - 1`.

The tree is represented by the array `parent`, where `parent[i]` is the parent of node `i`. Node `0` is the root and `parent[0] = -1`.

You are also given a string `s`, where `s[i]` represents the character assigned to node `i`.

For every node `x` from `1` to `n - 1`, simultaneously:

- Find the closest ancestor `y` of `x` such that `s[x] == s[y]`.
- If such an ancestor exists, change the parent of `x` to `y`.
- Otherwise, its parent remains unchanged.

Return an array `answer` where `answer[i]` is the subtree size of node `i` in the final tree.

## Examples

**Example 1:**

    Input: parent = [-1,0,0,1,1,1], s = "abaabc"
    Output: [6,3,1,1,1,1]

    Explanation:
    The parent of node 3 changes from node 1 to node 0.
    The final subtree sizes are [6,3,1,1,1,1].

**Example 2:**

    Input: parent = [-1,0,4,0,1], s = "abbba"
    Output: [5,2,1,1,1]

    Explanation:
    The following changes happen simultaneously:
    - Node 4 changes its parent from node 1 to node 0.
    - Node 2 changes its parent from node 4 to node 1.

    The final subtree sizes are [5,2,1,1,1].

## Constraints

- `n == parent.length == s.length`
- `1 <= n <= 10^5`
- `0 <= parent[i] <= n - 1` for all `i >= 1`
- `parent[0] == -1`
- `parent` represents a valid tree.
- `s` consists of lowercase English letters.

## C++ Solution

    class Solution {
    public:
        vector<int> answer;

        void dfsOriginal(int u, vector<vector<int>>& tree,
                         string& s, vector<int>& newParent,
                         vector<int>& last) {

            int c = s[u] - 'a';
            int previous = last[c];

            if (u != 0 && previous != -1) {
                newParent[u] = previous;
            }

            last[c] = u;

            for (int v : tree[u]) {
                dfsOriginal(v, tree, s, newParent, last);
            }

            // Restore the ancestor state for this DFS path.
            last[c] = previous;
        }

        int dfsFinal(int u, vector<vector<int>>& tree) {
            int size = 1;

            for (int v : tree[u]) {
                size += dfsFinal(v, tree);
            }

            answer[u] = size;
            return size;
        }

        vector<int> findSubtreeSizes(vector<int>& parent, string s) {
            int n = parent.size();

            vector<vector<int>> original(n);

            for (int i = 1; i < n; i++) {
                original[parent[i]].push_back(i);
            }

            vector<int> newParent = parent;
            vector<int> last(26, -1);

            dfsOriginal(0, original, s, newParent, last);

            // Construct the final tree.
            vector<vector<int>> finalTree(n);

            for (int i = 1; i < n; i++) {
                finalTree[newParent[i]].push_back(i);
            }

            answer.assign(n, 0);

            dfsFinal(0, finalTree);

            return answer;
        }
    };
