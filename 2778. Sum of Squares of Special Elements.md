# Problem Statement

You are given a **1-indexed integer array** `nums` of length `n`.

An element `nums[i]` is called **special** if its index `i` divides `n` evenly.

In other words:

    n % i == 0

Return the sum of the squares of all special elements.

**Note:** The problem uses 1-based indexing, but C++ arrays use 0-based indexing. Therefore, the element at index `i` in the problem corresponds to `nums[i - 1]` in C++.

---

## Examples

### Example 1

Input:

    nums = [1,2,3,4]

Output:

    21

Explanation:

The array length is:

    n = 4

The special indices are `1`, `2`, and `4`, because each divides `4` evenly.

Their corresponding elements are:

    nums[0] = 1
    nums[1] = 2
    nums[3] = 4

Sum of squares:

    1² + 2² + 4²
    = 1 + 4 + 16
    = 21

---

### Example 2

Input:

    nums = [2,7,1,19,18,3]

Output:

    63

Explanation:

The array length is:

    n = 6

The special indices are `1`, `2`, `3`, and `6`.

Their corresponding elements are:

    2, 7, 1, 3

Sum of squares:

    2² + 7² + 1² + 3²
    = 4 + 49 + 1 + 9
    = 63

---

## Constraints

- `1 <= nums.length == n <= 50`
- `1 <= nums[i] <= 50`
