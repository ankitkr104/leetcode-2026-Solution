# Problem Statement

You are given an integer array `nums`.

Find the minimum length of a subarray that is not identical to any other subarray in the array.

Two subarrays are considered identical if:
- They have the same length.
- Their elements are equal at every corresponding position.

Return the minimum possible length of a unique subarray.

## Examples

**Example 1:**

    Input: nums = [3,3,3]
    Output: 3

    Explanation:
    Length 1: [3] appears 3 times.
    Length 2: [3,3] appears 2 times.
    Length 3: [3,3,3] appears once.

    The minimum unique subarray length is 3.

**Example 2:**

    Input: nums = [2,1,2,3,3]
    Output: 1

    Explanation:
    Length 1:
    [2] appears 2 times.
    [1] appears once.
    [3] appears 2 times.

    The subarray [1] is unique.

**Example 3:**

    Input: nums = [1,1,2,2,1]
    Output: 2

    Explanation:
    Length 1: Every value appears more than once.
    Length 2: Subarrays [1,1], [1,2], [2,2], and [2,1]
    each appear only once.

    The minimum unique subarray length is 2.

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## C++ Solution

    using ll = long long;
    
    class Solution {
    public:
        int smallestUniqueSubarray(vector<int>& nums) {
            constexpr ll MOD = 1000000007LL;
            constexpr ll BASE = 911382323LL;
    
            int n = (int)nums.size();
            vector<ll> h(n + 1);
            vector<ll> p(n + 1);
            p[0] = 1;
    
            // Compute prefix hashes and powers of BASE
            for (int i = 0; i < n; ++i) {
                h[i + 1] = (h[i] * BASE + nums[i]) % MOD;
                p[i + 1] = p[i] * BASE % MOD;
            }
    
            auto check = [&](int len) {
                unordered_map<ll, int> cnt;
    
                for (int l = 0; l + len <= n; ++l) {
                    int r = l + len;
    
                    ll key = (h[r] - h[l] * p[len] % MOD + MOD) % MOD;
                    ++cnt[key];
                }
    
                for (auto& [key, times] : cnt) {
                    if (times == 1) {
                        return true;
                    }
                }
                return false;
            };
    
            int lo = 1, hi = n;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
    
                if (check(mid)) {
                    hi = mid;
                } else {
                    lo = mid + 1;
                }
            }
    
            return lo;
        }
    };
