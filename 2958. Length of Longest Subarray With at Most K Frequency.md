## Problem

You are given an integer array `nums` and an integer `k`.

The **frequency** of an element `x` is the number of times it occurs in an array.

An array is called **good** if the frequency of each element in this array is **less than or equal to `k`**.

Return the length of the **longest good subarray** of `nums`.

A **subarray** is a contiguous non-empty sequence of elements within `nums`.

---

## Example 1

**Input:**
`nums = [1,2,3,1,2,3,1,2]`  
`k = 2`

**Output:**
`6`

**Explanation:**

The longest possible good subarray is:

`[1,2,3,1,2,3]`

Each value occurs at most twice:

- `1` → 2 times
- `2` → 2 times
- `3` → 2 times

Therefore, the answer is `6`.

---

## Example 2

**Input:**
`nums = [1,2,1,2,1,2,1,2]`  
`k = 1`

**Output:**
`2`

**Explanation:**

Every element can occur at most once.

A longest valid subarray is:

`[1,2]`

or:

`[2,1]`

Therefore, the answer is `2`.

---

## Example 3

**Input:**
`nums = [5,5,5,5,5,5,5]`  
`k = 4`

**Output:**
`4`

**Explanation:**

The value `5` can occur at most four times.

Therefore, the longest good subarray is:

`[5,5,5,5]`

So the answer is `4`.

---

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= nums.length`
