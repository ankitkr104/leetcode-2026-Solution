# Problem Statement

Given a balanced parentheses string `s`, return its **score**.

The score is defined using these rules:

- `"()"` has score `1`.
- `AB` has score `A + B`, where `A` and `B` are balanced parentheses strings.
- `(A)` has score `2 * A`, where `A` is a balanced parentheses string.

---

## Examples

### Example 1

Input:

    s = "()"

Output:

    1

Explanation:

    "()"

has score `1`.

---

### Example 2

Input:

    s = "(())"

Output:

    2

Explanation:

    "(())" = 2 * "()"

Therefore:

    2 * 1 = 2

---

### Example 3

Input:

    s = "()()"

Output:

    2

Explanation:

    "()()" = "()" + "()"

Therefore:

    1 + 1 = 2

---

## Constraints

- `2 <= s.length <= 50`
- `s` consists only of `'('` and `')'`.
- `s` is a balanced parentheses string.

---

## C++ Solution

    class Solution {
    public:
        int scoreOfParentheses(string s) {
            stack<int> st;

            // Score of the outermost level.
            st.push(0);

            for (char c : s) {

                if (c == '(') {
                    // Start a new nested level.
                    st.push(0);
                }
                else {
                    // Score inside the current pair.
                    int inner = st.top();
                    st.pop();

                    // "()" -> 1
                    // "(A)" -> 2 * A
                    int value = (inner == 0) ? 1 : 2 * inner;

                    // Add the score to the outer level.
                    st.top() += value;
                }
            }

            return st.top();
        }
    };
