# Problem Statement

You are given a string `s` and a positive integer `k`.

Select a set of **non-overlapping substrings** from `s` such that:

- The length of every substring is at least `k`.
- Every selected substring is a palindrome.
- The selected substrings do not overlap.

Return the **maximum number of substrings** that can be selected.

A substring is a contiguous sequence of characters within a string.

---

## Examples

### Example 1

Input:

    s = "abaccdbbd"
    k = 3

Output:

    2

Explanation:

We can select:

    "aba"
    "dbbd"

Both are palindromes and have length at least `3`.

They do not overlap, so the answer is:

    2

---

### Example 2

Input:

    s = "adbcda"
    k = 2

Output:

    0

Explanation:

There is no palindromic substring with length at least `2`.

Therefore:

    answer = 0

---

## Constraints

- `1 <= k <= s.length <= 2000`
- `s` consists of lowercase English letters.
