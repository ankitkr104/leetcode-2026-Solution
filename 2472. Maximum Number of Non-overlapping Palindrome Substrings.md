# Problem Statement

You are given a string `s` and a positive integer `k`.

Select a set of **non-overlapping substrings** from `s` such that:

- The length of every substring is at least `k`.
- Every selected substring is a palindrome.
- The selected substrings do not overlap.

Return the **maximum number of substrings** that can be selected.

A substring is a contiguous sequence of characters within a string.

---

## Examples

### Example 1

Input:

    s = "abaccdbbd"
    k = 3

Output:

    2

Explanation:

We can select:

    "aba"
    "dbbd"

Both are palindromes and have length at least `3`.

They do not overlap, so the answer is:

    2

---

### Example 2

Input:

    s = "adbcda"
    k = 2

Output:

    0

Explanation:

There is no palindromic substring with length at least `2`.

Therefore:

    answer = 0

---

## Constraints

- `1 <= k <= s.length <= 2000`
- `s` consists of lowercase English letters.

---

## C++ Solution

    class Solution {
    public:
        int maxPalindromes(string s, int k) {
            int n = s.size();

            // isPal[i][j] = true if s[i..j] is a palindrome
            vector<vector<bool>> isPal(n, vector<bool>(n, false));

            // Build palindrome table by increasing length
            for (int i = n - 1; i >= 0; i--) {
                for (int j = i; j < n; j++) {

                    if (s[i] == s[j] &&
                        (j - i <= 1 || isPal[i + 1][j - 1])) {
                        isPal[i][j] = true;
                    }
                }
            }

            // dp[i] = maximum number of valid palindromes
            // using the first i characters
            vector<int> dp(n + 1, 0);

            for (int i = 1; i <= n; i++) {

                // Don't select a palindrome ending at i-1
                dp[i] = dp[i - 1];

                for (int j = 0; j < i; j++) {

                    // Length must be at least k
                    if (i - j < k) {
                        continue;
                    }

                    if (isPal[j][i - 1]) {
                        dp[i] = max(dp[i], dp[j] + 1);
                    }
                }
            }

            return dp[n];
        }
    };
