# Problem Statement

You are given two positive integers `num` and `sum`.

A positive integer `n` is called **good** if it satisfies both conditions:

1. The number of digits in `n` is exactly `num`.
2. The sum of the digits in `n` is exactly `sum`.

The score of a good integer `n` is the sum of the squares of its digits.

Return a string representing the good integer with the maximum score. If multiple integers achieve the maximum score, return the largest integer among them.

If no such integer exists, return an empty string.

## Examples

### Example 1

**Input:**
    num = 2, sum = 3

**Output:**
    "30"

**Explanation:**

The good integers are `12`, `21`, and `30`.

- Score of `12`: 1² + 2² = 5
- Score of `21`: 2² + 1² = 5
- Score of `30`: 3² + 0² = 9

The maximum score is `9`, achieved by `30`.

### Example 2

**Input:**
    num = 2, sum = 17

**Output:**
    "98"

**Explanation:**

The good integers are `89` and `98`.

Both have a score of:

    8² + 9² = 145

Since `98` is larger than `89`, the answer is `"98"`.

### Example 3

**Input:**
    num = 1, sum = 10

**Output:**
    ""

**Explanation:**

A single digit cannot have a digit sum of `10`, so no good integer exists.

## Constraints

- `1 <= num <= 2 * 10^5`
- `1 <= sum <= 2 * 10^6`
