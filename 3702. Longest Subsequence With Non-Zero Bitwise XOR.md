# Problem Statement

You are given an integer array `nums`.

Return the length of the **longest subsequence** in `nums` whose bitwise **XOR is non-zero**.

If no such subsequence exists, return `0`.

A subsequence can be obtained by deleting some or no elements from the array while keeping the remaining elements in their original order.

---

## Example 1

**Input:** `nums = [1,2,3]`

**Output:** `2`

**Explanation:**

One longest subsequence is `[2,3]`.

Its bitwise XOR is:

`2 XOR 3 = 1`

Since the XOR is non-zero, this is a valid subsequence.

The complete array has:

`1 XOR 2 XOR 3 = 0`

so we cannot use all three elements.

Therefore, the answer is `2`.

---

## Example 2

**Input:** `nums = [2,3,4]`

**Output:** `3`

**Explanation:**

The XOR of the complete array is:

`2 XOR 3 XOR 4 = 5`

Since `5` is non-zero, the entire array is a valid subsequence.

Therefore, the answer is `3`.

---

## Constraints

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

---

## Python3 Solution

    class Solution:
        def longestSubsequence(self, nums: list[int]) -> int:
            total_xor = 0

            for num in nums:
                total_xor ^= num

            if total_xor != 0:
                return len(nums)

            for num in nums:
                if num != 0:
                    return len(nums) - 1

            return 0
