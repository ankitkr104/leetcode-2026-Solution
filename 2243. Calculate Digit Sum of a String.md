# Problem Statement
You are given a digit string `s` and an integer `k`.

While the length of `s` is greater than `k`, perform the following operations:

1. Divide `s` into consecutive groups of size `k`. The last group may contain fewer than `k` characters.
2. Calculate the sum of digits in each group.
3. Replace each group with its digit sum represented as a string.
4. Merge all resulting strings to form the new `s`.

Repeat until the length of `s` becomes less than or equal to `k`.

Return the final string.

## Examples

**Example 1:**
- Input: `s = "11111222223", k = 3`
- Output: `"135"`
- Explanation:
  - First round: `"111"`, `"112"`, `"222"`, `"23"` → `"3465"`
  - Second round: `"346"`, `"5"` → `"135"`
  - Since the length is now 3, return `"135"`.

**Example 2:**
- Input: `s = "00000000", k = 3`
- Output: `"000"`
- Explanation:
  - Groups: `"000"`, `"000"`, `"00"`
  - Their digit sums are `0`, `0`, and `0`.
  - The resulting string is `"000"`.

## Constraints
- `1 <= s.length <= 100`
- `2 <= k <= 100`
- `s` consists of digits only.

## C++ Solution

    class Solution {
    public:
        string digitSum(string s, int k) {
            while (s.length() > k) {
                string next = "";

                for (int i = 0; i < s.length(); i += k) {
                    int sum = 0;

                    for (int j = i; j < min((int)s.length(), i + k); j++) {
                        sum += s[j] - '0';
                    }

                    next += to_string(sum);
                }

                s = next;
            }

            return s;
        }
    };
