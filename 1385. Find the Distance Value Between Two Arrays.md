# Problem Statement

Given two integer arrays `arr1` and `arr2`, and an integer `d`, return the **distance value between the two arrays**.

The distance value is defined as the number of elements `arr1[i]` such that there does not exist any element `arr2[j]` satisfying:

    |arr1[i] - arr2[j]| <= d

In other words, count the elements in `arr1` whose absolute difference from every element in `arr2` is strictly greater than `d`.

## Examples

### Example 1

**Input:**
    arr1 = [4, 5, 8]
    arr2 = [10, 9, 1, 8]
    d = 2

**Output:**
    2

**Explanation:**

- For `arr1[0] = 4`, every difference is greater than `2`.
- For `arr1[1] = 5`, every difference is greater than `2`.
- For `arr1[2] = 8`, there are elements in `arr2` within distance `2`.

Therefore, the answer is `2`.

### Example 2

**Input:**
    arr1 = [1, 4, 2, 3]
    arr2 = [-4, -3, 6, 10, 20, 30]
    d = 3

**Output:**
    2

### Example 3

**Input:**
    arr1 = [2, 1, 100, 3]
    arr2 = [-5, -2, 10, -3, 7]
    d = 6

**Output:**
    1

## Constraints

- `1 <= arr1.length, arr2.length <= 500`
- `-1000 <= arr1[i], arr2[j] <= 1000`
- `0 <= d <= 100`

## C++ Solution

    class Solution {
    public:
        int findTheDistanceValue(vector<int>& arr1,
                                 vector<int>& arr2, int d) {
            int ans = 0;

            for (int num : arr1) {
                bool valid = true;

                for (int x : arr2) {
                    if (abs(num - x) <= d) {
                        valid = false;
                        break;
                    }
                }

                if (valid) {
                    ans++;
                }
            }

            return ans;
        }
    };
