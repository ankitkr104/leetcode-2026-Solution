# Problem Statement

Given a string `s` containing lowercase English letters and parentheses, remove the **minimum number of invalid parentheses** to make the resulting string valid.

Return all **unique valid strings** that can be obtained using the minimum number of removals.

The answer can be returned in any order.

Letters do not affect whether the parentheses are valid.

---

## Examples

### Example 1

Input:

    s = "()())()"

Output:

    ["(())()","()()()"]

Explanation:

Removing one `)` gives either:

    "(())()"

or:

    "()()()"

Both are valid, and only one removal is required.

---

### Example 2

Input:

    s = "(a)())()"

Output:

    ["(a())()","(a)()()"]

Explanation:

Removing one invalid `)` produces either valid string.

---

### Example 3

Input:

    s = ")("

Output:

    [""]

Explanation:

Both parentheses are invalid, so both must be removed.

---

## Constraints

- `1 <= s.length <= 25`
- `s` consists of lowercase English letters and parentheses `(` and `)`.
- There are at most `20` parentheses in `s`.

---

## C++ Solution

    class Solution {
    public:
        bool isValid(const string& s) {
            int balance = 0;

            for (char c : s) {
                if (c == '(') {
                    balance++;
                }
                else if (c == ')') {
                    balance--;

                    // More ')' than '(' in a prefix.
                    if (balance < 0) {
                        return false;
                    }
                }
            }

            // All '(' must be matched.
            return balance == 0;
        }

        vector<string> removeInvalidParentheses(string s) {
            vector<string> answer;

            queue<string> q;
            unordered_set<string> visited;

            q.push(s);
            visited.insert(s);

            bool found = false;

            while (!q.empty() && !found) {
                int size = q.size();

                while (size--) {
                    string current = q.front();
                    q.pop();

                    // If valid, this is a minimum-removal solution.
                    if (isValid(current)) {
                        answer.push_back(current);
                        found = true;
                    }

                    // Do not generate the next level once
                    // a valid string has been found.
                    if (found) {
                        continue;
                    }

                    // Remove one parenthesis at every possible position.
                    for (int i = 0; i < current.size(); i++) {

                        if (current[i] != '(' && current[i] != ')') {
                            continue;
                        }

                        string next = current.substr(0, i)
                                    + current.substr(i + 1);

                        if (!visited.count(next)) {
                            visited.insert(next);
                            q.push(next);
                        }
                    }
                }
            }

            return answer;
        }
    };
