# Problem Statement

Alice and Bob are playing a game with an **even number** of piles of stones.

- `piles[i]` represents the number of stones in the `i-th` pile.
- Alice always plays first.
- On each turn, a player removes the **entire leftmost or rightmost pile**.
- The game continues until all piles have been taken.
- The player with the **most stones wins**.

It is guaranteed that:

- The number of piles is even.
- The total number of stones is odd, so a tie is impossible.

Return

```text
true
```

if Alice wins assuming both players play optimally; otherwise return

```text
false
```

---

## Example 1

```text
Input

piles = [5,3,4,5]
```

Output

```text
true
```

### Explanation

Alice picks the leftmost `5`.

No matter what Bob chooses next, Alice can always secure more stones and win.

---

## Example 2

```text
Input

piles = [3,7,2,3]
```

Output

```text
true
```

---

## Constraints

```text
2 <= piles.length <= 500

piles.length is even.

1 <= piles[i] <= 500

sum(piles) is odd.
```
