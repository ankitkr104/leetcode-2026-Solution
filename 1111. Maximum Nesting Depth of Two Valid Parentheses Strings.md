# Problem Statement

A valid parentheses string (VPS) consists only of `(` and `)` and follows the rules:
 cdc d 
- The empty string is valid.
- If `A` and `B` are valid, then `AB` is valid.
- If `A` is valid, then `(A)` is valid.

The **nesting depth** of a valid parentheses string is the maximum number of simultaneously open parentheses.

Given a valid parentheses string `seq`, split its characters into two disjoint subsequences `A` and `B` such that:

- Both `A` and `B` are valid parentheses strings.
- Every character belongs to exactly one of them.
- `A.length + B.length = seq.length`.
- `max(depth(A), depth(B))` is minimized.

Return an array `answer` where:

- `answer[i] = 0` means `seq[i]` belongs to `A`.
- `answer[i] = 1` means `seq[i]` belongs to `B`.

Any optimal answer is acceptable.

---

## Examples

### Example 1

Input:

    seq = "(()())"

Output:

    [0,1,1,1,1,0]

The characters are divided between the two subsequences so that both remain valid and their maximum nesting depth is minimized.

---

### Example 2

Input:

    seq = "()(())()"

Output:

    [0,0,0,1,1,0,1,1]

Again, both resulting subsequences are valid parentheses strings.

---

## Constraints

- `1 <= seq.size <= 10000`
- `seq` is a valid parentheses string.

---

## C++ Solution

    class Solution {
    public:
        vector<int> maxDepthAfterSplit(string seq) {
            vector<int> answer(seq.size());

            int depth = 0;

            for (int i = 0; i < seq.size(); i++) {
                if (seq[i] == '(') {
                    depth++;

                    // Alternate between group 0 and group 1.
                    answer[i] = depth % 2;
                } else {
                    // Closing parenthesis belongs to the same
                    // group as its matching opening parenthesis.
                    answer[i] = depth % 2;

                    depth--;
                }
            }

            return answer;
        }
    };
