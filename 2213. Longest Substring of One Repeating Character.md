# Problem Statement

You are given a **0-indexed** string `s`. You are also given a **0-indexed** string `queryCharacters` of length `k` and a **0-indexed** array of integers `queryIndices` of length `k`.

Both arrays describe `k` queries.

The `i-th` query updates the character in `s` at index `queryIndices[i]` to the character `queryCharacters[i]`.

After each query, return the length of the **longest substring** of `s` consisting of only one repeating character.

Return an array `lengths` of length `k`, where `lengths[i]` is the length of the longest repeating-character substring after the `i-th` query.

---

## Example 1

### Input

```text
s = "babacc"
queryCharacters = "bcb"
queryIndices = [1,3,3]
```

### Output

```text
[3,3,4]
```

### Explanation

- After the 1st query:

```text
s = "bbbacc"
```

The longest repeating substring is `"bbb"` with length `3`.

- After the 2nd query:

```text
s = "bbbccc"
```

The longest repeating substring can be `"bbb"` or `"ccc"`, both having length `3`.

- After the 3rd query:

```text
s = "bbbbcc"
```

The longest repeating substring is `"bbbb"` with length `4`.

Therefore:

```text
[3,3,4]
```

---

## Example 2

### Input

```text
s = "abyzz"
queryCharacters = "aa"
queryIndices = [2,1]
```

### Output

```text
[2,3]
```

### Explanation

After the 1st query:

```text
s = "abazz"
```

The longest repeating substring is `"zz"` with length `2`.

After the 2nd query:

```text
s = "aaazz"
```

The longest repeating substring is `"aaa"` with length `3`.

Therefore:

```text
[2,3]
```

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
- `k == queryCharacters.length == queryIndices.length`
- `1 <= k <= 10^5`
- `queryCharacters` consists of lowercase English letters.
- `0 <= queryIndices[i] < s.length`
