# Problem Statement

You are given a **0-indexed** string `s`. You are also given a **0-indexed** string `queryCharacters` of length `k` and a **0-indexed** array of integers `queryIndices` of length `k`.

Both arrays describe `k` queries.

The `i-th` query updates the character in `s` at index `queryIndices[i]` to the character `queryCharacters[i]`.

After each query, return the length of the **longest substring** of `s` consisting of only one repeating character.

Return an array `lengths` of length `k`, where `lengths[i]` is the length of the longest repeating-character substring after the `i-th` query.

---

## Example 1

### Input

```text
s = "babacc"
queryCharacters = "bcb"
queryIndices = [1,3,3]
```

### Output

```text
[3,3,4]
```

### Explanation

- After the 1st query:

```text
s = "bbbacc"
```

The longest repeating substring is `"bbb"` with length `3`.

- After the 2nd query:

```text
s = "bbbccc"
```

The longest repeating substring can be `"bbb"` or `"ccc"`, both having length `3`.

- After the 3rd query:

```text
s = "bbbbcc"
```

The longest repeating substring is `"bbbb"` with length `4`.

Therefore:

```text
[3,3,4]
```

---

## Example 2

### Input

```text
s = "abyzz"
queryCharacters = "aa"
queryIndices = [2,1]
```

### Output

```text
[2,3]
```

### Explanation

After the 1st query:

```text
s = "abazz"
```

The longest repeating substring is `"zz"` with length `2`.

After the 2nd query:

```text
s = "aaazz"
```

The longest repeating substring is `"aaa"` with length `3`.

Therefore:

```text
[2,3]
```

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
- `k == queryCharacters.length == queryIndices.length`
- `1 <= k <= 10^5`
- `queryCharacters` consists of lowercase English letters.
- `0 <= queryIndices[i] < s.length`

---

# Python3 Solution

```python
from typing import List


class SegmentTree:
    def __init__(self, s):
        self.n = len(s)
        self.tree = [None] * (4 * self.n)
        self.s = s

        self.build(1, 0, self.n - 1)

    def build(self, node, left, right):
        if left == right:
            ch = self.s[left]
            self.tree[node] = (ch, ch, 1, 1, 1, 1)
            return

        mid = (left + right) // 2

        self.build(node * 2, left, mid)
        self.build(node * 2 + 1, mid + 1, right)

        self.tree[node] = self.merge(
            self.tree[node * 2],
            self.tree[node * 2 + 1]
        )

    def merge(self, a, b):
        left_char_a, right_char_a, prefix_a, suffix_a, best_a, length_a = a
        left_char_b, right_char_b, prefix_b, suffix_b, best_b, length_b = b

        left_char = left_char_a
        right_char = right_char_b

        prefix = prefix_a
        suffix = suffix_b

        if prefix_a == length_a and right_char_a == left_char_b:
            prefix = length_a + prefix_b

        if suffix_b == length_b and right_char_a == left_char_b:
            suffix = length_b + suffix_a

        best = max(best_a, best_b)

        if right_char_a == left_char_b:
            best = max(best, suffix_a + prefix_b)

        length = length_a + length_b

        return (
            left_char,
            right_char,
            prefix,
            suffix,
            best,
            length
        )

    def update(self, index, ch):
        self._update(1, 0, self.n - 1, index, ch)

    def _update(self, node, left, right, index, ch):
        if left == right:
            self.tree[node] = (ch, ch, 1, 1, 1, 1)
            return

        mid = (left + right) // 2

        if index <= mid:
            self._update(node * 2, left, mid, index, ch)
        else:
            self._update(node * 2 + 1, mid + 1, right, index, ch)

        self.tree[node] = self.merge(
            self.tree[node * 2],
            self.tree[node * 2 + 1]
        )

    def get_best(self):
        return self.tree[1][4]


class Solution:
    def longestRepeating(
        self,
        s: str,
        queryCharacters: str,
        queryIndices: List[int]
    ) -> List[int]:

        seg = SegmentTree(s)

        ans = []

        for ch, index in zip(queryCharacters, queryIndices):
            seg.update(index, ch)
            ans.append(seg.get_best())

        return ans
```
