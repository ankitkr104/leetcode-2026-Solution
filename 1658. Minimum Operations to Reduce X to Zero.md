# Problem Statement

You are given an integer array `nums` and an integer `x`.

In one operation, you can remove either:

- The leftmost element, or
- The rightmost element

and subtract its value from `x`.

Return the **minimum number of operations** needed to reduce `x` to exactly `0`.

If it is impossible, return `-1`.

---

## Examples

### Example 1

    Input:
    nums = [1,1,4,2,3]
    x = 5

    Output:
    2

Explanation:

Remove the last two elements:

    3 + 2 = 5

So the answer is:

    2

---

### Example 2

    Input:
    nums = [5,6,7,8,9]
    x = 4

    Output:
    -1

Explanation:

Every element is greater than `4`, so it is impossible to reduce `x` to exactly `0`.

---

### Example 3

    Input:
    nums = [3,2,20,1,1,3]
    x = 10

    Output:
    5

Explanation:

Remove:

    3 + 2

from the left and:

    3 + 1 + 1

from the right.

Total removed:

    3 + 2 + 3 + 1 + 1 = 10

Number of operations:

    5

---

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
- `1 <= x <= 10^9`
