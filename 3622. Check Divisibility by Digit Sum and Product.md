## Problem Statement 

You are given a positive integer `n`.

Determine whether `n` is divisible by the **sum of the following two values**:

1. The **digit sum** of `n`.
2. The **digit product** of `n`.

Return `true` if `n` is divisible by this sum; otherwise, return `false`.

In other words:

    digitSum = sum of all digits of n
    digitProduct = product of all digits of n

We need to check:

    n % (digitSum + digitProduct) == 0

---

## Example 1

**Input:**

    n = 99

**Output:**

    true

### Explanation

The digits are:

    9, 9

Digit sum:

    9 + 9 = 18

Digit product:

    9 * 9 = 81

Their sum is:

    18 + 81 = 99

Now check:

    99 % 99 == 0

Therefore:

    true

---

## Example 2

**Input:**

    n = 23

**Output:**

    false

### Explanation

The digits are:

    2, 3

Digit sum:

    2 + 3 = 5

Digit product:

    2 * 3 = 6

Their sum is:

    5 + 6 = 11

Now check:

    23 % 11 != 0

Therefore:

    false

---

## Constraints

- `1 <= n <= 10^6`
