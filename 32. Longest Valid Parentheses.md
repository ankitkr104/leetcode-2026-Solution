# Problem Statement

Given a string `s` containing only `'('` and `')'`, return the length of the **longest valid (well-formed) parentheses substring**.

A valid parentheses substring must have:

- Matching opening and closing parentheses.
- Correct ordering of parentheses.

The substring must be **contiguous**.

---

## Examples

### Example 1

Input:

    s = "(()"

Output:

    2

Explanation:

The longest valid parentheses substring is:

    "()"

Its length is `2`.

---

### Example 2

Input:

    s = ")()())"

Output:

    4

Explanation:

The longest valid parentheses substring is:

    "()()"

Its length is `4`.

---

### Example 3

Input:

    s = ""

Output:

    0

---

## Constraints

- `0 <= s.length <= 3 * 10^4`
- `s[i]` is either `'('` or `')'`.

---

## C++ Solution

    class Solution {
    public:
        int longestValidParentheses(string s) {
            stack<int> st;

            // Boundary before the beginning of the string.
            st.push(-1);

            int answer = 0;

            for (int i = 0; i < s.size(); i++) {

                if (s[i] == '(') {
                    // Store the index of an opening bracket.
                    st.push(i);
                } else {
                    // Try to match the current closing bracket.
                    st.pop();

                    if (st.empty()) {
                        // Current ')' cannot be matched.
                        // It becomes the new boundary.
                        st.push(i);
                    } else {
                        // The valid substring starts after st.top().
                        answer = max(answer, i - st.top());
                    }
                }
            }

            return answer;
        }
    };
