## Problem tatement 

Alice and Bob play a game with `n` stones arranged in a row.

Alice starts first.

While there is more than one stone remaining, the current player performs the following operation:

1. Choose an integer `x > 1`.
2. Remove the **leftmost `x` stones**.
3. Add the sum of the removed stones to the player's score.
4. Put a new stone with that sum on the **left side** of the remaining row.

The game ends when only one stone remains.

Alice wants to **maximize**:

    Alice's score - Bob's score

Bob wants to **minimize**:

    Alice's score - Bob's score

Return the score difference when both players play optimally.

---

## Example 1

**Input:**

    stones = [-1,2,-3,4,-5]

**Output:**

    5

### Explanation

Alice removes the first 4 stones:

    -1 + 2 - 3 + 4 = 2

Alice's score becomes:

    2

The new row is:

    [2,-5]

Bob removes both stones:

    2 + (-5) = -3

Bob's score becomes:

    -3

The new row is:

    [-3]

Therefore:

    Alice score - Bob score
    = 2 - (-3)
    = 5

---

## Example 2

**Input:**

    stones = [7,-6,5,10,5,-2,-6]

**Output:**

    13

### Explanation

Alice can remove all stones at once.

Their sum is:

    7 - 6 + 5 + 10 + 5 - 2 - 6 = 13

Alice gets:

    13

Bob gets:

    0

Therefore:

    13 - 0 = 13

---

## Example 3

**Input:**

    stones = [-10,-12]

**Output:**

    -22

### Explanation

There are only two stones, so Alice must remove both:

    -10 + (-12) = -22

Alice gets:

    -22

Bob gets:

    0

Therefore:

    -22 - 0 = -22

---

## Constraints

- `n == stones.length`
- `2 <= n <= 10^5`
- `-10^4 <= stones[i] <= 10^4`

---


# Python Solution

    class Solution:
        def stoneGameVIII(self, stones):
            n = len(stones)

            # Build prefix sums.
            prefix = [0] * n
            prefix[0] = stones[0]

            for i in range(1, n):
                prefix[i] = prefix[i - 1] + stones[i]

            # Start with the move that takes all stones.
            best = prefix[n - 1]

            # Try every possible prefix from right to left.
            for i in range(n - 2, 0, -1):
                best = max(best, prefix[i] - best)

            return best
