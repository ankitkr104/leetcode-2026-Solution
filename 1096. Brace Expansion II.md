# Problem Statement

Given an expression containing:

- Lowercase letters
- `{`
- `}`
- `,`

the expression represents a set of lowercase words.

There are three important rules:

### 1. Single Letters

A letter represents a set containing only that letter.

    R("a") = {"a"}
    R("z") = {"z"}

### 2. Comma Means Union

Expressions separated by commas represent the union of their possible words.

    R("{a,b,c}") = {"a","b","c"}

Duplicates are removed automatically because the result is a set.

### 3. Concatenation

When two expressions are next to each other, concatenate every word from the first set with every word from the second set.

    R("{a,b}{c,d}")
    = {"ac","ad","bc","bd"}

Return all distinct words in **lexicographically sorted order**.

---

## Examples

### Example 1

    Input:
    expression = "{a,b}{c,{d,e}}"

    Output:
    ["ac","ad","ae","bc","bd","be"]

---

### Example 2

    Input:
    expression = "{{a,z},a{b,c},{ab,z}}"

    Output:
    ["a","ab","ac","z"]

Explanation:

The expression produces duplicate words, but each word appears only once.

---

## Constraints

- `1 <= expression.length <= 60`
- Every character is `{`, `}`, `,`, or a lowercase English letter.
- The expression is valid according to the given grammar.

## C++ Solution

    class Solution {
    public:
        string s;
        int pos;

        set<string> combine(const set<string>& a,
                             const set<string>& b) {
            set<string> result;

            for (const string& x : a) {
                for (const string& y : b) {
                    result.insert(x + y);
                }
            }

            return result;
        }

        set<string> parseExpression() {
            set<string> result = parseTerm();

            while (pos < s.size() && s[pos] == ',') {
                pos++;

                set<string> next = parseTerm();

                result.insert(next.begin(), next.end());
            }

            return result;
        }

        set<string> parseTerm() {
            set<string> result;
            result.insert("");

            while (pos < s.size() &&
                   s[pos] != '}' &&
                   s[pos] != ',') {

                set<string> factor;

                if (s[pos] == '{') {
                    pos++;

                    factor = parseExpression();

                    // Skip closing brace.
                    pos++;
                } else {
                    factor.insert(string(1, s[pos]));
                    pos++;
                }

                result = combine(result, factor);
            }

            return result;
        }

        vector<string> braceExpansionII(string expression) {
            s = expression;
            pos = 0;

            set<string> result = parseExpression();

            return vector<string>(result.begin(), result.end());
        }
    };
