# Problem Statement

You are given an `m x n` binary grid where:

- `0` represents an empty cell.
- `1` represents a mirror.

A robot starts at `(0, 0)` and wants to reach `(m - 1, n - 1)`.

The robot can move only right or down.

When the robot attempts to enter a mirror cell:

- If it enters while moving right, it is reflected downward and moves into the cell directly below the mirror.
- If it enters while moving down, it is reflected rightward and moves into the cell directly to the right of the mirror.

If the robot enters another mirror after reflection, the reflection process continues immediately.

If a reflection moves the robot outside the grid, that path is invalid.

Return the number of unique valid paths modulo `10^9 + 7`.

## Examples

### Example 1

**Input:**
    grid = [[0,1,0],
            [0,0,1],
            [1,0,0]]

**Output:**
    5

**Explanation:**

There are five valid paths from the starting cell to the destination.

### Example 2

**Input:**
    grid = [[0,0],
            [0,0]]

**Output:**
    2

**Explanation:**

There are two possible paths:
- Right, then down.
- Down, then right.

### Example 3

**Input:**
    grid = [[0,1,1],
            [1,1,0]]

**Output:**
    1

**Explanation:**

Only one path reaches the destination. The other path eventually moves outside the grid.

## Constraints

- `m == grid.length`
- `n == grid[i].length`
- `2 <= m, n <= 500`
- `grid[i][j]` is either `0` or `1`.
- `grid[0][0] == grid[m - 1][n - 1] == 0`

## C++ Solution

    class Solution {
    public:
        int uniquePaths(vector<vector<int>>& grid) {
            const int MOD = 1e9 + 7;

            int m = grid.size();
            int n = grid[0].size();

            // memo[i][j][dir]:
            // -2 = not calculated
            // -1 = invalid
            // otherwise = flattened index of destination
            vector<vector<array<int, 2>>> memo(
                m, vector<array<int, 2>>(n, {-2, -2})
            );

            // Resolve consecutive mirror reflections.
            // dir = 0: entered while moving right.
            // dir = 1: entered while moving down.
            function<int(int, int, int)> resolve =
                [&](int i, int j, int dir) -> int {

                if (i < 0 || i >= m || j < 0 || j >= n) {
                    return -1;
                }

                if (grid[i][j] == 0) {
                    return i * n + j;
                }

                int& res = memo[i][j][dir];

                if (res != -2) {
                    return res;
                }

                int ni = i;
                int nj = j;

                if (dir == 0) {
                    // Entered from the left: move down.
                    ni++;
                } else {
                    // Entered from above: move right.
                    nj++;
                }

                // The next mirror, if present, is entered
                // using the reflected direction.
                return res = resolve(ni, nj, 1 - dir);
            };

            vector<vector<int>> dp(
                m, vector<int>(n, 0)
            );

            dp[0][0] = 1;

            // Process cells in increasing diagonal order.
            for (int d = 0; d < m + n - 1; d++) {
                int start = max(0, d - (n - 1));
                int finish = min(m - 1, d);

                for (int i = start; i <= finish; i++) {
                    int j = d - i;

                    if (grid[i][j] == 1 || dp[i][j] == 0) {
                        continue;
                    }

                    int ways = dp[i][j];

                    // Move right.
                    if (j + 1 < n) {
                        int destination;

                        if (grid[i][j + 1] == 0) {
                            destination = i * n + (j + 1);
                        } else {
                            destination = resolve(i, j + 1, 0);
                        }

                        if (destination != -1) {
                            int x = destination / n;
                            int y = destination % n;

                            dp[x][y] = (dp[x][y] + ways) % MOD;
                        }
                    }

                    // Move down.
                    if (i + 1 < m) {
                        int destination;

                        if (grid[i + 1][j] == 0) {
                            destination = (i + 1) * n + j;
                        } else {
                            destination = resolve(i + 1, j, 1);
                        }

                        if (destination != -1) {
                            int x = destination / n;
                            int y = destination % n;

                            dp[x][y] = (dp[x][y] + ways) % MOD;
                        }
                    }
                }
            }

            return dp[m - 1][n - 1];
        }
    };
