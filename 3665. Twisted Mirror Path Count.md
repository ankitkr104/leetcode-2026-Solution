# Problem Statement

You are given an `m x n` binary grid where:

- `0` represents an empty cell.
- `1` represents a mirror.

A robot starts at `(0, 0)` and wants to reach `(m - 1, n - 1)`.

The robot can move only right or down.

When the robot attempts to enter a mirror cell:

- If it enters while moving right, it is reflected downward and moves into the cell directly below the mirror.
- If it enters while moving down, it is reflected rightward and moves into the cell directly to the right of the mirror.

If the robot enters another mirror after reflection, the reflection process continues immediately.

If a reflection moves the robot outside the grid, that path is invalid.

Return the number of unique valid paths modulo `10^9 + 7`.

## Examples

### Example 1

**Input:**
    grid = [[0,1,0],
            [0,0,1],
            [1,0,0]]

**Output:**
    5

**Explanation:**

There are five valid paths from the starting cell to the destination.

### Example 2

**Input:**
    grid = [[0,0],
            [0,0]]

**Output:**
    2

**Explanation:**

There are two possible paths:
- Right, then down.
- Down, then right.

### Example 3

**Input:**
    grid = [[0,1,1],
            [1,1,0]]

**Output:**
    1

**Explanation:**

Only one path reaches the destination. The other path eventually moves outside the grid.

## Constraints

- `m == grid.length`
- `n == grid[i].length`
- `2 <= m, n <= 500`
- `grid[i][j]` is either `0` or `1`.
- `grid[0][0] == grid[m - 1][n - 1] == 0`
