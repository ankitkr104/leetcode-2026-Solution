# Problem Statement

You are given an integer array `nums`.

- **Low score**: The minimum absolute difference between any two integers.
- **High score**: The maximum absolute difference between any two integers.
- **Score**: The sum of the low score and high score.

You can change any two elements of `nums`.

Return the minimum possible score after changing exactly two elements.

## Examples

**Example 1:**

    Input: nums = [1,4,7,8,5]
    Output: 3

    Explanation:
    Change nums[0] and nums[1] to 6.
    The array becomes [6,6,7,8,5].

    Low score = 0
    High score = 8 - 5 = 3

    Total score = 0 + 3 = 3.

**Example 2:**

    Input: nums = [1,4,3]
    Output: 0

    Explanation:
    Change nums[1] and nums[2] to 1.
    The array becomes [1,1,1].

    Low score = 0
    High score = 0

    Total score = 0.

## Constraints

- `3 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`


## C++ Solution

    class Solution {
    public:
        int minimizeSum(vector<int>& nums) {
            sort(nums.begin(), nums.end());

            int n = nums.size();

            return min({
                nums[n - 1] - nums[2],
                nums[n - 2] - nums[1],
                nums[n - 3] - nums[0]
            });
        }
    };
