# Problem Statement 

There are several stones arranged in a row, and each stone has an associated value given in the array `stoneValue`.

In each round of the game:

1. Alice divides the row into two non-empty parts: a left part and a right part.
2. Bob calculates the sum of both parts.
3. Bob throws away the part with the larger sum.
4. Alice's score increases by the sum of the part that remains.
5. If both parts have the same sum, Bob lets Alice choose which part to keep.
6. The game continues with the remaining part.

The game ends when only one stone remains.

Return the maximum score Alice can obtain.

---

## Example 1

**Input:** `stoneValue = [6,2,3,4,5,5]`

**Output:** `18`

### Explanation

Alice can divide the array as:

    [6,2,3] | [4,5,5]

The sums are:

    left  = 6 + 2 + 3 = 11
    right = 4 + 5 + 5 = 14

Since `11 < 14`, Bob throws away the right part.

Alice gets `11` points.

The remaining array is:

    [6,2,3]

Alice divides it as:

    [6] | [2,3]

The sums are:

    left  = 6
    right = 5

Bob throws away `[6]`, so Alice gets another `5`.

The remaining array is:

    [2,3]

Alice divides it as:

    [2] | [3]

Bob throws away `[3]`, so Alice gets `2`.

Total score:

    11 + 5 + 2 = 18

Therefore, the answer is `18`.

## Example 3

**Input:** `stoneValue = [4]`

**Output:** `0`

There is only one stone, so Alice cannot divide the row into two non-empty parts.

---

## Constraints

    1 <= stoneValue.length <= 500
    1 <= stoneValue[i] <= 10^6

---

# Python3 Solution

    class Solution:
    def stoneGameV(self, stoneValue: List[int]) -> int:
        @lru_cache(None)
        def dfs(left: int, right: int) -> int:
            if left == right:
                return 0

            total = sum(stoneValue[left : right + 1])
            suml = ans = 0
            for i in range(left, right):
                suml += stoneValue[i]
                sumr = total - suml
                if suml < sumr:
                    ans = max(ans, dfs(left, i) + suml)
                elif suml > sumr:
                    ans = max(ans, dfs(i + 1, right) + sumr)
                else:
                    ans = max(ans, max(dfs(left, i), dfs(i + 1, right)) + suml)
            return ans

        n = len(stoneValue)
        return dfs(0, n - 1)
