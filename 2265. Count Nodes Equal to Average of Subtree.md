## Problem Statement

Given the `root` of a binary tree, return the number of nodes where the value of the node is equal to the **average of the values in its subtree**.

The average is calculated as:

    sum of values in subtree / number of nodes in subtree

The result is **rounded down** to the nearest integer.

A subtree consists of the node itself and all of its descendants.

---

## Examples

### Example 1

Input:

    root = [4,8,5,0,1,null,6]

Output:

    5

Explanation:

For node `4`:

    (4 + 8 + 5 + 0 + 1 + 6) / 6
    = 24 / 6
    = 4

So node `4` is counted.

For node `5`:

    (5 + 6) / 2
    = 11 / 2
    = 5

Since the average is rounded down, node `5` is counted.

Nodes `0`, `1`, and `6` are also counted because each is a leaf:

    0 / 1 = 0
    1 / 1 = 1
    6 / 1 = 6

Therefore, the answer is:

    5

---

### Example 2

Input:

    root = [1]

Output:

    1

Explanation:

The subtree contains only the node `1`.

    1 / 1 = 1

Therefore, the node is counted.

---

## Constraints

- Number of nodes is in `[1, 1000]`.
- `0 <= Node.val <= 1000`.
