# Problem Statement

You are given an `m x n` grid containing only `'('` and `')'`.

Starting from the top-left cell `(0, 0)`, you must reach the bottom-right cell `(m-1, n-1)` by moving only:

- Right
- Down

The characters encountered along the path form a parentheses string.

Return `true` if there exists at least one path whose resulting string is a **valid parentheses string**. Otherwise, return `false`.

A parentheses string is valid if:

- Every `(` has a matching `)`.
- At every prefix of the string, the number of `)` does not exceed the number of `(`.
- At the end, the total number of `(` equals the total number of `)`.

---

## Examples

### Example 1

Input:

    grid = [
        ["(", "(", "("],
        [")", "(", ")"],
        ["(", "(", ")"],
        ["(", "(", ")"]
    ]

Output:

    true

Explanation:

There are paths that form valid parentheses strings such as:

    "()(())"
    "((()))"

Therefore, return `true`.

---

### Example 2

Input:

    grid = [
        [")", ")"],
        ["(", "("]
    ]

Output:

    false

Explanation:

The possible paths produce:

    "))("
    ")(("

Neither is a valid parentheses string.

Therefore, return `false`.

---

## Constraints

- `1 <= m, n <= 100`
- `grid[i][j]` is either `'('` or `')'`.

---

## Approach

The important observation is that while constructing a parentheses string, we only need to know the **current balance**.

Define:

    balance = number of '(' - number of ')'

For a valid parentheses string:

1. The balance can never become negative.
2. The final balance must be exactly `0`.

For every cell `(i, j)`, we maintain all possible balances that can be achieved when reaching that cell.

Let:

    dp[i][j][balance] = true

if there exists a path from `(0,0)` to `(i,j)` whose current parentheses balance is `balance`.

When we enter a cell:

- If `grid[i][j] == '('`, increase the balance by `1`.
- If `grid[i][j] == ')'`, decrease the balance by `1`.

A negative balance is immediately invalid because it means we have encountered more closing parentheses than opening parentheses.

---

## Important Early Checks

The path from `(0,0)` to `(m-1,n-1)` always contains exactly:

    m + n - 1

characters.

A valid parentheses string must have even length.

Therefore:

    if (m + n - 1) % 2 == 1
        return false;

Also, the first character must be `'('` and the last character must be `')'`.

So:

    if grid[0][0] == ')' or grid[m-1][n-1] == '('
        return false;

These checks eliminate many impossible cases immediately.
