# Problem Statement

You are given two positive 0-indexed integer arrays, `nums1` and `nums2`, both of length `n`.

The sum of squared differences is defined as:

    sum((nums1[i] - nums2[i])^2)

You are also given two integers, `k1` and `k2`.

You can perform the following operations:

- Modify any element of `nums1` by `+1` or `-1` at most `k1` times.
- Modify any element of `nums2` by `+1` or `-1` at most `k2` times.

Your task is to return the **minimum possible sum of squared differences** after performing these operations.

Note: Array elements are allowed to become negative.

---

## Examples

### Example 1

Input:

    nums1 = [1,2,3,4]
    nums2 = [2,10,20,19]
    k1 = 0
    k2 = 0

Output:

    579

Explanation:

No modifications are allowed.

    (1 - 2)^2 + (2 - 10)^2 + (3 - 20)^2 + (4 - 19)^2
    = 1 + 64 + 289 + 225
    = 579

### Example 2

Input:

    nums1 = [1,4,10,12]
    nums2 = [5,8,6,9]
    k1 = 1
    k2 = 1

Output:

    43

Explanation:

One optimal strategy is to increase `nums1[0]` once and increase `nums2[2]` once.

The resulting arrays are:

    nums1 = [2,4,10,12]
    nums2 = [5,8,7,9]

The squared difference is:

    (2 - 5)^2 + (4 - 8)^2 + (10 - 7)^2 + (12 - 9)^2
    = 9 + 16 + 9 + 9
    = 43

---

## Constraints

- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `0 <= nums1[i], nums2[i] <= 10^5`
- `0 <= k1, k2 <= 10^9`

---

## C++ Solution

    class Solution {
    public:
        long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2,
                                   int k1, int k2) {
            long long k = (long long)k1 + k2;
            int n = nums1.size();
    
            vector<int> freq(100001, 0);
            long long total = 0;
            int maxDiff = 0;
    
            for (int i = 0; i < n; i++) {
                int d = abs(nums1[i] - nums2[i]);
                freq[d]++;
                total += d;
                maxDiff = max(maxDiff, d);
            }
    
            if (total <= k) {
                return 0;
            }
    
            // Reduce differences from the highest level downward.
            for (int d = maxDiff; d > 0 && k > 0; d--) {
                if (freq[d] == 0) {
                    continue;
                }
    
                long long operationsNeeded = freq[d];
    
                if (k >= operationsNeeded) {
                    // Move all differences at level d to level d - 1.
                    freq[d - 1] += freq[d];
                    k -= operationsNeeded;
                    freq[d] = 0;
                } else {
                    // Only some differences can be reduced by one.
                    freq[d] -= k;
                    freq[d - 1] += k;
                    k = 0;
                }
            }
    
            long long answer = 0;
    
            for (int d = 1; d <= maxDiff; d++) {
                answer += 1LL * d * d * freq[d];
            }
    
            return answer;
        }
    };
