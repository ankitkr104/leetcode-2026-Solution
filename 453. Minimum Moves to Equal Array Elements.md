# Problem Statement

Given an integer array `nums` of size `n`, return the minimum number of moves required to make all array elements equal.

In one move, you can increment exactly `n - 1` elements of the array by `1`.

## Examples

### Example 1

**Input:**
    nums = [1, 2, 3]

**Output:**
    3

**Explanation:**

Only three moves are needed:

    [1, 2, 3]
    [2, 3, 3]
    [3, 4, 3]
    [4, 4, 4]

### Example 2

**Input:**
    nums = [1, 1, 1]

**Output:**
    0

**Explanation:**

All elements are already equal, so no moves are required.

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- The answer is guaranteed to fit in a 32-bit integer.
