# Problem Statement

You are given an integer array `nums`. You may rearrange its elements in any order.

The alternating score of an array `arr` is defined as:

    score = arr[0]² - arr[1]² + arr[2]² - arr[3]² + ...

Return the maximum possible alternating score after rearranging the elements of `nums`.

## Examples

### Example 1

**Input:**
    nums = [1,2,3]

**Output:**
    12

**Explanation:**

One optimal rearrangement is `[2,1,3]`.

    score = 2² - 1² + 3²
          = 4 - 1 + 9
          = 12

### Example 2

**Input:**
    nums = [1,-1,2,-2,3,-3]

**Output:**
    16

**Explanation:**

One optimal rearrangement is `[-3,-1,-2,1,3,2]`.

    score = (-3)² - (-1)² + (-2)² - 1² + 3² - 2²
          = 9 - 1 + 4 - 1 + 9 - 4
          = 16

## Constraints

- `1 <= nums.length <= 10^5`
- `-4 * 10^4 <= nums[i] <= 4 * 10^4`

## C++ Solution

    class Solution {
    public:
        long long maxAlternatingSum(vector<int>& nums) {
            int n = nums.size();
            vector<long long> squares;

            for (int num : nums) {
                squares.push_back(1LL * num * num);
            }

            sort(squares.begin(), squares.end());

            long long answer = 0;

            for (int i = 0; i < n; i++) {
                if (i < n / 2) {
                    answer -= squares[i];
                } else {
                    answer += squares[i];
                }
            }

            return answer;
        }
    };
