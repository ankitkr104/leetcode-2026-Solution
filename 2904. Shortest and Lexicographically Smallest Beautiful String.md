## Problem Statement 

You are given a binary string `s` and a positive integer `k`.

A substring of `s` is called **beautiful** if it contains exactly `k` occurrences of `'1'`.

Let `len` be the length of the **shortest** beautiful substring.

Return the **lexicographically smallest** beautiful substring having length `len`.

If `s` does not contain any beautiful substring, return an empty string `""`.

A string `a` is lexicographically larger than a string `b` of the same length if, at the first position where they differ, `a` contains a character that is greater than the corresponding character in `b`.

For example:

    "abcd" > "abcc"

because the first different character is the fourth character:

    'd' > 'c'

---

## Example 1

**Input:**

    s = "100011001"
    k = 3

**Output:**

    "11001"

### Explanation

We need a substring containing exactly `3` ones.

The shortest beautiful substring has length:

    5

Among all beautiful substrings of length `5`, the lexicographically smallest one is:

    "11001"

Therefore, the answer is:

    "11001"

---

## Example 2

**Input:**

    s = "1011"
    k = 2

**Output:**

    "11"

### Explanation

The substring:

    "11"

contains exactly `2` ones.

Its length is:

    2

This is the shortest possible beautiful substring.

Therefore:

    "11"

is the answer.

---

## Example 3

**Input:**

    s = "000"
    k = 1

**Output:**

    ""

### Explanation

There is no substring containing even one `'1'`.

Therefore, no beautiful substring exists.

Return:

    ""

---

## Constraints

- `1 <= s.length <= 100`
- `1 <= k <= s.length`

---

# Python Solution

    class Solution:
        def shortestBeautifulSubstring(self, s, k):
            positions = []

            # Store positions of all '1's.
            for i, ch in enumerate(s):
                if ch == '1':
                    positions.append(i)

            # Not enough 1s to form a beautiful substring.
            if len(positions) < k:
                return ""

            best = ""
            min_length = float("inf")

            # Check every group of k consecutive 1s.
            for i in range(len(positions) - k + 1):
                left = positions[i]
                right = positions[i + k - 1]

                length = right - left + 1

                candidate = s[left:right + 1]

                if length < min_length:
                    min_length = length
                    best = candidate

                elif length == min_length:
                    if candidate < best:
                        best = candidate

            return best
