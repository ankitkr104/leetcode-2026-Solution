# Problem Statement

Given a string `s` containing only `(` and `)`, return the **minimum number of insertions** needed to make the string balanced.

A string is balanced if every opening parenthesis `(` has exactly **two consecutive closing parentheses `))`** as its matching pair.

For example:

    "())"       -> Balanced
    "())(())))" -> Balanced
    ")()"       -> Not balanced
    "()))"      -> Not balanced

You can insert `(` or `)` at any position in the string.

---

## Examples

### Example 1

Input:

    s = "(()))"

Output:

    1

Explanation:

The first `(` has only one matching `)`, so one more `)` must be inserted.

    "(()))" -> "(())))"

Only one insertion is required.

### Example 2

Input:

    s = "())"

Output:

    0

Explanation:

The string is already balanced.

### Example 3

Input:

    s = "))())("

Output:

    3

Explanation:

- Insert one `(` before the first `))`.
- Insert one `)` to complete the closing pair for the second `(`.
- Insert another `)` to complete the closing pair for the final `(`.

Total insertions: `3`.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists only of `(` and `)`.

---

## C++ Solution

    class Solution {
    public:
        int minInsertions(string s) {
            int answer = 0;
            int need = 0;

            for (char c : s) {
                if (c == '(') {
                    // An opening parenthesis needs two ')'.
                    // If need is odd, complete the pending pair.
                    if (need % 2 == 1) {
                        answer++;
                        need--;
                    }

                    need += 2;
                } else {
                    // Use one required closing parenthesis.
                    need--;

                    // No opening parenthesis can match this ')'.
                    if (need < 0) {
                        answer++;
                        need = 1;
                    }
                }
            }

            // Insert all remaining required ')'.
            answer += need;

            return answer;
        }
    };
