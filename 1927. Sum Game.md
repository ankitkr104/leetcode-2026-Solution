## Problem Statement 

Alice and Bob take turns playing a game, with **Alice starting first**.

You are given a string `num` of **even length** consisting of digits and `'?'` characters.

On each turn, if there is at least one `'?'`, the current player:

1. Chooses an index `i` where `num[i] == '?'`.
2. Replaces `num[i]` with any digit from `'0'` to `'9'`.

The game ends when there are no more `'?'` characters.

For Bob to win:

    sum of digits in first half
    ==
    sum of digits in second half

For Alice to win:

    sum of first half
    !=
    sum of second half

Both players play optimally.

Return `true` if Alice wins, otherwise return `false`.

---

## Example 1

**Input:**

    num = "5023"

**Output:**

    false

### Explanation

There are no `'?'` characters, so there are no moves.

First half:

    5 + 0 = 5

Second half:

    2 + 3 = 5

The sums are equal, so Bob wins.

Therefore:

    false

---

## Example 2

**Input:**

    num = "25??"

**Output:**

    true

### Explanation

Alice can choose one of the question marks and replace it with `9`.

For example:

    "25??"
        ↓
    "259?"

Now Bob cannot choose a digit that makes the two halves equal.

Therefore Alice can force the sums to be different.

Answer:

    true

---

## Example 3

**Input:**

    num = "?3295???"

**Output:**

    false

### Explanation

It can be proven that Bob can always make the two halves equal.

One possible sequence is:

    Alice: ? -> 9
    num = "93295???"

    Bob: ? -> 9
    num = "932959??"

    Alice: ? -> 2
    num = "9329592?"

    Bob: ? -> 7
    num = "93295927"

Now:

    First half:
    9 + 3 + 2 + 9 = 23

    Second half:
    5 + 9 + 2 + 7 = 23

The sums are equal, so Bob wins.

Therefore:

    false

---

## Constraints

- `2 <= num.length <= 10^5`
- `num.length` is even.
- `num` consists only of digits and `'?'`.

---

# Python Solution

    class Solution:
    def sumGame(self, num):
        n = len(num)
        half = n // 2

        left_sum = 0
        right_sum = 0
        left_q = 0
        right_q = 0

        for i in range(half):
            if num[i] == '?':
                left_q += 1
            else:
                left_sum += int(num[i])

        for i in range(half, n):
            if num[i] == '?':
                right_q += 1
            else:
                right_sum += int(num[i])

        # Alice gets the last move when the total number
        # of question marks is odd.
        if (left_q + right_q) % 2 == 1:
            return True

        # Bob wins only when he can exactly balance the sums.
        return left_sum - right_sum != 9 * (right_q - left_q) // 2
