# Problem Statement

You are given an array of **positive integers** `nums` and a positive integer `k`.

You can perform an operation once by removing a prefix and a suffix from `nums`, as long as the remaining array is **non-empty**.

The prefix and suffix may also be empty.

For every `x` from `0` to `k - 1`, find the number of ways to perform the operation such that the **product of the remaining elements** has remainder `x` when divided by `k`.

Return an array `result` of size `k`, where:

    result[x] = number of valid operations whose remaining product % k == x

Since removing a prefix and suffix leaves exactly one **non-empty contiguous subarray**, the problem is equivalent to:

> Count all non-empty subarrays according to the remainder of their product modulo `k`.

---

## Examples

### Example 1

    Input:
    nums = [1,2,3,4,5]
    k = 3

    Output:
    [9,2,4]

There are:

    9 subarrays with product % 3 == 0
    2 subarrays with product % 3 == 1
    4 subarrays with product % 3 == 2

---

### Example 2

    Input:
    nums = [1,2,4,8,16,32]
    k = 4

    Output:
    [18,1,2,0]

---

### Example 3

    Input:
    nums = [1,1,2,1,1]
    k = 2

    Output:
    [9,6]

---

## Constraints

- `1 <= nums[i] <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= k <= 5`
