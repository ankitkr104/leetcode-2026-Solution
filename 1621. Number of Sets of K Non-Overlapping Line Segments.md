# Problem Statement

Given `n` points on a 1-D plane, where the `i`th point is at:

    x = i

for `0 <= i < n`, find the number of ways to draw **exactly `k` non-overlapping line segments**.

Each segment:

- Must cover at least two points.
- Must have integral-coordinate endpoints.
- The segments are allowed to share endpoints.
- The segments do not have to cover all `n` points.

Return the number of possible ways modulo:

    10^9 + 7

Two segments are non-overlapping if they do not share any points, except that they are explicitly allowed to share endpoints.

---

## Examples

### Example 1

Input:

    n = 4
    k = 2

Output:

    5

The five possible sets are:

    {(0,2), (2,3)}
    {(0,1), (1,3)}
    {(0,1), (2,3)}
    {(1,2), (2,3)}
    {(0,1), (1,2)}

---

### Example 2

Input:

    n = 3
    k = 1

Output:

    3

The possible segments are:

    (0,1)
    (0,2)
    (1,2)

---

### Example 3

Input:

    n = 30
    k = 7

Output:

    796297179

## Constraints

- `2 <= n <= 1000`
- `1 <= k <= n - 1`

---

## Key Observation

There is a beautiful combinatorial formula for this problem:

    Answer = C(n + k - 1, 2k)

where `C(a, b)` is the binomial coefficient:

    a choose b

or:

    a! / (b! * (a-b)!)

---

## Why Does This Formula Work?

Suppose the `k` segments are ordered from left to right.

Write their endpoints as:

    l1, r1
    l2, r2
    ...
    lk, rk

Because every segment must have positive length:

    l1 < r1
    l2 < r2
    ...
    lk < rk

Because segments may share endpoints:

    r1 <= l2
    r2 <= l3
    ...

Therefore, the complete sequence of endpoints satisfies:

    l1 < r1 <= l2 < r2 <= ... <= lk < rk

We need to count the number of such endpoint sequences.

---

## Transform the Endpoints

Subtract the segment number from each endpoint:

    l1
    r1 - 1
    l2 - 1
    r2 - 2
    ...
    lk - (k-1)
    rk - k

This converts the required sequence into a non-decreasing sequence.

After this transformation, we are essentially choosing:

    2k

positions from:

    n + k - 1

available positions.

The number of ways to do that is:

    C(n + k - 1, 2k)

Therefore:

    Answer = C(n + k - 1, 2k)

---

## Example: n = 4, k = 2

Using the formula:

    C(n + k - 1, 2k)

Substitute:

    C(4 + 2 - 1, 4)

    = C(5,4)

    = 5

Therefore:

    answer = 5

---

## Example: n = 3, k = 1

    C(3 + 1 - 1, 2)

    = C(3,2)

    = 3

Therefore:

    answer = 3

---

## Computing the Binomial Coefficient

We need:

    C(n + k - 1, 2k)

The maximum value of:

    n + k - 1

is:

    1000 + 999 - 1 = 1998

So we can precompute factorials up to `2000`.

Using:

    C(n,r) = n! / (r! * (n-r)!)

Under modulo arithmetic:

    C(n,r) = fact[n] * inverse(fact[r]) * inverse(fact[n-r])

We calculate modular inverses using **Fermat's Little Theorem**:

    a^(MOD-2) mod MOD

because `MOD = 10^9 + 7` is prime.

---

## Algorithm

1. Let:

       N = n + k - 1

2. We need:

       C(N, 2k)

3. Precompute factorials from `0` to `N`.
4. Compute the modular inverse of the required factorials.
5. Calculate:

       fact[N] * invFact[2k] * invFact[N - 2k]

6. Return the result modulo `10^9 + 7`.

---

## C++ Solution

    class Solution {
    public:
        static const long long MOD = 1000000007LL;

        long long power(long long a, long long b) {
            long long result = 1;

            while (b > 0) {
                if (b & 1) {
                    result = result * a % MOD;
                }

                a = a * a % MOD;
                b >>= 1;
            }

            return result;
        }

        int numberOfSets(int n, int k) {
            int N = n + k - 1;

            vector<long long> fact(N + 1);
            vector<long long> invFact(N + 1);

            // Factorials
            fact[0] = 1;

            for (int i = 1; i <= N; i++) {
                fact[i] = fact[i - 1] * i % MOD;
            }

            // Inverse factorials
            invFact[N] = power(fact[N], MOD - 2);

            for (int i = N - 1; i >= 0; i--) {
                invFact[i] = invFact[i + 1] * (i + 1) % MOD;
            }

            // C(N, 2k)
            long long ans = fact[N];

            ans = ans * invFact[2 * k] % MOD;
            ans = ans * invFact[N - 2 * k] % MOD;

            return (int)ans;
        }
    };
