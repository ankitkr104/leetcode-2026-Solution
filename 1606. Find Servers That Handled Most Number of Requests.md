# Problem Statement

You are given `k` servers numbered from `0` to `k - 1`, which handle multiple requests.

Each request is assigned according to the following rules:

1. The `i-th` request arrives at time `arrival[i]`.
2. If all servers are busy, the request is dropped.
3. Otherwise, try to assign the request to server `i % k`.
4. If that server is busy, assign the request to the next available server, wrapping around to server `0` if necessary.

Each request takes `load[i]` time to complete.

Return the IDs of all servers that handled the maximum number of requests.

## Examples

### Example 1

**Input:**
    k = 3
    arrival = [1,2,3,4,5]
    load = [5,2,3,3,3]

**Output:**
    [1]

**Explanation:**

- Request 0 is assigned to server 0.
- Request 1 is assigned to server 1.
- Request 2 is assigned to server 2.
- Request 3 arrives when server 0 is busy, so it is assigned to server 1.
- Request 4 is dropped because all servers are busy.

Server 1 handles two requests, while the other servers handle one each.

### Example 2

**Input:**
    k = 3
    arrival = [1,2,3,4]
    load = [1,2,1,2]

**Output:**
    [0]

**Explanation:**

Server 0 handles two requests, while servers 1 and 2 handle one each.

### Example 3

**Input:**
    k = 3
    arrival = [1,2,3]
    load = [10,12,11]

**Output:**
    [0,1,2]

**Explanation:**

Each server handles exactly one request, so all servers are busiest.

## Constraints

- `1 <= k <= 10^5`
- `1 <= arrival.length, load.length <= 10^5`
- `arrival.length == load.length`
- `1 <= arrival[i], load[i] <= 10^9`
- `arrival` is strictly increasing.
