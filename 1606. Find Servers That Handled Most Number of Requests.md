# Problem Statement

You are given `k` servers numbered from `0` to `k - 1`, which handle multiple requests.

Each request is assigned according to the following rules:

1. The `i-th` request arrives at time `arrival[i]`.
2. If all servers are busy, the request is dropped.
3. Otherwise, try to assign the request to server `i % k`.
4. If that server is busy, assign the request to the next available server, wrapping around to server `0` if necessary.

Each request takes `load[i]` time to complete.

Return the IDs of all servers that handled the maximum number of requests.

## Examples

### Example 1

**Input:**
    k = 3
    arrival = [1,2,3,4,5]
    load = [5,2,3,3,3]

**Output:**
    [1]

**Explanation:**

- Request 0 is assigned to server 0.
- Request 1 is assigned to server 1.
- Request 2 is assigned to server 2.
- Request 3 arrives when server 0 is busy, so it is assigned to server 1.
- Request 4 is dropped because all servers are busy.

Server 1 handles two requests, while the other servers handle one each.

### Example 2

**Input:**
    k = 3
    arrival = [1,2,3,4]
    load = [1,2,1,2]

**Output:**
    [0]

**Explanation:**

Server 0 handles two requests, while servers 1 and 2 handle one each.

### Example 3

**Input:**
    k = 3
    arrival = [1,2,3]
    load = [10,12,11]

**Output:**
    [0,1,2]

**Explanation:**

Each server handles exactly one request, so all servers are busiest.

## Constraints

- `1 <= k <= 10^5`
- `1 <= arrival.length, load.length <= 10^5`
- `arrival.length == load.length`
- `1 <= arrival[i], load[i] <= 10^9`
- `arrival` is strictly increasing.

## C++ Solution

    class Solution {
        struct Job {
            int at;  // the time its server frees up
            int server;
            auto operator<=>(const Job&) const = default;
        };
        template <class T> using MinHeap = priority_queue<T, vector<T>, greater<>>;
    
    public:
        vector<int> busiestServers(int k, vector<int>& arrival, vector<int>& load) {
            vector<int> turns(k);
            iota(turns.begin(), turns.end(), 0);  // at request 0, server x's next turn is x
            MinHeap<int> free(greater<>{}, std::move(turns));  // each free server, keyed by its next turn
    
            MinHeap<Job> busy;
            vector<int> handled(k);
            for (int i = 0; i < ssize(arrival); ++i) {
                while (!busy.empty() && busy.top().at <= arrival[i]) {  // done by the arrival
                    int x = busy.top().server;
                    busy.pop();
                    free.push(i + (x - i % k + k) % k);  // its first turn from i on
                }
                if (free.empty()) continue;  // none free: the request is dropped
                int x = free.top() % k;
                free.pop();
                busy.push({arrival[i] + load[i], x});
                ++handled[x];
            }
    
            int most = ranges::max(handled);
            vector<int> ans;
            for (int x = 0; x < k; ++x)
                if (handled[x] == most) ans.push_back(x);
            return ans;
        }
    };
