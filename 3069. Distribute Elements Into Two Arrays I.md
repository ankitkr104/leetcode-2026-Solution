# Problem Statement

You are given a **1-indexed** array of **distinct** integers `nums` of length `n`.

You need to distribute all elements of `nums` between two arrays `arr1` and `arr2` using `n` operations.

### Rules

- In the first operation, append `nums[1]` to `arr1`.
- In the second operation, append `nums[2]` to `arr2`.
- For every operation after that:
  - If the last element of `arr1` is **greater** than the last element of `arr2`, append the current element to `arr1`.
  - Otherwise, append the current element to `arr2`.

Finally, form the `result` array by concatenating `arr1` and `arr2`.

For example:

    arr1 = [1,2,3]
    arr2 = [4,5,6]

Then:

    result = [1,2,3,4,5,6]

Return `result`.

---

## Example 1

**Input:**

    nums = [2,1,3]

**Output:**

    [2,3,1]

### Explanation

After the first two operations:

    arr1 = [2]
    arr2 = [1]

For the third element:

    nums[2] = 3

Compare the last elements:

    arr1[-1] = 2
    arr2[-1] = 1

Since:

    2 > 1

we append `3` to `arr1`.

Now:

    arr1 = [2,3]
    arr2 = [1]

Concatenating both arrays:

    result = [2,3,1]

---

## Example 2

**Input:**

    nums = [5,4,3,8]

**Output:**

    [5,3,4,8]

### Explanation

After the first two operations:

    arr1 = [5]
    arr2 = [4]

For `3`:

    5 > 4

Therefore, add `3` to `arr1`:

    arr1 = [5,3]

For `8`:

    3 < 4

Therefore, add `8` to `arr2`:

    arr2 = [4,8]

Finally:

    result = [5,3,4,8]

---

## Constraints

- `3 <= n <= 50`
- `1 <= nums[i] <= 100`
- All elements in `nums` are distinct.
