# Problem Statement

You are given an array `nums` of distinct positive integers.

Sort the array in increasing order based on the sum of the digits of each number. If two numbers have the same digit sum, the smaller number must appear first.

Return the minimum number of swaps required to rearrange `nums` into the sorted order.

A swap means exchanging the values at two distinct positions.

## Examples

### Example 1

**Input:**
    nums = [37,100]

**Output:**
    1

**Explanation:**

The digit sums are `[10,1]`, so the sorted array is `[100,37]`.

One swap is required.

### Example 2

**Input:**
    nums = [22,14,33,7]

**Output:**
    0

**Explanation:**

The digit sums are `[4,5,6,7]`. The array is already sorted, so no swaps are required.

### Example 3

**Input:**
    nums = [18,43,34,16]

**Output:**
    2

**Explanation:**

The digit sums are `[9,7,7,7]`.

The sorted array is `[16,34,43,18]`.

Swap `18` with `16`, then swap `43` with `34`.

The minimum number of swaps is `2`.

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- All elements in `nums` are distinct.
