## Problem Statement

Given a string `s`, return the number of **distinct non-empty subsequences** of `s`.

Since the answer may be very large, return it modulo:

    10^9 + 7

A subsequence is formed from the original string by deleting some characters (possibly none) without changing the relative order of the remaining characters.

For example:

    "ace"

is a subsequence of:

    "abcde"

but:

    "aec"

is not.

---

## Examples

### Example 1

Input:

    s = "abc"

Output:

    7

Explanation:

The distinct non-empty subsequences are:

    "a"
    "b"
    "c"
    "ab"
    "ac"
    "bc"
    "abc"

There are `7` distinct subsequences.

---

### Example 2

The distinct non-empty subsequences are:

    "a"
    "b"
    "ab"

Input:

---

## Constraints

- `1 <= s.length <= 2000`
- `s` consists of lowercase English letters.
