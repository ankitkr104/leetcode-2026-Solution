# Problem Statement

You are given a **palindromic** string `s`.

Return the **lexicographically smallest palindromic permutation** of `s`.

It is guaranteed that at least one palindromic rearrangement exists.

---

## Example 1

```text
Input

s = "z"
```

Output

```text
"z"
```

### Explanation

A single character is already the smallest possible palindrome.

---

## Example 2

```text
Input

s = "babab"
```

Output

```text
"abbba"
```

### Explanation

Character frequencies are

```text
a → 2

b → 3
```

Half of the palindrome is

```text
"ab"
```

Middle character

```text
"b"
```

Reverse of the first half

```text
"ba"
```

Result

```text
"ab" + "b" + "ba"

= "abbba"
```

---

## Example 3

```text
Input

s = "daccad"
```

Output

```text
"acddca"
```

### Explanation

Character frequencies are

```text
a → 2

c → 2

d → 2
```

First half

```text
"acd"
```

Reverse

```text
"dca"
```

Result

```text
"acd" + "" + "dca"

= "acddca"
```

---

## Constraints

```text
1 <= s.length <= 10^5

s consists of lowercase English letters.

s is guaranteed to be palindromic.
```

---

# Python Solution

```python
from collections import Counter

class Solution:
    def smallestPalindrome(self, s: str) -> str:
        freq = Counter(s)

        firstHalf = []
        middle = ""

        for ch in sorted(freq):
            firstHalf.append(ch * (freq[ch] // 2))
            if freq[ch] % 2:
                middle = ch

        firstHalf = "".join(firstHalf)

        return firstHalf + middle + firstHalf[::-1]
```
