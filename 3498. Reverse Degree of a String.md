# Problem Statement

Given a string `s`, calculate its **reverse degree**.

The reverse degree is calculated as follows:

1. Each lowercase letter has a position in the reversed alphabet:
   - `'a' = 26`
   - `'b' = 25`
   - ...
   - `'z' = 1`
2. Multiply this reversed-alphabet value by the character's **1-indexed position** in the string.
3. Add all these products together.

Return the reverse degree of `s`.

---

## Examples

### Example 1

    Input:
    s = "abc"

    Output:
    148

Explanation:

    'a' -> 26 * 1 = 26
    'b' -> 25 * 2 = 50
    'c' -> 24 * 3 = 72

    Total = 26 + 50 + 72 = 148

---

### Example 2

    Input:
    s = "zaza"

    Output:
    160

Explanation:

    'z' -> 1  * 1 = 1
    'a' -> 26 * 2 = 52
    'z' -> 1  * 3 = 3
    'a' -> 26 * 4 = 104

    Total = 1 + 52 + 3 + 104 = 160

---

## Constraints

- `1 <= s.length <= 1000`
- `s` contains only lowercase English letters.

---

## C++ Solution

    class Solution {
    public:
        int reverseDegree(string s) {
            int answer = 0;

            for (int i = 0; i < s.size(); i++) {
                int reverseValue = 26 - (s[i] - 'a');
                answer += reverseValue * (i + 1);
            }

            return answer;
        }
    };
