## Problem Statement

Given two strings `s` and `t`, return the number of distinct subsequences of `s` which equals `t`.

A **subsequence** is formed by deleting some characters from `s` without changing the relative order of the remaining characters.

The answer is guaranteed to fit in a 32-bit signed integer.

---

## Examples

### Example 1

Input:

    s = "rabbbit"
    t = "rabbit"

Output:

    3

Explanation:

There are 3 different ways to delete one of the three `b` characters from `"rabbbit"` to obtain `"rabbit"`.

---

### Example 2

Input:

    s = "babgbag"
    t = "bag"

Output:

    5

Explanation:

There are 5 distinct subsequences of `"babgbag"` that form `"bag"`.

---

## Constraints

- `1 <= s.length, t.length <= 1000`
- `s` and `t` consist of English letters.
- The answer fits in a 32-bit signed integer.

---

## Approach

This is a classic **Dynamic Programming** problem.

The key question is:

> How many ways can we form the first `j` characters of `t` using the first `i` characters of `s`?

We can define:

    dp[j] = number of ways to form t[:j] using the characters processed so far from s

### What happens when characters match?

Suppose:

    s[i] == t[j]

We have two choices:

1. **Use `s[i]`** to match `t[j]`.
2. **Skip `s[i]`** and don't use it.

Therefore:

    dp[j] += dp[j - 1]

If we don't use `s[i]`, the existing `dp[j]` remains unchanged.

So when:

    s[i] == t[j]

we perform:

    dp[j] = dp[j] + dp[j - 1]

### Base Case

There is exactly **one** way to form an empty string:

    dp[0] = 1

That means we can always choose to delete all characters from `s`.

For example:

    s = "abc"
    t = ""

There is exactly one subsequence equal to `""`.

---

## Why Iterate `t` Backwards?

We use a 1D DP array.

When processing a character from `s`, we need:

    dp[j - 1]

from the **previous iteration**.

If we iterate `j` from right to left, `dp[j - 1]` has not yet been modified for the current character.

Therefore, we safely update:

    dp[j] += dp[j - 1]

from right to left.

---

## Algorithm

1. Create a DP array of size `len(t) + 1`.
2. Set `dp[0] = 1`.
3. Iterate through every character `ch` in `s`.
4. For each character, iterate through `t` from right to left.
5. If `ch == t[j - 1]`, add the number of ways to form `t[:j-1]` to the number of ways to form `t[:j]`.
6. Return `dp[len(t)]`.

---

## Python Solution

    class Solution:
        def numDistinct(self, s, t):
            m = len(t)

            dp = [0] * (m + 1)
            dp[0] = 1

            for ch in s:
                for j in range(m, 0, -1):
                    if ch == t[j - 1]:
                        dp[j] += dp[j - 1]

            return dp[m]
