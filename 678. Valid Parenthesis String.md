# Problem Statement

Given a string `s` containing three types of characters:

    '('
    ')'
    '*'

return `true` if the string is valid.

The rules are:

- Every `(` must have a corresponding `)`.
- Every `)` must have a corresponding `(`.
- An opening parenthesis must appear before its corresponding closing parenthesis.
- `*` can be treated as:
  - `(`
  - `)`
  - An empty string `""`

---

## Examples

### Example 1

Input:

    s = "()"

Output:

    true

---

### Example 2

Input:

    s = "(*)"

Output:

    true

Explanation:

The `*` can be treated as an empty string:

    "()"

---

### Example 3

Input:

    s = "(*))"

Output:

    true

Explanation:

The `*` can be treated as `(`:

    "(())"

---

### Example 4

Input:

    s = "("

Output:

    false

---

## Constraints

- `1 <= s.length <= 100`
- `s[i]` is `'('`, `')'`, or `'*'`.
