# Problem Statement

Given a string `s` containing three types of characters:

    '('
    ')'
    '*'

return `true` if the string is valid.

The rules are:

- Every `(` must have a corresponding `)`.
- Every `)` must have a corresponding `(`.
- An opening parenthesis must appear before its corresponding closing parenthesis.
- `*` can be treated as:
  - `(`
  - `)`
  - An empty string `""`

---

## Examples

### Example 1

Input:

    s = "()"

Output:

    true

---

### Example 2

Input:

    s = "(*)"

Output:

    true

Explanation:

The `*` can be treated as an empty string:

    "()"

---

### Example 3

Input:

    s = "(*))"

Output:

    true

Explanation:

The `*` can be treated as `(`:

    "(())"

---

### Example 4

Input:

    s = "("

Output:

    false

---

## Constraints

- `1 <= s.length <= 100`
- `s[i]` is `'('`, `')'`, or `'*'`.

---

## C++ Solution

    class Solution {
    public:
        bool checkValidString(string s) {
            int low = 0;
            int high = 0;

            for (char c : s) {

                if (c == '(') {
                    low++;
                    high++;
                }
                else if (c == ')') {
                    low--;
                    high--;
                }
                else {
                    // '*' can be ')', '(' or empty.
                    low--;
                    high++;
                }

                // Minimum possible balance cannot be negative.
                low = max(low, 0);

                // Even the maximum possible balance is negative.
                if (high < 0) {
                    return false;
                }
            }

            // We need some interpretation with exactly
            // zero unmatched opening parentheses.
            return low == 0;
        }
    };
