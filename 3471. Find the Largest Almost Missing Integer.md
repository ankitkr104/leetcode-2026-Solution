# Problem Statement 

You are given an integer array `nums` and an integer `k`.

An integer `x` is called **almost missing** from `nums` if `x` appears in **exactly one subarray of size `k`** within `nums`.

Return the **largest almost missing integer** from `nums`.

If no such integer exists, return `-1`.

A **subarray** is a contiguous sequence of elements within `nums`.

---

## Example 1

**Input:** `nums = [3,9,2,1,7], k = 3`

**Output:** `7`

### Explanation

There are three subarrays of size `3`:

    [3,9,2]
    [9,2,1]
    [2,1,7]

The occurrences are:

    1 -> appears in 2 subarrays
    2 -> appears in 3 subarrays
    3 -> appears in 1 subarray
    7 -> appears in 1 subarray
    9 -> appears in 2 subarrays

The integers that appear in exactly one subarray are:

    3, 7

The largest one is:

    7

Therefore, the answer is `7`.

---

## Example 2

**Input:** `nums = [3,9,7,2,1,7], k = 4`

**Output:** `3`

### Explanation

The subarrays of size `4` are:

    [3,9,7,2]
    [9,7,2,1]
    [7,2,1,7]

The occurrences are:

    1 -> appears in 2 subarrays
    2 -> appears in 3 subarrays
    3 -> appears in 1 subarray
    7 -> appears in 3 subarrays
    9 -> appears in 2 subarrays

Only `3` appears in exactly one subarray.

Therefore, the answer is:

    3

---

## Example 3

**Input:** `nums = [0,0], k = 1`

**Output:** `-1`

### Explanation

The subarrays of size `1` are:

    [0]
    [0]

The value `0` appears in both subarrays, so it does not appear in exactly one subarray.

Therefore, there is no almost missing integer.

Answer:

    -1

---

## Constraints

    1 <= nums.length <= 50
    0 <= nums[i] <= 50
    1 <= k <= nums.length

---

# Python3 Solution

    class Solution:
        def largestInteger(self, nums, k):
            count = {}
    
            n = len(nums)
    
            # Check every subarray of size k
            for i in range(n - k + 1):
                # Set ensures that a number is counted
                # only once inside the same subarray.
                seen = set(nums[i:i + k])
    
                for x in seen:
                    count[x] = count.get(x, 0) + 1
    
            # Find the largest number that appears
            # in exactly one subarray.
            ans = -1
    
            for x in count:
                if count[x] == 1:
                    ans = max(ans, x)
    
            return ans
