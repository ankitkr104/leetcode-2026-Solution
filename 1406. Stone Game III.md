## Problem Statement

Alice and Bob are playing a game with a row of stones.

Each stone has an integer value given in the array `stoneValue`.

Rules:

- Alice starts first.
- On each turn, a player may take **1**, **2**, or **3** stones from the beginning of the remaining row.
- The player's score is the sum of the values of the stones they take.
- Both players play optimally.

Return

- `"Alice"` if Alice wins.
- `"Bob"` if Bob wins.
- `"Tie"` if both players finish with the same score.

---

## Example 1

```text
Input

stoneValue = [1,2,3,7]
```

Output

```text
"Bob"
```

### Explanation

Whatever Alice chooses, Bob can always obtain a larger score.

---

## Example 2

```text
Input

stoneValue = [1,2,3,-9]
```

Output

```text
"Alice"
```

### Explanation

Alice should take the first three stones.

```text
Score = 1 + 2 + 3 = 6
```

Bob is forced to take

```text
-9
```

Alice wins.

---

## Example 3

```text
Input

stoneValue = [1,2,3,6]
```

Output

```text
"Tie"
```

### Explanation

Both players can finish with the same score.

---

## Constraints

```text
1 <= stoneValue.length <= 5 × 10^4

-1000 <= stoneValue[i] <= 1000
```

---

# Python3 Solution

```python
from typing import List

class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)

        dp = [0] * (n + 1)

        for i in range(n - 1, -1, -1):
            best = float("-inf")
            total = 0

            for j in range(i, min(i + 3, n)):
                total += stoneValue[j]
                best = max(best, total - dp[j + 1])

            dp[i] = best

        if dp[0] > 0:
            return "Alice"
        elif dp[0] < 0:
            return "Bob"
        else:
            return "Tie"
```
