# Problem Statement

A parentheses string is valid if:

- It is the empty string.
- It can be written as `AB`, where both `A` and `B` are valid.
- It can be written as `(A)`, where `A` is valid.

You are given a string `s` containing only `(` and `)`.

In one move, you can insert a parenthesis at any position in the string.

Return the **minimum number of insertions** required to make `s` a valid parentheses string.

---

## Examples

### Example 1

Input:

    s = "())"

Output:

    1

Explanation:

Insert one `(` before the last `)`:

    "())" -> "()( )"

More simply, the string can become:

    "(())"

Therefore, only `1` insertion is required.

---

### Example 2

Input:

    s = "((("

Output:

    3

Explanation:

There are three unmatched opening parentheses, so we need three closing parentheses:

    "(((" -> "((()))"

Therefore, the answer is `3`.

---

## Constraints

- `1 <= s.length <= 1000`
- `s[i]` is either `(` or `)`.

---

## C++ Solution

    class Solution {
    public:
        int minAddToMakeValid(string s) {
            int balance = 0;
            int answer = 0;

            for (char c : s) {

                if (c == '(') {
                    // An unmatched opening parenthesis.
                    balance++;
                }
                else {
                    // Try to match this closing parenthesis.
                    if (balance > 0) {
                        balance--;
                    }
                    else {
                        // No '(' available.
                        // We need to insert one.
                        answer++;
                    }
                }
            }

            // Remaining '(' need matching ')'.
            answer += balance;

            return answer;
        }
    };
