# Problem Statement

Given `n` pairs of parentheses, generate all combinations of **well-formed parentheses**.

A well-formed parentheses string must:

- Never have more closing parentheses than opening parentheses at any point.
- Contain exactly `n` opening parentheses and `n` closing parentheses.

Return all possible valid combinations.

---

## Examples

### Example 1

Input:

    n = 3

Output:

    ["((()))","(()())","(())()","()(())","()()()"]

---

### Example 2

Input:

    n = 1

Output:

    ["()"]

---

## Constraints

- `1 <= n <= 8`
