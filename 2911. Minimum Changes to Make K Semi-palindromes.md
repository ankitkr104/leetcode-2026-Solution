# Problem Statement

You are given a string `s` and an integer `k`.

Partition `s` into exactly `k` non-empty substrings such that every substring is a semi-palindrome.

A substring is a **semi-palindrome** if there exists a positive divisor `d` of its length, where `d` is strictly smaller than its length, such that the characters at positions following the same repeating pattern of length `d` form palindromes.

Return the minimum number of character changes required to make all `k` substrings semi-palindromes.

## Examples

**Example 1:**

    Input: s = "abcac", k = 2
    Output: 1

    Explanation:
    Partition into "ab" and "cac".
    "cac" is already a semi-palindrome.
    Change "ab" into "aa" using one character change.

**Example 2:**

    Input: s = "abcdef", k = 2
    Output: 2

    Explanation:
    Partition into "abc" and "def".
    Each substring requires one character change.

**Example 3:**

    Input: s = "aabbaa", k = 3
    Output: 0

    Explanation:
    Partition into "aa", "bb", and "aa".
    All three substrings are already semi-palindromes.

## Constraints

- `2 <= s.length <= 200`
- `1 <= k <= s.length / 2`
- `s` contains only lowercase English letters.

## C++ Solution

    class Solution {
    public:
        int minimumChanges(string s, int k) {
            int n = s.size(), inf = INT_MAX / 2;
            auto peel = [&](int i, int j, int d) {  // s[i:j] in blocks of d: the outer pair of blocks, then the inside
                int changes = 0;
                for (; j - i > d; i += d, j -= d)
                    for (int t = 0; t < d; ++t)
                        changes += s[i + t] != s[j - d + t];
                return changes;
            };
    
            vector cost(n + 1, vector(n + 1, inf));  // cost[i][j]: changes to make s[i:j] a semi-palindrome
            for (int d = 1; 2 * d <= n; ++d)
                for (int length = 2 * d; length <= n; length += d)  // every length that d divides, with d < length
                    for (int i = 0, j = length; j <= n; ++i, ++j)
                        cost[i][j] = min(cost[i][j], peel(i, j, d));
    
            vector best(n + 1, inf);  // best[j]: the fewest changes for s[:j] cut into the pieces placed so far
            best[0] = 0;
            auto extend = [&](int j) {  // the newest piece s[i:j] starts at an old cut i and gets at least 2 letters
                return ranges::min(views::iota(0, j - 1) | views::transform([&](int i) { return best[i] + cost[i][j]; }));
            };
            for (int pieces = 1; pieces < k; ++pieces) {  // every piece but the last
                vector next(n + 1, inf);
                for (int j = 2 * pieces; j <= n - 2 * (k - pieces); ++j)  // 2 letters for each piece, placed or still to come
                    next[j] = extend(j);
                swap(best, next);
            }
            return extend(n);  // the last piece ends at n
        }
    };
