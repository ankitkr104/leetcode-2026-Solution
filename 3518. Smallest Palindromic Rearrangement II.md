# Problem Statement

You are given a **palindromic** string `s` and an integer `k`.

Return the **k-th lexicographically smallest palindromic permutation** of `s`.

If there are fewer than `k` distinct palindromic permutations, return an empty string.

**Note:** Different rearrangements producing the same palindrome are counted only once.

---

## Example 1

```text
Input

s = "abba"

k = 2
```

Output

```text
"baab"
```

### Explanation

The distinct palindromic rearrangements are

```text
abba

baab
```

Lexicographical order

```text
abba

baab
```

The 2nd palindrome is

```text
baab
```

---

## Example 2

```text
Input

s = "aa"

k = 2
```

Output

```text
""
```

### Explanation

There is only one palindromic rearrangement.

Since

```text
k > 1
```

the answer is an empty string.

---

## Example 3

```text
Input

s = "bacab"

k = 1
```

Output

```text
"abcba"
```

### Explanation

The distinct palindromes are

```text
abcba

bacab
```

The first one is

```text
abcba
```

---

## Constraints

```text
1 <= s.length <= 10000

s consists of lowercase English letters.

s is guaranteed to be palindromic.

1 <= k <= 10^6
```
