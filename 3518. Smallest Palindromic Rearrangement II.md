# Problem Statement

You are given a **palindromic** string `s` and an integer `k`.

Return the **k-th lexicographically smallest palindromic permutation** of `s`.

If there are fewer than `k` distinct palindromic permutations, return an empty string.

**Note:** Different rearrangements producing the same palindrome are counted only once.

---

## Example 1

```text
Input

s = "abba"

k = 2
```

Output

```text
"baab"
```

### Explanation

The distinct palindromic rearrangements are

```text
abba

baab
```

Lexicographical order

```text
abba

baab
```

The 2nd palindrome is

```text
baab
```

---

## Example 2

```text
Input

s = "aa"

k = 2
```

Output

```text
""
```

### Explanation

There is only one palindromic rearrangement.

Since

```text
k > 1
```

the answer is an empty string.

---

## Example 3

```text
Input

s = "bacab"

k = 1
```

Output

```text
"abcba"
```

### Explanation

The distinct palindromes are

```text
abcba

bacab
```

The first one is

```text
abcba
```

---

## Constraints

```text
1 <= s.length <= 10000

s consists of lowercase English letters.

s is guaranteed to be palindromic.

1 <= k <= 10^6
```

---

# Python3 Solution

```python
class Solution:
    def smallestPalindrome(self, s: str, k: int) -> str:
        def comb(n: int, m: int, k_limit: int) -> int:
            res = 1
            m = min(m, n - m)

            for i in range(1, m + 1):
                res = res * (n - i + 1) // i
                if res > k_limit:
                    return k_limit + 1
            return res

        partition = len(s) // 2
        bucket = [0] * 26

        for i in range(partition):
            bucket[ord(s[i]) - 97] += 1

        def permutations(rem: int) -> int:
            ways = 1
            for i in range(26):
                if bucket[i] == 0:
                    continue

                ways *= comb(rem, bucket[i], k)
                if ways > k:
                    break
                rem -= bucket[i]
            return ways

        left_chars = []
        start_index = 1

        for pos in range(partition):
            for i in range(26):
                if bucket[i] == 0:
                    continue

                bucket[i] -= 1

                ways = permutations(partition - pos - 1)
                if start_index + ways > k:
                    left_chars.append(chr(i + 97))
                    break

                bucket[i] += 1
                start_index += ways

        if len(left_chars) < partition:
            return ""

        mid = s[partition] if len(s) % 2 != 0 else ""
        left_str = "".join(left_chars)
        right_str = left_str[::-1]

        return left_str + mid + right_str
```
