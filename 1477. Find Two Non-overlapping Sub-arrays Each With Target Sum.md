# Problem Statement

You are given an array of integers `arr` and an integer `target`.

Find **two non-overlapping sub-arrays** such that each sub-array has a sum equal to `target`.

If multiple answers exist, return the **minimum possible sum of the lengths** of the two sub-arrays.

Return `-1` if it is impossible to find two such sub-arrays.

---

## Examples

### Example 1

    Input: arr = [3,2,2,4,3], target = 3
    Output: 2

Explanation:

The only sub-arrays with sum `3` are `[3]` at the beginning and `[3]` at the end.

Their total length is:

    1 + 1 = 2

---

### Example 2

    Input: arr = [7,3,4,7], target = 7
    Output: 2

Explanation:

Possible sub-arrays are:

    [7]       -> length 1
    [3,4]     -> length 2
    [7]       -> length 1

We can choose the first `[7]` and the last `[7]`.

Total length:

    1 + 1 = 2

---

### Example 3

    Input: arr = [4,3,2,6,2,3,4], target = 6
    Output: -1

Explanation:

There is only one sub-array with sum `6`, so we cannot choose two non-overlapping sub-arrays.

---

## Constraints

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`

---

## C++ Solution

    class Solution {
    public:
        int minSumOfLengths(vector<int>& arr, int target) {
            int n = arr.size();
            const int INF = 1e9;

            vector<int> best(n, INF);

            int left = 0;
            long long sum = 0;
            int ans = INF;
            int minLength = INF;

            for (int right = 0; right < n; right++) {
                sum += arr[right];

                while (sum > target) {
                    sum -= arr[left];
                    left++;
                }

                if (sum == target) {
                    int currentLength = right - left + 1;

                    // Combine with the shortest valid subarray
                    // completely before the current one.
                    if (left > 0 && best[left - 1] != INF) {
                        ans = min(ans, currentLength + best[left - 1]);
                    }

                    minLength = min(minLength, currentLength);
                }

                // Best valid subarray ending at or before right.
                if (right > 0) {
                    best[right] = best[right - 1];
                }

                best[right] = min(best[right], minLength);
            }

            return ans == INF ? -1 : ans;
        }
    };
