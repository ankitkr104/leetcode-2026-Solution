# Problem Statement

You are given an array of integers `arr` and an integer `target`.

Find **two non-overlapping sub-arrays** such that each sub-array has a sum equal to `target`.

If multiple answers exist, return the **minimum possible sum of the lengths** of the two sub-arrays.

Return `-1` if it is impossible to find two such sub-arrays.

---

## Examples

### Example 1

    Input: arr = [3,2,2,4,3], target = 3
    Output: 2

Explanation:

The only sub-arrays with sum `3` are `[3]` at the beginning and `[3]` at the end.

Their total length is:

    1 + 1 = 2

---

### Example 2

    Input: arr = [7,3,4,7], target = 7
    Output: 2

Explanation:

Possible sub-arrays are:

    [7]       -> length 1
    [3,4]     -> length 2
    [7]       -> length 1

We can choose the first `[7]` and the last `[7]`.

Total length:

    1 + 1 = 2

---

### Example 3

    Input: arr = [4,3,2,6,2,3,4], target = 6
    Output: -1

Explanation:

There is only one sub-array with sum `6`, so we cannot choose two non-overlapping sub-arrays.

---

## Constraints

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`
